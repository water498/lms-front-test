# 과정 검색 (Student)

강의 검색 페이지. 텍스트 검색, 카테고리/수업방식/난이도/가격 필터, 정렬 기능을 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 정보 (제목, 강사, 태그, 평점, 가격, 타입 등) |

## 화면 구성

### 섹션: 검색 바
- 텍스트 입력 + "검색" 버튼
- 강의명, 강사명, 기술 스택, 카테고리로 검색
- URL 쿼리 파라미터(q)와 동기화

### 섹션: 필터 사이드바 (데스크톱 좌측)
- **카테고리**: 프론트엔드, 백엔드, 데이터, AI/ML, 모바일, 디자인, DevOps, 기타
- **수업 방식**: 온라인, 오프라인, 온+오프라인
- **난이도**: 입문, 초급, 중급, 고급
- **가격**: 전체/무료/유료 (라디오)
- 필터 초기화 버튼
- 모바일에서는 토글 버튼으로 접기/펼치기

### 섹션: 결과 헤더
- 검색어 표시, 결과 수
- 정렬: 관련순, 평점 높은순, 최신순, 낮은 가격순, 높은 가격순
- 활성 필터 칩 (클릭 시 해제)

### 섹션: 검색 결과 카드 목록
- 가로형 카드: 썸네일, 제목, 강사, 태그, 평점, 가격
- 수업 타입 배지 (온라인/오프라인/혼합)
- 오프라인 과정: 장소, 개강일, 정원 표시
- 위시리스트 하트 토글
- 유료: "담기" 버튼 (장바구니), 무료: "무료 수강" 링크
- 결과 없을 때: 검색어 지우기/필터 초기화 안내

## 비즈니스 규칙

- 장바구니·위시리스트 상태는 대시보드와 공유 (모듈 레벨 store)
- 카드 클릭 시 과정 상세 페이지로 이동
- 필터와 정렬은 클라이언트 사이드 처리 (프로토타입)
