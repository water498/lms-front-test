# 공지사항 목록 (Student)

전체 공지사항 목록 페이지. 공지/이벤트/업데이트를 필터링하고 펼쳐서 본문을 확인한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Announcement | announcement | 공지사항 (타입, 제목, 본문, 날짜) |

## 화면 구성

### 섹션: 필터 탭
- 전체 / 공지(NOTICE) / 이벤트(EVENT) / 업데이트(UPDATE)
- 활성 필터는 보라색 배경

### 섹션: 공지 목록
- 타입 배지: 공지(회색), 이벤트(붉은색), 업데이트(파란색)
- 제목, 7일 이내면 "NEW" 표시
- 날짜 표시
- 클릭 시 아코디언 펼침/접기
- 펼침 시 본문 텍스트 표시

## 비즈니스 규칙

- 하나의 공지만 동시에 펼칠 수 있음 (다른 것 클릭 시 이전 것 접힘)
- 7일 이내 생성된 공지에 NEW 라벨 표시
- 장바구니 수량은 네비게이션 바에 표시
