# 약관 및 정책 (Student)

이용약관, 개인정보처리방침, 운영정책을 탭으로 구분하여 표시하는 법적 문서 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| LegalDocument | platform | 약관/정책 문서 (시행일, 본문) |

## 화면 구성

### 섹션: 탭 바
- 이용약관(terms) / 개인정보처리방침(privacy) / 운영정책(policy)
- URL 쿼리 파라미터(tab)와 동기화

### 섹션: 문서 본문
- 시행일 표시
- 본문 텍스트 (pre-wrap 포맷)

## 비즈니스 규칙

- URL 쿼리 파라미터로 초기 탭 지정 가능 (?tab=privacy)
- 읽기 전용 뷰
