# 나의 학습 (Student)

마이페이지 내 수강 중/완료 과정을 한눈에 확인하는 학습 현황 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Enrollment | enrollment | 수강 등록 |
| CourseProgress | progress | 과정 진행률 |
| Course | course | 과정 정보 |

## 화면 구성

### 섹션: 수강 중
- 진행 중인 과정 카드 목록 (썸네일, 제목, 강사, 레벨, 진행률 바, 다음 레슨)
- 클릭 시 세션 또는 학습 플레이어로 이동

### 섹션: 완료
- progress 100%인 과정 카드 목록
- 완료 아이콘 오버레이 + 완료일 표시
- 액션 버튼: 다시 보기, 리뷰 작성, 수료증 보기

## 비즈니스 규칙

- 수강 중 과정은 sessionId 유무에 따라 세션 페이지 또는 학습 플레이어로 분기
- 완료 과정의 리뷰 작성은 과정 상세 reviews 탭으로 이동
- 수료증 버튼은 수료증 목록 페이지(/my/certificates)로 이동
