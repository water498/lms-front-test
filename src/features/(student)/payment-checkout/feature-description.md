# 결제 (Student)

[B2C only] 주문/결제 페이지. 주문 강의 확인, 구매자 정보, 결제 수단 선택, 약관 동의 후 결제를 진행한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 주문 강의 정보 |
| Order | payment | 주문 (주문번호, 결제 금액) |
| Coupon | payment | 쿠폰 코드 |

## 화면 구성

### 섹션: 브레드크럼
- 홈 > 장바구니 > 결제

### 섹션: 주문 강의 (좌측)
- 주문 강의 수, 각 강의 썸네일/제목/강사/가격
- 오프라인 과정: 장소, 개강일 추가 표시

### 섹션: 구매자 정보 (좌측)
- 이름, 이메일, 연락처 입력란 (기본값 채워짐)

### 섹션: 결제 수단 (좌측)
- 신용/체크카드, 카카오페이, 네이버페이, 계좌이체 (4개 버튼 그리드)
- 카드 선택 시: 카드사 드롭다운 (현대/신한/국민/우리/하나/삼성)
- 간편결제 선택 시: PG 연동 안내
- 계좌이체 선택 시: 입금 계좌 안내

### 섹션: 약관 동의 (좌측)
- 전체 동의 체크박스
- 이용약관 동의 (필수), 개인정보 수집/이용 동의 (필수)

### 섹션: 결제 금액 사이드바 (우측 고정)
- 강의 금액, 쿠폰 할인, 총 결제 금액
- 쿠폰 코드 입력 + 적용 (OPEN10 = 10% 할인)
- "결제하기" 버튼 (약관 미동의 시 비활성화)
- 결제 처리 중 스피너 표시
- SSL 암호화 안내

## 비즈니스 규칙

- B2C 전용 페이지 (B2B tenantType에서는 접근 불가)
- 장바구니 비어있으면 빈 상태 표시
- 약관 모두 동의해야 결제 가능
- 결제 처리: 1.4초 지연 후 성공 페이지로 이동 (PG 시뮬레이션)
- 결제 완료 시 장바구니 비움 + 주문번호 생성
- 총액이 0원이면 "무료 수강 신청" 버튼 표시
