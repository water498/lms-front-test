# 내 리뷰 목록 (Student)

작성한 과정 리뷰와 강사 리뷰를 조회하고 수정/삭제할 수 있는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseReview | review | 과정 리뷰 (별점, 본문) |
| InstructorReview | review | 강사 리뷰 (별점, 본문) |

## 화면 구성

### 섹션: 필터
- 전체 / 과정 리뷰 / 강사 리뷰 필터 토글 + 건수 표시

### 섹션: 리뷰 카드 그리드
- 2열 카드 (유형 뱃지, 대상명 링크, 작성일, 별점, 리뷰 본문)
- 액션: 과정 보기(링크), 수정, 삭제
- 수정 모드: 인라인 별점 선택기 + 텍스트 에디터 + 저장/취소
- 삭제 시 confirm 다이얼로그

### 빈 상태
- 리뷰 없음 안내 + 수강 완료 후 작성 유도 메시지

## 비즈니스 규칙

- 리뷰 수정 시 별점 + 본문 모두 필수 (빈값 저장 불가)
- 삭제는 confirm 후 즉시 반영
- 과정 리뷰와 강사 리뷰는 동일 과정에 대해 각각 독립 작성
