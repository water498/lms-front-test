# 주문 내역 (Student)

과정 구매 이력과 결제 상태를 확인하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Order | order | 주문 정보 (주문번호, 금액, 상태) |
| OrderItem | order | 주문 항목 (과정별 단가, 할인) |

## 화면 구성

### 섹션: 주문 목록
- 주문 카드별 헤더: 주문번호(mono), 주문일, 상태 뱃지(결제 대기/완료/취소/환불)
- 주문 항목: 과정명 + 가격 (할인 시 원가 취소선 표시)
- 푸터: 쿠폰 할인 금액 + 합계 (다건 주문 또는 할인 시 표시)

## 비즈니스 규칙

- 주문 상태: PENDING, PAID, CANCELLED, REFUNDED
- 할인 금액이 있을 경우 원가 취소선 + 할인가 표시
- 다건 주문 시 합계 영역 표시

## B2C/B2B 분기

- B2C 전용 탭 (features.payments 플래그 기반)
- B2B 환경에서는 마이페이지 탭 자체가 숨겨짐
