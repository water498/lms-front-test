# 세션 공지 (Student)

세션 워크스페이스의 "공지" 탭. 세션별 공지사항 목록을 표시한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionAnnouncement | announcement | 세션 공지 (타입, 제목, 본문, 작성자, 날짜) |

## 화면 구성

### 섹션: 공지 목록
- 긴급(URGENT): 경고 아이콘 + 붉은 배경, "긴급" 배지
- 일반: 메가폰 아이콘 + 기본 배경
- 제목, 본문, 작성자, 날짜 표시
- 공지 없을 때: "등록된 공지가 없습니다" 안내

## 비즈니스 규칙

- session-layout의 SessionWorkspaceProvider에서 announcements 데이터 전달받음
- 읽기 전용 뷰 (수강생 액션 없음)
