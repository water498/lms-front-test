# 회원가입 (Student)

B2C 학생 회원가입 페이지. 이름, 이메일, 비밀번호 입력 후 이메일 인증 페이지로 이동한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 사용자 등록 정보 |

## 화면 구성

- 이름, 이메일, 비밀번호, 비밀번호 확인 입력
- 비밀번호 불일치 시 오류 메시지
- 이용약관 및 개인정보 처리방침 동의 체크박스
- "회원가입" 버튼 (모든 필수값 + 동의 시 활성화)
- 로그인 링크

## 비즈니스 규칙

- 비밀번호 8자 이상
- 비밀번호 확인 불일치 시 실시간 오류 표시
- 가입 완료 시 이메일 인증(verify-email) 페이지로 이동
