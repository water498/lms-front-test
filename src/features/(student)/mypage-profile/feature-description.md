# 프로필 설정 (Student)

사용자 기본 정보(이름, 이메일, 자기소개)와 비밀번호를 수정하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 사용자 프로필 (이름, 이메일, 아바타, 비밀번호) |

## 화면 구성

### 섹션: 아바타
- 프로필 사진 (이니셜 fallback) + 이름/이메일 표시
- 프로필 사진 변경 버튼

### 섹션: 정보 폼
- 이름 입력
- 이메일 입력
- 자기소개 텍스트에어리어
- 비밀번호 변경 입력
- 저장하기 버튼 (저장 시 2초간 성공 피드백)

## 비즈니스 규칙

- 저장 후 "저장되었습니다" 피드백 2초 표시
- 현재 B2C 기준으로 모든 필드 편집 가능

## B2C/B2B 분기

- B2B SSO 사용자: idpManagedFields에 해당하는 필드(이름, 이메일 등)는 read-only 처리
- B2B SSO 사용자: 비밀번호 변경 UI 숨김 (IdP에서 관리)
