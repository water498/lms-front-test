# 세션 자료실 (Student)

세션 워크스페이스의 "자료실" 탭. 강사가 업로드한 학습 자료를 카테고리별로 표시하고 다운로드를 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| StudentResource | course | 학습 자료 (파일명, MIME 타입, 크기, 카테고리, 설명) |

## 화면 구성

### 섹션: 자료 목록 (카테고리별 그룹)
- 카테고리명 헤더
- 파일 카드: MIME 타입별 아이콘(PDF/PPT/Excel/기타), 제목, 설명, 파일명, 파일 크기
- "다운로드" 버튼
- 자료 없을 때: "등록된 자료가 없습니다" 안내

## 비즈니스 규칙

- session-layout의 SessionWorkspaceProvider에서 resources 데이터 전달받음
- 파일 크기는 B/KB/MB 단위로 자동 변환 표시
