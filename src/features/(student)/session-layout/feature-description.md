# 세션 워크스페이스 레이아웃 (Student)

수강 등록된 세션의 워크스페이스 레이아웃. 홈/커리큘럼/Q&A/공지/자료실 탭을 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Session | course | 세션 정보 (이름, 기간, 정원, 수료 기준) |
| Course | course | 과정 기본 정보 (진도율, 다음 학습 활동) |

## 화면 구성

### 섹션: 브레드크럼
- "과정 소개" (과정 상세 링크) > 세션명

### 섹션: 헤더 카드
- 과정명, 세션명
- 상태 배지: 모집 중(OPEN), 진행 중(ONGOING), 종료(CLOSED)
- 기간, 강사명
- "이어 학습" 버튼 (학습 플레이어로 이동)
- 진도율 프로그레스 바 + 퍼센트
- 다음 학습 활동 안내
- 정원, 수료 기준, 총 활동 수 통계

### 섹션: 탭 바
- 홈(home) / 커리큘럼(curriculum) / Q&A(qna) / 공지(announcements) / 자료실(resources)
- 공지 탭에 긴급 공지 수 배지 표시
- URL 기반 탭 전환

## 비즈니스 규칙

- SessionWorkspaceProvider로 세션 데이터를 하위 탭에 공유
- sessionId는 URL 파라미터에서 추출
- 세션 상태(OPEN/ONGOING/CLOSED)에 따라 헤더 배지 색상 분기
