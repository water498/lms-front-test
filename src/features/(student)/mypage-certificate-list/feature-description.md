# 수료증 목록 (Student)

발급받은 수료증을 조회하고 PDF 다운로드 및 공유할 수 있는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Certificate | certificate | 수료증 발급 정보 |
| Course | course | 수료 과정 정보 |

## 화면 구성

### 섹션: 수료증 그리드
- 2열 카드 그리드 (과정명, 강사, 발급일)
- 카드 클릭 시 수료증 상세 모달 오픈

## 모달: 수료증 상세

- 수료증 미리보기 (수여자명, 과정명, 강사, 카테고리, 수강시간, 발급일, 증서번호)
- PDF 다운로드 버튼
- 공유 버튼

## 비즈니스 규칙

- 수료증은 과정 완료 시 자동 발급
- 증서번호는 고유 식별자로 외부 검증에 사용
- 발급 기관명(테넌트)이 수료증 상단에 표시됨
