# 장바구니 (Student)

[B2C only] 장바구니 페이지. 담긴 강의 목록, 쿠폰 적용, 주문 요약을 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 장바구니에 담긴 과정 정보 |
| Coupon | payment | 쿠폰 코드 |

## 화면 구성

### 섹션: 브레드크럼
- 홈 > 장바구니

### 섹션: 장바구니 헤더
- 장바구니 아이콘, 제목, 담긴 강의 수

### 섹션: 장바구니 항목 목록 (좌측)
- 과정 카드: 썸네일, 제목, 강사, 난이도
- 오프라인 과정: 장소, 개강일 추가 표시
- 수업 타입 배지 (온라인/오프라인/혼합)
- 가격, 삭제(휴지통) 버튼
- 비어있을 때: "장바구니가 비어있습니다" + "강의 탐색하기" 버튼

### 섹션: 주문 요약 사이드바 (우측 고정)
- 강의 금액 소계
- 쿠폰 할인 (적용 시)
- 총 결제 금액
- 쿠폰 코드 입력 + 적용 버튼 (OPEN10 = 10% 할인)
- "결제하기" 버튼 (checkout 페이지로 이동)

## 비즈니스 규칙

- B2C 전용 페이지 (B2B tenantType에서는 접근 불가)
- 장바구니 상태는 모듈 레벨 store로 관리
- 쿠폰 코드 "OPEN10" 입력 시 10% 할인 적용
- 쿠폰은 1회만 적용 가능 (적용 후 입력란 비활성화)
