# 세션 워크스페이스 (Student)

학습자가 수강 중인 차수의 학습 공간. 진도율, 커리큘럼, Q&A, 공지, 자료실을 탭으로 제공.

## 탭 구성

- **홈**: 긴급 공지, 차수 정보 그리드, 수료증 안내 (종료 시), 진도율 바
- **커리큘럼**: 과목/활동 목록. Phase 잠금 및 활동 잠금 UI (순서 강제 과정)
- **Q&A**: 질문 작성 및 강사 답변 확인
- **공지**: 차수별 공지사항 목록
- **자료실**: 수강생 다운로드용 문서 자료 (PDF/PPT/DOC 등). 카테고리별 그룹핑, 다운로드 버튼
