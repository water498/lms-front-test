# 과정 Q&A (Student)

과정 상세 페이지 또는 세션 워크스페이스에서 사용되는 Q&A 탭. 수강생이 질문을 작성하고 강사 답변을 확인한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| QnaItem | course | 질문 (작성자, 본문, 답변 상태, 관련 활동) |

## 화면 구성

### 섹션: Q&A 헤더
- 답변 완료 수, 미답변 수 배지 표시
- 등록된 수강생만 "질문 작성" 버튼 활성화
- 미등록 시 "등록된 수강생만 질문을 남길 수 있습니다" 안내

### 섹션: 질문 작성 폼
- 텍스트 입력, 취소/등록 버튼
- 빈 텍스트 시 등록 비활성화

### 섹션: Q&A 목록
- 질문 카드를 아코디언으로 펼치기/접기
- 작성자 아바타, 이름, 관련 활동명, 날짜
- 답변 완료/미답변 상태 배지
- 펼침 시: 강사 답변 표시 (보라색 아바타 구분)
- 미답변인 경우 "강사가 아직 답변을 작성하지 않았습니다" 안내

## 비즈니스 규칙

- canPost=false 시 질문 작성 불가 (미등록 수강생)
- sessionId가 있으면 세션 범위 Q&A로 동작
- 질문 등록 후 자동으로 해당 질문 펼침 (낙관적 업데이트)
