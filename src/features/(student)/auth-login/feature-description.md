# 로그인 (Student)

학생 로그인 페이지. B2C는 소셜 로그인(Google/카카오) + 이메일 로그인, B2B는 SSO 전용 로그인을 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 사용자 인증 정보 |

## 화면 구성

- **B2C**: Google/카카오 소셜 로그인 버튼, 이메일+비밀번호 폼, 비밀번호 찾기 링크, 회원가입 링크
- **B2B**: 테넌트명 + SSO 로그인 버튼 1개

## B2C/B2B 분기

| 항목 | B2C | B2B |
|------|-----|-----|
| 소셜 로그인 | Google, 카카오 | 없음 |
| 이메일 로그인 | 있음 | 없음 |
| SSO 로그인 | 없음 | 테넌트 SSO 버튼 |
