# AI 학습 도우미 (Student)

우측 하단 플로팅 챗봇. AI 기반 학습 질의응답 채팅 인터페이스를 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| AiChatSession | ai_chat | 채팅 세션 (컨텍스트 타입) |
| AiChatMessage | ai_chat | 채팅 메시지 (역할, 내용, 토큰, 모델) |

## 화면 구성

### 섹션: FAB 버튼
- 우측 하단 보라색 원형 버튼 (MessageCircle 아이콘)
- 클릭 시 채팅 패널 열림

### 섹션: 채팅 패널 (400x600px)
- **헤더**: AI 학습 도우미 제목, 컨텍스트 라벨(일반 질문/과정 학습/세션 학습/학습 중), 닫기 버튼
- **메시지 영역**: 사용자/AI/시스템 메시지 구분
  - 사용자: 우측 정렬, 보라색 버블
  - AI: 좌측 정렬, 흰색 버블 + Bot 아바타
  - 시스템: 중앙 정렬, 보라 배경
- **타이핑 인디케이터**: AI 응답 생성 중 점 3개 애니메이션
- **입력 영역**: 텍스트 입력 + 전송 버튼, Enter로 전송 (Shift+Enter 줄바꿈)
- "AI 응답은 참고용이며, 정확하지 않을 수 있습니다" 면책 안내

## 비즈니스 규칙

- 컨텍스트 타입에 따라 헤더 라벨 변경 (LANDING/COURSE/SESSION/LEARNING)
- 사용자 메시지 전송 후 500ms 후 Mock AI 응답 생성
- 입력 중이거나 빈 텍스트 시 전송 비활성화
- 패널 열릴 때 입력창 자동 포커스
- 새 메시지 시 자동 스크롤
