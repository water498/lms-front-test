# 과정 리뷰 (Student)

과정 상세 페이지의 "리뷰" 탭. 과정 리뷰 목록과 별점 분포를 표시하며, 과정 완료 시 리뷰 작성이 가능하다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseReview | course | 과정 리뷰 (별점, 본문, 작성자) |
| InstructorProfile | user | 강사 프로필 (리뷰 2단계 플로우용) |

## 화면 구성

### 섹션: 리뷰 헤더
- "과정 리뷰" 제목
- 과정 완료(canWrite) 시 "리뷰 작성" 버튼, 미완료 시 안내 메시지

### 섹션: 별점 요약
- 평균 별점 (대형 숫자), 별 아이콘, 총 리뷰 수
- 5~1점별 분포 막대 그래프 (StarBar)

### 섹션: 리뷰 카드 목록
- 작성자 아바타, 이름, 별점, 날짜, 리뷰 본문

## 모달

### 과정 리뷰 작성 (2단계 플로우)
- **1단계 (course)**: 과정 별점 + 텍스트 리뷰 입력. 강사가 있으면 "다음: 강사 리뷰" 버튼
- **2단계 (instructor)**: 강사 별점 + 텍스트 리뷰 입력. "건너뛰기" 또는 "리뷰 등록"
- 별점 0 또는 빈 텍스트 시 등록 비활성화
- 강사가 없으면 1단계에서 바로 완료

## 비즈니스 규칙

- 과정을 완료한 수강생만 리뷰 작성 가능
- 과정 리뷰 작성 후 강사 리뷰로 자연스럽게 이어지는 플로우
- 강사 리뷰는 건너뛰기 가능
- 리뷰 등록 시 즉시 목록에 반영 (낙관적 업데이트)
