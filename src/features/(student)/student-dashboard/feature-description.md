# 학생 대시보드 (Student)

학생 메인 홈 화면. 수강 중인 과정, 추천 강의, 인기 강의, 카테고리별 추천, 학습 현황, 공지/이벤트를 한 화면에 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 정보 (카드 표시용) |
| Announcement | announcement | 공지/이벤트 |

## 화면 구성

### 섹션: 네비게이션 바
- OpenKnock 로고, 알림 벨, 장바구니 아이콘(담긴 수 표시), 프로필 아바타

### 섹션: ContextPanel
- 현재 테넌트 컨텍스트 표시 (개발용 B2C/B2B 전환 포함)

### 섹션: 필수 수강 과정 [B2B only]
- `mandatoryCourses` feature flag 활성 시만 노출
- 필수 지정된 과정 목록을 가로 스크롤로 표시

### 섹션: 내 부서 대상 과정 [B2B only]
- `orgStructure` feature flag 활성 시만 노출
- 소속 부서 대상 과정 목록 표시

### 섹션: 히어로 배너
- 프로모션/이벤트 배너 영역

### 섹션: 이어서 학습하기
- 진행 중인 과정 카드 (진도율 표시), 없으면 숨김

### 섹션: 추천 강의
- 추천 과정 카드 목록 (장바구니 담기, 위시리스트 토글 가능)

### 섹션: 지금 인기있는 강의
- 인기 과정 카드 목록 (장바구니 담기, 위시리스트 토글 가능)

### 섹션: 카테고리별 추천
- 카테고리 탭별 과정 추천

### 섹션: 내 학습 현황
- 학습 통계 위젯

### 섹션: 공지/이벤트
- 공지사항 및 이벤트 그리드

### 섹션: AI 학습 도우미
- 우측 하단 플로팅 챗 버튼 (AiChatFeature 임베드)

## 비즈니스 규칙

- 장바구니·위시리스트 상태는 모듈 레벨 store로 관리 (페이지 간 공유)
- B2B 전용 섹션(필수 수강, 부서 대상)은 TenantContext feature flag로 분기

## B2C/B2B 분기

| 항목 | B2C | B2B |
|------|-----|-----|
| 필수 수강 과정 섹션 | 숨김 | `mandatoryCourses` 활성 시 표시 |
| 내 부서 대상 과정 섹션 | 숨김 | `orgStructure` 활성 시 표시 |
| 장바구니/위시리스트 | 표시 | feature flag에 따름 |
