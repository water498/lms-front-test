# 마이페이지 레이아웃 (Student)

마이페이지 레이아웃 셸. 좌측 사이드바에 프로필 요약과 탭 네비게이션, 우측에 탭 콘텐츠를 표시한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 사용자 프로필 (이름, 이메일) |
| Course | course | 수강 과정 수 집계용 |

## 화면 구성

### 섹션: 네비게이션 바
- 로고, 검색, 알림, 장바구니(B2C), 프로필/로그아웃

### 섹션: 비로그인 가드 모달
- 미로그인 시 전체 화면 모달로 로그인/회원가입 유도
- "나중에 하기"로 대시보드 이동 가능

### 섹션: 프로필 카드 (좌측 사이드바)
- 아바타(이니셜), 이름, 이메일
- 통계: 강의 수, 수료증 수, 위시리스트 수

### 섹션: 탭 네비게이션 (좌측 사이드바)
- 내 학습(learning), 수료증(certificates), 주문 내역(orders) [B2C only], 내 리뷰(reviews), 알림(notifications), 내 정보(profile)
- URL 기반 탭 전환

### 섹션: 강사 신청 버튼
- 학생 역할만 보유 시 "강사로 활동하기" 버튼 표시
- 이미 INSTRUCTOR 역할이면 숨김

### 섹션: 로그아웃 버튼

## 모달

### 강사 신청 모달
- 전문 분야 (필수), 강의 계획 (필수), 관련 경력 (선택) 입력
- 필수 항목 미입력 시 신청 비활성화
- 신청 후 "접수 완료" 메시지 (영업일 3~5일 내 처리 안내)

## 비즈니스 규칙

- 로그인 상태 확인 후 미로그인 시 가드 모달 표시
- 주문 내역 탭은 `payments` feature flag 활성 시만 표시

## B2C/B2B 분기

| 항목 | B2C | B2B |
|------|-----|-----|
| 장바구니 아이콘 | `cart` 활성 시 표시 | 숨김 |
| 주문 내역 탭 | `payments` 활성 시 표시 | 숨김 |
