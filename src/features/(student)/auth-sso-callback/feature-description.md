# SSO 콜백 (Student)

SSO 인증 완료 후 콜백 처리 페이지. 로딩 스피너 표시 후 자동 로그인 또는 오류 안내를 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | SSO 인증 사용자 |

## 화면 구성

- **로딩 상태**: 스피너 + "로그인 처리 중..." 안내
- **오류 상태**: 오류 아이콘 + "로그인에 실패했습니다" + 로그인으로 돌아가기 버튼

## 비즈니스 규칙

- URL 파라미터 error=true 시 오류 상태 표시
- 정상 시 1초 후 자동 로그인 + 대시보드 리다이렉트
