# 세션 홈 (Student)

세션 워크스페이스의 "홈" 탭. 긴급 공지, 세션 기본 정보, 수료증 안내를 표시한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Session | course | 세션 정보 (기간, 정원, 수료 기준) |
| SessionAnnouncement | announcement | 세션 공지 (긴급/일반) |

## 화면 구성

### 섹션: 긴급 공지
- URGENT 타입 공지를 상단에 경고 스타일로 표시
- 없으면 숨김

### 섹션: 세션 정보 그리드
- 개강일, 종강일, 수강 인원(현재/정원), 수료 기준 (2x2 그리드)

### 섹션: 수료증 안내 [종료된 세션]
- 세션 종료(isClosed) 시 수료증 발급 배너 표시
- "수료증 보기" 버튼 (마이페이지 수료증 탭으로 이동)

## 비즈니스 규칙

- session-layout의 SessionWorkspaceProvider에서 데이터 전달받음
- 세션 종료 상태에서만 수료증 섹션 표시
