# 알림 목록 (Student)

수신한 알림을 전체/안 읽음 필터로 조회하고 읽음 처리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Notification | notification | 알림 (유형, 제목, 본문, 읽음 여부, 링크) |

## 화면 구성

### 섹션: 필터 + 액션
- 전체 / 안 읽음 필터 토글 (안 읽음 개수 뱃지)
- 모두 읽음 처리 버튼

### 섹션: 알림 리스트
- 유형 아이콘 + 유형 라벨 뱃지 + 제목 + 시간
- 미읽음: 보라색 강조 배경 + 인디케이터 dot
- 클릭 시 읽음 처리 + linkUrl이 있으면 해당 페이지로 이동
- 페이지네이션: "더 보기" 버튼 (10건 단위 로드)

### 빈 상태
- 알림 없음 / 안 읽음 없음 각각 빈 상태 메시지 표시

## 비즈니스 규칙

- 알림 클릭 시 자동 읽음 처리
- linkUrl 존재 시 해당 페이지로 라우팅
- 모두 읽음 버튼은 미읽음 알림이 있을 때만 노출
