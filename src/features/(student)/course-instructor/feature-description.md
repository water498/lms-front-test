# 과정 강사 (Student)

과정 상세 페이지의 "강사" 탭. 강사 프로필과 강사 리뷰를 표시하며, 과정 완료 시 리뷰 작성이 가능하다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorProfile | user | 강사 프로필 (이름, 소속, 전문분야, 소개) |
| InstructorReview | course | 강사 리뷰 (별점, 본문, 작성자) |

## 화면 구성

### 섹션: 강사 소개
- 아바타(이니셜), 이름, 헤드라인, 소속 회사
- 전문분야 태그 목록
- 자기소개 텍스트
- "프로필 상세보기" 링크 (모달 열기)

### 섹션: 강사 리뷰
- 평균 별점, 리뷰 수 표시
- 리뷰 카드 목록 (작성자, 별점, 내용, 날짜)
- 과정 완료(isCompleted) 시 "강사 리뷰 작성" 버튼 활성화
- 미완료 시 "과정 완료 후 리뷰를 작성할 수 있습니다" 안내

## 모달

### 강사 리뷰 작성
- 5점 별점 선택 (호버 시 라벨 표시: 별로예요~최고예요!)
- 텍스트 리뷰 입력
- 별점 0 또는 빈 텍스트 시 등록 버튼 비활성화

## 비즈니스 규칙

- 과정을 완료한 수강생만 강사 리뷰 작성 가능
- 리뷰 등록 후 즉시 목록에 반영 (낙관적 업데이트)
