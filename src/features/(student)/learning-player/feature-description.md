# 학습 플레이어 (Student)

풀스크린 학습 플레이어. 비디오 재생, 퀴즈/과제 플레이스홀더, 커리큘럼 사이드바를 제공한다.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 기본 정보 |
| CourseSubject | course | 과정 섹션 |
| CourseActivity | course | 활동 (VIDEO, QUIZ, ASSIGNMENT) |

## 화면 구성

### 섹션: 헤더 바
- 뒤로가기 (강의 정보 페이지), 과정 제목
- 진도율 프로그레스 바 (완료/전체 활동 수)
- 닫기(X) 버튼 (대시보드로 이동)

### 섹션: 콘텐츠 영역 (좌측)
- **VIDEO**: Video.js 플레이어 (시청 구간 추적, 되감기 제한 모드 지원)
- **QUIZ**: 퀴즈 플레이스홀더 (문제 수 표시, "퀴즈 시작" 버튼)
- **ASSIGNMENT**: 과제 플레이스홀더 (항목 수 표시, "과제 제출" 버튼)

### 섹션: 활동 정보
- 섹션명, 활동 제목
- 완료 상태 표시 (체크 아이콘)
- QUIZ: 80% 이상 정답 시 완료 안내
- ASSIGNMENT: 제출 시 강사 피드백 안내

### 섹션: 이전/다음 네비게이션
- 이전/다음 활동 링크 (제목 표시)
- 마지막 활동이면 "강의 완료!" 표시

### 섹션: 커리큘럼 사이드바 (우측, 데스크톱)
- 섹션별 활동 목록
- 완료: 초록 체크, 현재: 보라 점, 잠김: 자물쇠, 미완료: 타입별 아이콘
- 현재 활동은 좌측 보라색 보더 강조
- 클릭 시 해당 활동으로 이동 (접근 가능한 경우만)

## 비즈니스 규칙

- VIDEO: 시청 구간(watchedRanges) 추적, 80% 이상 시청 시 자동 완료 처리
- VIDEO: 끝까지 재생(onEnded) 시에도 완료 처리
- 순차 학습 강제: 이전 활동 완료 후 다음 활동 접근 가능 (잠금 아이콘 표시)
- 완료 상태는 모듈 레벨 변수로 관리 (페이지 전환 간 유지)
- QUIZ/ASSIGNMENT는 데모 모드에서 즉시 완료 처리
