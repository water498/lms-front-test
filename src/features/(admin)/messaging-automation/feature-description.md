# 메시징 자동화 (Admin)

SMS, 알림톡(카카오), 이메일 채널별 메시지 발송 이력, 템플릿, 자동화 규칙, 채널 설정을 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| MessageTemplate | messaging | 메시지 템플릿 |
| MessageEventRule | messaging | 이벤트 기반 자동 발송 규칙 |
| MessageLog | messaging | 발송 이력 |
| CreditPool | credit | 메시징 크레딧 잔액 |

## 화면 구성

- **크레딧 잔액 바**: 채널별 건당 크레딧 비용, 예상 발송 가능 건수, 잔액 부족 경고
- **서브탭 4개**:
  - 발송 이력: 발송된 메시지 목록 (상태, 수신자, 시간)
  - 템플릿: 채널별 메시지 템플릿 관리 (생성/편집)
  - 자동화: 이벤트 기반 자동 발송 규칙 (수강 신청 시, 수료 시 등)
  - 설정: 채널별 발신 설정

## 모달

### 메시지 발송
- 수신 대상 선택, 템플릿 선택, 내용 편집 후 발송

### 템플릿 생성/편집
- 채널, 제목, 내용(변수 치환 지원) 설정

### 자동화 규칙 생성/편집
- 트리거 이벤트, 채널, 템플릿, 활성화 여부 설정

## 비즈니스 규칙

- 크레딧 부족 시 발송 불가
- 채널별 건당 크레딧 비용이 다름 (SMS, 알림톡, 이메일)
