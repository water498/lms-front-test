# 과정 상세 레이아웃 (Admin)

개별 과정의 상세 페이지를 탭 내비게이션으로 구성하는 레이아웃 셸.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 템플릿 |

## 화면 구성

- 브레드크럼: "과정 관리" 링크 > 현재 과정명
- 탭 내비게이션 6개: 과정 정보, 커리큘럼, 차수 관리, 리뷰, 수강생, 오프라인
- 탭 콘텐츠는 children으로 렌더링 (각 탭은 독립 feature)
- CourseDetailProvider 컨텍스트로 courseId 공유

## 비즈니스 규칙

- 존재하지 않는 courseId 접근 시 "과정을 찾을 수 없습니다" 표시
