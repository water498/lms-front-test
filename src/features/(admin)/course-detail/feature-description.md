# 과정 상세 (Admin)

관리자가 과정(Course)의 상세 정보를 관리하는 페이지.

## 탭 구성

- **과정 정보**: 과정 기본 정보 (제목, 설명, 카테고리, 모드 등)
- **커리큘럼**: PRE/LEARNING/POST 3단계 Phase 기반 커리큘럼 편집. 과목/활동 추가·삭제·순서변경 (DnD)
- **차수 관리**: 차수(CourseSession) 목록 및 관리
- **리뷰**: 수강생 리뷰 목록

## 커리큘럼 탭 — 순서 강제 토글

- **활동 순서 강제** 토글: `Course.isSequential` 제어
- Phase 순서(PRE→LEARNING→POST)는 항상 강제됨 (토글과 무관)
- 토글 ON 시: Phase 내에서도 과목·활동을 순서대로 완료해야 다음 항목 접근 가능
- 법정교육/규제 교육용. 기본값 OFF
- 진행 중 차수가 있으면 커리큘럼 수정 불가 (경고 배너 표시)

## 커리큘럼 탭 — 활동 타입

- **VIDEO**: 영상 콘텐츠 (미디어 라이브러리 연결)
- **SCORM**: SCORM 패키지 (미디어 라이브러리 연결)
- **QUIZ**: 시험 (시험 템플릿 연결)
- **ASSIGNMENT**: 과제 (과제 템플릿 연결, 강사 필요)
- **SURVEY**: 설문
- **OFFLINE**: 오프라인 강의/실습 — 출석 시 자동 수강 완료 처리

## 커리큘럼 탭 — 오프라인 회차 잠금 (requiredDayNum)

- 과목(Subject)에 `requiredDayNum` 설정 가능 (OFFLINE/BLENDED 모드만)
- 해당 회차 출석 완료 시에만 과목 접근 가능
- 과목 헤더에 잠금 뱃지로 시각적 표시 (예: "2회차 출석 필요")
- 미설정 시 출석 제한 없이 접근 가능

## 모달: 과목 편집 (EditSubjectModal)

- 과목명 수정
- Phase(단계) 변경: PRE / LEARNING / POST
- 오프라인 회차 출석 요구 설정 (OFFLINE/BLENDED 모드일 때만 표시)

## 모달: 활동 편집 (EditActivityModal)

- 활동명 수정
- 활동 타입 표시 (읽기 전용 뱃지)
- QUIZ 타입: 합격 필수(수료 조건) 체크박스
- VIDEO 타입: 영상 길이 정보 표시 (읽기 전용)
- OFFLINE 타입: 오프라인 강의 안내 표시

## 모달: 활동 추가 (AddActivityModal)

- 미디어/시험/과제/오프라인 4개 탭
- 미디어 탭: 검색 + VIDEO/SCORM 필터, 미디어 라이브러리에서 선택
- 시험 탭: 등록된 시험 템플릿에서 선택
- 과제 탭: 등록된 과제 템플릿에서 선택 (강사 없는 과정은 비활성)
- 오프라인 탭: 제목만 입력하여 오프라인 강의 등록
