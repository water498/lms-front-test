# 과정 상세 (Admin)

관리자가 과정(Course)의 상세 정보를 관리하는 페이지.

## 탭 구성

- **과정 정보**: 과정 기본 정보 (제목, 설명, 카테고리, 모드 등)
- **커리큘럼**: PRE/LEARNING/POST 3단계 Phase 기반 커리큘럼 편집. 과목/활동 추가·삭제·순서변경 (DnD)
- **차수 관리**: 차수(CourseSession) 목록 및 관리
- **리뷰**: 수강생 리뷰 목록

## 커리큘럼 탭 — 순서 강제 토글

- **활동 순서 강제** 토글: `Course.isSequential` 제어
- Phase 순서(PRE→LEARNING→POST)는 항상 강제됨 (토글과 무관)
- 토글 ON 시: Phase 내에서도 과목·활동을 순서대로 완료해야 다음 항목 접근 가능
- 법정교육/규제 교육용. 기본값 OFF
- 진행 중 차수가 있으면 커리큘럼 수정 불가 (경고 배너 표시)
