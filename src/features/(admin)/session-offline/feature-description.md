# 차수 오프라인 관리 (Admin)

오프라인/혼합 과정 차수의 회차(OfflineSession)별 일정과 출결을 관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OfflineSession | offline_course | 오프라인 회차 (날짜, 시간, 장소, 강사, 정원, 상태) |
| OfflineAttendance | offline_course | 출결 기록 (출석/지각/결석) |

## 화면 구성

- "회차 추가" 버튼
- 회차 테이블: 회차 번호, 날짜/시간, 장소, 강사(주+보조), 정원, 출석률, 상태(예정/완료/취소), 액션
- 액션 버튼: QR 코드 생성, 출결 관리

## 모달

### QR 코드 (QrModal)
- 해당 회차의 출석 체크용 QR 코드 표시

### 출결 관리 (AttendanceModal)
- 수강생별 출석/지각/결석 상태 관리

### 회차 추가 (CreateOfflineSessionModal)
- 새 오프라인 회차 생성 (날짜, 시간, 장소, 강사, 정원 입력)

## 비즈니스 규칙

- 예정(SCHEDULED) 상태 회차는 출석률 미표시
- 오프라인/혼합 모드 과정에서만 탭 노출
