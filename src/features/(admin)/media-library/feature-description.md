# 미디어 라이브러리 (Admin)

과정 콘텐츠에 사용할 미디어 파일을 업로드하고 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| MediaAsset | media | 미디어 파일 (동영상, PDF, SCORM, 이미지) |
| MediaFolder | media | 미디어 폴더 (계층 구조) |

## 화면 구성

- **좌측 폴더 트리**: 전체 / 미분류 / 사용자 정의 폴더. 폴더 추가, 이름 변경, 삭제 지원
- **뷰 모드 전환**: 그리드 / 리스트
- 유형 필터: 전체 / 동영상 / PDF / SCORM / 이미지
- 상태 필터: 전체 / 활성 / 처리 중 / 오류
- 테이블/그리드 표시: 파일명, 유형, 크기, 상태(대기/검증 중/처리 중/활성/오류), 연결된 차수, 업로드일
- 파일 삭제, 미리보기 기능

## 모달

### 파일 업로드
- 드래그앤드롭 또는 클릭으로 파일 선택
- 폴더 지정 가능

## 비즈니스 규칙

- 업로드 상태: PENDING > VALIDATING > PROCESSING > ACTIVE (또는 ERROR)
- 차수에 연결된 파일은 삭제 시 경고 표시
- 폴더 삭제 시 하위 폴더도 함께 삭제
