# 사용자 수강 이력 (Admin)

사용자의 전체 수강 이력을 과정/차수별로 조회하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Enrollment | enrollment | 수강 등록 (과정, 차수, 진행률, 상태) |
| CertificateIssuance | certificate | 수료증 발급 여부 |

## 화면 구성

- 수강 이력 테이블: 과정명, 차수명, 진행률 바, 상태(진행중/완료/수료불가/취소/만료), 수료증 발급 여부
- 이력 없으면 빈 상태 안내

## 비즈니스 규칙

- 상태별 색상 구분: 진행중(파란), 완료(초록), 수료불가(빨강), 취소(회색), 만료(주황)
