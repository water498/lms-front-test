# 접속 이력 (Admin)

전체 유저 또는 특정 유저의 로그인/로그아웃 접속 이력을 조회하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| UserAccessLog | user | 접속 이력 (이벤트 유형, IP, 브라우저, 접속단) |

## 화면 구성

- 필터: 이벤트 유형(로그인/로그아웃/세션만료/자동로그인), 접속단(사용자단/관리자단), 날짜 범위, 회원명 검색
- 필터 초기화 버튼
- 결과 건수 표시
- 테이블 컬럼: 날짜시간, 회원명(전체 뷰), 이벤트 유형, 접속단, IP, 브라우저/OS
- 특정 유저 컨텍스트에서는 회원명 컬럼 및 회원명 검색 숨김

## 비즈니스 규칙

- userId prop 전달 시 해당 유저의 이력만 표시 (유저 상세 탭에서 사용)
- 최신 이력이 상단에 표시 (내림차순 정렬)
