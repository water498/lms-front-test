# 사용자 활동 로그 (Admin)

사용자의 학습 활동 이벤트를 시간순으로 조회하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| ActivityLog | progress | 학습 활동 로그 (행위, 대상, 결과) |

## 화면 구성

- 타임라인 목록: 타임스탬프 + 행위 뱃지 + 상세 정보
- 행위 유형: 수강 신청, 레슨 시작, 레슨 완료, 강의 시청, 시험 제출, 과제 제출, 설문 응답, 수료, 수료증 발급
- 상세: 대상 콘텐츠 제목, 점수, 합격/불합격 등
- 활동 없으면 빈 상태 안내

## 비즈니스 규칙

- 행위별 색상 구분 (수강 신청=파란, 완료/수료=초록, 시험=주황 등)
