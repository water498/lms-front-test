# 차수 상세 (Admin)

관리자가 차수(CourseSession)의 운영 현황을 관리하는 페이지.

## 탭 구성

- **대시보드**: 진도율 분포, 수강생 통계
- **차수 정보**: 일정, 정원, 강사, 수료 기준 등 메타 정보
- **수강생**: 등록된 수강생 목록 및 진도율
- **평가 설정**: 사전/사후 시험·과제·설문 템플릿 연결
- **학습 이력**: 활동별 완료 기록 (ActivityCompletion)
- **자료실**: 수강생 다운로드용 문서 자료 관리 (PDF/PPT/DOC 등)
- **오프라인 관리**: OFFLINE/BLENDED 모드일 때만 표시. 출결 관리
- **대기자**: COHORT 타입일 때만 표시. 수강 대기자 승인/거절

## 자료실 탭

- 차수(CourseSession) 레벨로 자료 관리
- 카테고리별 그룹핑 (강의자료, 참고문헌, 서식 등)
- 자료 등록/수정/삭제, 공개/비공개 토글
- 챕터(CourseSubject) 연결 가능
- 관리자 + 강사 모두 관리 가능 (강사는 본인 담당 차수 스코프)
