# 차수 자료실 (Admin)

차수에 첨부된 문서 자료를 등록/관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionResource | media | 차수 자료 (파일, 분류, 공개 여부) |

## 화면 구성

- 헤더: "자료실" 제목 + 설명 + "자료 등록" 버튼
- 분류(카테고리)별 접기/펼치기 그룹
  - 분류 헤더: 카테고리명, 건수
  - 자료 행: 파일 타입 아이콘, 제목, 비공개 뱃지, 연결 주제(Subject) 태그, 설명, 파일명/크기/업로더
  - 호버 액션: 공개/비공개 전환, 편집, 삭제
- 자료 없을 때 빈 상태 + "첫 자료 등록하기" 버튼

## 모달

### 자료 등록 (AddResourceModal)
- 파일 선택 (PDF, PPT, DOC, XLS, HWP, ZIP 지원)
- 자료명 (파일명에서 자동 채움)
- 분류: 프리셋(강의자료, 참고문헌, 서식, 기타) 또는 직접 입력
- 설명 (선택)
- 등록 시 공개 상태로 생성

## 비즈니스 규칙

- 비공개 자료는 수강생에게 표시되지 않음
- 자료는 특정 주제(Subject)에 연결하거나 차수 전체 자료로 등록 가능
