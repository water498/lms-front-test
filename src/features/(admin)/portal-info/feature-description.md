# 포털 정보 (Admin)

학습자 포털의 기본 정보(포털명, 로고, 파비콘, URL)를 설정하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgSettings | org | 조직 설정 (포털명, 서브도메인, 브랜드 등) |

## 화면 구성

- 포털명 입력 (브라우저 탭, 이메일 발신자명, 로그인 화면에 표시)
- 로고 업로드 (PNG, SVG 권장, 최소 200x80px)
- 파비콘 업로드 (ICO, PNG 권장, 32x32 또는 64x64px)
- 포털 URL 표시 (읽기 전용, subdomain.lms.io 형식)
- 저장 버튼

## 비즈니스 규칙

- 포털 URL 변경은 플랫폼 관리자에게 문의 필요
