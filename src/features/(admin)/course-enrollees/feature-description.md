# 수강생 (Admin)

과정에 등록된 수강생 목록을 차수별로 필터링하고 진도율을 확인하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseEnrollee | course | 수강생 정보 (진도율, 등록일, 차수) |
| CourseSession | course | 차수 (필터 드롭다운용) |
| User | user | 학습자 상세 (UserDrawer) |

## 화면 구성

- 차수별 필터 드롭다운 (전체 / 각 차수명)
- 필터된 수강생 수 표시
- 수강생 테이블: 이름(클릭 시 UserDrawer), 차수명, 진도율 바+%, 등록일
- UserDrawer: 우측 슬라이드 패널로 학습자 상세 정보 표시

## 비즈니스 규칙

- 진도율 바 너비 = progress%
- 이름 클릭 시 UserDrawer 열림 (페이지 이동 아님)
