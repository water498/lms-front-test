# 리뷰 (Admin)

과정에 대한 수강생 리뷰를 조회하고 공개/숨김을 관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseReview | course | 수강 리뷰 (별점 1~5, 본문, 공개 여부) |

## 화면 구성

- 요약 카드: 평균 별점(공개 리뷰 기준), 전체/공개/숨김 수
- 리뷰 테이블: 학습자 아바타+이름, 별점, 내용(truncate), 작성일, 공개/숨김 토글
- 숨겨진 리뷰는 회색 처리
- 빈 상태: "아직 리뷰가 없습니다"

## 비즈니스 규칙

- 평균 별점은 공개(visible=true) 리뷰만 기준
- 숨김 처리해도 삭제되지 않음 (soft hide)
