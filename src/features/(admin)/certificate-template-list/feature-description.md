# 수료증 템플릿 (Admin)

수료증 디자인 템플릿을 생성하고 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CertificateTemplate | certificate | 수료증 템플릿 (HTML 템플릿, 배경 이미지) |

## 화면 구성

- 그리드 형태로 템플릿 카드 표시 (iframe 기반 실시간 미리보기)
- 각 카드: 템플릿명, 생성일, 편집/수동 발급 버튼
- "+ 새 템플릿" 버튼

## 모달

### 템플릿 생성/편집
- HTML 에디터로 수료증 디자인 편집
- 배경 이미지 설정
- 변수 치환 지원 (학습자명, 과정명, 발급일 등)

### 수동 발급
- 과정, 학습자 선택 후 즉시 발급

## 비즈니스 규칙

- 템플릿은 과정 정보(course-info)에서 연결하여 사용
- HTML 템플릿 내 변수는 발급 시 실제 데이터로 치환
