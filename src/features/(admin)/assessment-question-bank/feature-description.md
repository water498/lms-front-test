# 문항 은행 (Admin)

시험/설문 문항을 그룹별로 관리하는 문항 은행 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| QuestionGroup | assessment/question | 문항 그룹 (시험용/설문용 구분) |
| Question | assessment/question | 개별 문항 (유형, 보기, 태그) |

## 화면 구성

- **종류 탭**: 시험(EXAM) / 설문(SURVEY) 전환
- **좌측 그룹 목록**: 그룹 선택, 그룹 추가/편집/보관/삭제 (컨텍스트 메뉴)
- **우측 문항 편집**: 선택된 그룹의 문항 목록
  - 문항 추가, 드래그앤드롭 순서 변경
  - 유형 선택: 시험(객관식 단일/복수, O/X, 주관식), 설문(리커트, 객관식 단일/복수, 자유 서술)
  - 문항 텍스트, 보기 편집, 정답 지정, 태그 관리
  - 리커트 척도 단계(3~7) 설정 (설문 전용)

## 모달

### 문항 그룹 생성/편집
- 필드: 그룹 이름(필수), 설명

## 비즈니스 규칙

- 그룹은 EXAM 또는 SURVEY 종류로 구분 (시험 에디터에서 EXAM 그룹만, 설문 에디터에서 SURVEY 그룹만 선택 가능)
- 보관된 그룹은 목록에서 숨김 처리
- 문항 삭제 시 해당 문항이 시험/설문에서 출제 대상에서 제외
