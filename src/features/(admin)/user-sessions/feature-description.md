# 사용자 접속 세션 (Admin)

사용자의 로그인 세션(기기)을 조회하고 강제 종료하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| UserSession | user | 로그인 세션 (기기, IP, 만료, 종료 사유) |

## 화면 구성

### 섹션: 활성 세션
- 기기 아이콘 (PC/모바일/태블릿 자동 판별)
- 기기명, User-Agent, IP, 마지막 활동일, 만료일
- "강제 종료" 버튼 (ADMIN_REVOKE로 세션 종료)

### 섹션: 종료된 세션 (접기/펼치기)
- 종료 사유 뱃지: 로그아웃, 재로그인, 관리자 종료, 만료
- 기기명, IP, 종료일

## 비즈니스 규칙

- 관리자가 강제 종료 시 사유는 ADMIN_REVOKE로 기록
- 세션 이력이 없으면 빈 상태 표시
