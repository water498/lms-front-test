# 배너 / 팝업 관리 (Admin)

학습자 포털 메인에 노출할 배너와 팝업을 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| PortalBanner | portal | 포털 배너/팝업 (제목, 이미지, 기간, 활성 여부) |

## 화면 구성

- 탭 전환: 배너 / 팝업
- 각 항목 카드: 이미지 썸네일, 제목, 노출 기간
- 활성화 토글 (노출/숨김)
- 편집 / 삭제 버튼
- "+ 추가" 버튼

## 비즈니스 규칙

- 배너와 팝업은 별도 목록으로 관리
- 삭제 시 확인 다이얼로그 표시
