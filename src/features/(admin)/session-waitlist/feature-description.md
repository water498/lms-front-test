# 차수 대기자 (Admin)

정규(COHORT) 차수의 대기 신청자를 관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| WaitApply | enrollment | 대기 신청 (사용자, 신청일, 상태) |

## 화면 구성

- 헤더: "대기자" + 대기 중 인원 뱃지
- 대기자 테이블: 순번, 이름, 신청일, 상태(대기 중/등록됨/취소됨)
- 대기 중 상태에서 액션: 수락 버튼(등록됨으로 전환), 취소 버튼(취소됨으로 전환)
- 대기자 없으면 빈 상태 안내

## 비즈니스 규칙

- COHORT 유형 차수에서만 탭 노출
- 수락 시 수강 등록으로 전환
