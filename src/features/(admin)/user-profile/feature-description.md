# 사용자 프로필 (Admin)

사용자의 계정 정보, 학습 현황, 조직 이동 이력을 조회하고 역할 변경/계정 관리를 수행하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 사용자 (이름, 이메일, 역할, 상태, 인증 방식) |
| OrgTeam | org | 소속 부서 |
| OrgPosition | org | 직급 |
| OrgSite | org | 사업장 |
| InstructorProfile | instructor | 강사 프로필 (강사 역할 사용자만) |

## 화면 구성

### 섹션: 프로필 헤더
- 아바타, 이름, 역할 뱃지, 상태 뱃지, 이메일, 소속 부서
- "이 유저로 보기" 버튼 (LEARNER만) — 학생 화면으로 임퍼소네이션
- "역할 변경" 버튼 (SUPER_ADMIN 제외)

### 섹션: 계정 정보
- 이메일, 역할, 가입일, 마지막 로그인, 인증 방식 (LOCAL/SOCIAL/SSO)

### 섹션: 학습 현황
- 수강/완료 과정 수, 수료증 수, 사업장/부서/직급

### 섹션: 계정 관리 (ACTIVE + 비 SUPER_ADMIN)
- 비밀번호 초기화 버튼
- 계정 비활성화 버튼

### 섹션: 강사 프로필 (INSTRUCTOR만)
- 한 줄 소개, 전문 분야, 강사 유형(내부/외부), 웹사이트, 소개, 경력
- 공개/비공개 토글

### 섹션: 조직 이동 이력
- 타임라인: 날짜, 사업장/부서/직급 변경 전후, 비고

## 모달

### 역할 변경
- 수강생/강사/관리자 중 선택 → 변경 적용
- SUPER_ADMIN은 변경 대상 아님

## 비즈니스 규칙

- SSO 사용자는 IdP 관리 필드(이름, 이메일)가 읽기 전용
- 임퍼소네이션은 LEARNER 역할에만 허용
