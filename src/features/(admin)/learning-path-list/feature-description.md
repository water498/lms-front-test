# 학습 경로 (Admin)

여러 과정을 묶어 하나의 학습 여정으로 제공하는 학습 경로(LearningPath) 관리 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| LearningPath | course | 학습 경로 (제목, 설명, 가격, 상태) |
| LearningPathCourse | course | 학습 경로-과정 연결 (순서 포함) |
| Course | course | 포함 과정 |

## 화면 구성

- 테이블 컬럼: 학습 경로명, 포함 코스 수, 상태(게시됨/임시저장), 가격, 생성일, 액션
- 액션: 편집, 삭제
- "+ 학습 경로 추가" 버튼

## 모달

### 학습 경로 만들기 / 수정
- 필드: 제목(필수), 설명, 가격(B2C용, 미입력 시 미설정)
- 코스 선택: 체크박스로 다중 선택
- 코스 순서: 선택된 코스를 위/아래 버튼으로 순서 변경
- 상태: 임시저장 / 게시됨 라디오 선택

## 비즈니스 규칙

- 제목 미입력 시 저장 불가
- 코스 순서는 수동 지정 (order 필드)
