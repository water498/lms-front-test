# 플랫폼 공지 (platform-admin)

전체 테넌트 어드민 대상 공지사항을 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| PlatformAnnouncement | - | 플랫폼 공지 |

## 화면 구성

### 섹션: 통계 칩
- 전체, 게시 중, 비게시 건수 표시

### 섹션: 공지 테이블
- 유형(점검/업데이트/긴급/일반), 제목, 상태(게시 중/비게시), 일시
- 행 클릭 시 상세 패널 토글 (제목, 유형, 작성자, 상태, 본문)
- 행별 액션: 편집, 삭제, 게시/내리기 토글

### 섹션: 상세 패널
- 유형 배지, 제목, 작성자, 상태, 게시일, 본문(pre-wrap)

## 모달

### 새 공지 작성 / 편집 (ComposeModal)
- 공지 유형 선택(MAINTENANCE/UPDATE/URGENT/GENERAL)
- 제목, 내용(textarea) 입력
- 저장/취소 버튼

## 비즈니스 규칙

- 공지 상태: PUBLISHED(게시 중) / UNPUBLISHED(비게시) 토글 가능
- 삭제 시 목록에서 즉시 제거
- 편집 시 기존 데이터로 모달 프리필
