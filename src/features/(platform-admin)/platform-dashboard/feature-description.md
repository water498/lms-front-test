# 플랫폼 대시보드 (platform-admin)

전체 테넌트 현황, 학습자 추이, 스토리지, 운영 이슈를 종합 요약하는 메인 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Tenant | - | 기업(테넌트) |

## 화면 구성

### 섹션: Control Plane 헬스
- API 서버, DB Cluster, 스토리지 상태 표시 (정상/이상)
- 마지막 동기화 시각

### 섹션: 핵심 지표 카드 (3열)
- 테넌트: 총 개수, B2B/B2C 구분, 상태별(ACTIVE/TRIAL/SUSPENDED) 배지
- 전체 학습자: 총 인원, 전월 대비 증감률
- 스토리지: 총 사용량/할당량, 사용률 프로그레스 바

### 섹션: 운영 현황
- 인프라 이상(error), SSO 미설정(warning), 만료 임박(warning), 온보딩 대기(info), 정지 중(info)
- 각 항목 클릭 시 해당 테넌트 상세로 이동

### 섹션: 차트 (2열)
- 월별 학습자 추이 (SVG 라인 차트, 최근 6개월)
- 기업별 스토리지 사용률 (수평 막대 차트)

### 섹션: 테넌트 현황 목록
- 테넌트명, 서브도메인, 유형(B2B/B2C), 상태, 사용자 수, 초대 미수락, SSO 꺼짐, 인프라 이상 배지
- 테넌트명 클릭 시 상세 페이지로 이동

## 비즈니스 규칙

- 인프라 이상: EC2/RDS/S3 중 HEALTHY가 아닌 서비스가 하나라도 있으면 경고
- 만료 임박: TRIAL은 D-7 이내, ACTIVE는 계약 종료 D-30 이내
- 스토리지 사용률 90% 이상 red, 75% 이상 amber, 나머지 teal
