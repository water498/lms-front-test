# 플랫폼 일반 설정 (platform-admin)

플랫폼 전역 기본 설정(서비스명, 도메인, 이메일)을 관리하는 탭.

## 화면 구성

### 섹션: 설정 폼
- 서비스명: 브랜딩 영역에 표시되는 플랫폼 이름 (편집 가능)
- 루트 도메인: 전체 기업 서브도메인의 기반 도메인 (읽기 전용)
- 운영 이메일: 내부 운영 알림 수신 이메일 (편집 가능)
- 지원 이메일: 학습자/관리자 화면에 노출되는 문의 이메일 (편집 가능)
- 저장 버튼

## 비즈니스 규칙

- 루트 도메인은 운영팀 승인 후에만 변경 가능 (UI에서 read-only)
- 각 필드에 InfoTooltip으로 용도 설명 제공
