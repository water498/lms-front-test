# 테넌트 목록 (platform-admin)

전체 기업(테넌트) 목록을 테이블로 조회하고 신규 테넌트를 생성하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Tenant | - | 기업(테넌트) |

## 화면 구성

### 섹션: 테넌트 테이블
- 테넌트명, 유형(B2B/B2C), 서브도메인, 상태(ACTIVE/TRIAL D-N/SUSPENDED), 사용자 수, 스토리지 사용률 바, 계약 기간
- 행 클릭 시 테넌트 상세(tenant-layout)로 이동
- "신규 테넌트 추가" 버튼

## 모달

### 신규 기업 온보딩 (CreateTenantModal)
- 기업명, 서브도메인(실시간 유효성 검사), 기업 Admin 이메일
- 최대 학습자 수(0=무제한), 스토리지 한도(GB), 계약 종료일
- 서브도메인: format/reserved/taken/valid 상태 실시간 표시
- "온보딩 시작" 클릭 시 생성 + 초대 이메일 자동 발송

## 비즈니스 규칙

- 서브도메인: 소문자 영숫자/하이픈만 허용, 최소 2자, 예약어/중복 불가
- TRIAL 상태 테넌트는 만료 D-day 표시
- 스토리지 사용률 90% 이상 red, 75% 이상 amber
