# 테넌트 크레딧 (platform-admin)

개별 테넌트의 메시징 크레딧 잔액 조회 및 수동 지급을 관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CreditTransaction | - | 크레딧 거래 내역 |

## 화면 구성

### 섹션: 잔여 크레딧
- 현재 잔액 표시, "크레딧 지급" 버튼

### 섹션: 지급 이력 테이블
- 일시, 내용(메모), 지급량 표시

## 모달

### 크레딧 지급
- 프리셋 금액 선택(1,000 / 5,000 / 10,000 / 30,000 cr) 또는 직접 입력
- 메모(선택) 입력
- 지급 실행 시 잔액 즉시 반영 + 이력 추가

## 비즈니스 규칙

- 크레딧은 양수만 지급 가능 (차감 기능 없음)
- 프리셋 선택과 직접 입력은 상호 배타적
