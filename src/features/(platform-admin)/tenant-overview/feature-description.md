# 테넌트 개요 (platform-admin)

개별 테넌트의 기본 정보, 사용 현황, 관리 액션을 표시하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Tenant | - | 기업(테넌트) |

## 화면 구성

### 섹션: 기본 정보
- 담당자 이메일 + 초대 상태(활성/초대 발송됨) + 재발송 버튼
- 계약 기간, 상태 배지
- 서브도메인 인라인 편집 (실시간 유효성 검사: format/reserved/taken/valid)

### 섹션: 사용 현황
- 사용자 수 프로그레스 바 (현재/최대, 무제한 지원)
- 저장 용량 프로그레스 바 (사용량/한도)

### 섹션: 관리 액션
- "기업 정지" / "정지 해제" 토글 버튼 (confirm 다이얼로그)

## 비즈니스 규칙

- 서브도메인 변경 시 실시간 중복/예약어/포맷 검증
- 사용자/스토리지 사용률 90% 초과 시 red 색상 경고
- 최대 사용자 0이면 "무제한"으로 표시
