# 테넌트 SSO (platform-admin)

개별 테넌트의 SSO 연동 상태를 조회하고 긴급 제어하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Tenant | - | 기업(테넌트) |
| TenantSsoConfig | - | SSO 설정 |

## 화면 구성

### 섹션: SSO 상태
- 활성/비활성/강제 비활성화(override) 상태 표시
- 플랜 배지, 연결 상태(정상/꺼짐), IdP 호스트명, 마지막 확인 시각
- "강제 비활성화" break-glass 버튼 (confirm 다이얼로그)
- SSO 미설정 시 안내 메시지

### 섹션: 관리자 전환
- "관리자로 전환" 링크 (impersonation) — SSO 세부 설정은 기업 admin에서 변경

## 비즈니스 규칙

- 플랫폼 관리자는 SSO 세부 설정을 직접 변경하지 않음 (기업 admin 위임)
- 긴급 시 "강제 비활성화"로 SSO를 일시적으로 끄고 이메일/비밀번호 로그인 허용
- 강제 비활성화 해제 시 기업 관리자가 설정한 SSO가 다시 활성화
