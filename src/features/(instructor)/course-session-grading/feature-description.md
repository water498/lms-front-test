# 차시 채점 (Instructor)

강사가 과제 제출물과 시험 주관식 답안을 채점하는 화면.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentSubmission | progress | 과제 제출 (점수·피드백 포함) |
| ExamAnswer | assessment/exam | 시험 답안 (주관식 채점 대상) |

## 화면 구성

### 섹션: 과제
- 테이블: 수강생명, 과제명, 제출 시각, 점수(0~100), 피드백, 채점 버튼
- 미채점 항목은 빨간 "미채점" 배지 표시
- 인라인 편집: 점수 입력 + 피드백 텍스트 → 저장/취소

### 섹션: 주관식
- 카드 레이아웃: 수강생명, 시험명, 문제, 답안 전문, 점수(0~10), 피드백
- 답안 본문을 전체 표시하여 채점 편의 제공
- 인라인 편집: 점수 + 피드백 textarea → 저장/취소

- 상단 섹션 토글(과제/주관식)에 미채점 건수 배지 표시
- 전체 채점 완료 시 초록색 "전체 채점 완료" 표시

## 비즈니스 규칙

- 과제 점수 범위: 0~100, 주관식 점수 범위: 0~10
- 채점 저장 시 gradedAt 타임스탬프 자동 기록
- 채점 완료 후에도 수정 가능
