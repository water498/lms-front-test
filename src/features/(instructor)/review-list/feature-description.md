# 강사 리뷰 목록 (instructor)

수강생이 남긴 강사 리뷰를 조회하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorReview | course | 강사 리뷰 |

## 화면 구성

### 섹션: 평점 요약
- 평균 평점(숫자 + 별), 총 리뷰 수
- 5~1점 별점 분포 막대 차트

### 섹션: 리뷰 목록
- 작성자명 이니셜 아바타, 이름, 별점, 비공개 배지, 작성일
- 리뷰 본문 표시
- 리뷰가 없으면 빈 상태 메시지

## 비즈니스 규칙

- 평균 평점과 분포는 공개(visible) 리뷰만 대상
- 비공개 리뷰도 강사에게는 목록에 표시되나 "비공개" 배지 부착
