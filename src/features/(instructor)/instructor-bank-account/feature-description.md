# 계좌 정보 (instructor)

정산금 수령 계좌를 등록·관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorBankAccount | course | 강사 계좌 |

## 화면 구성

### 섹션: 계좌 목록
- 은행명, 계좌번호, 예금주 표시
- 주 계좌 배지(violet 강조), "주 계좌로 설정" 버튼, 삭제 버튼
- 계좌 미등록 시 빈 상태 + "계좌 추가" CTA

### 섹션: 계좌 등록 폼
- "계좌 추가" 버튼 클릭 시 인라인 폼 표시
- 은행 선택(9개 은행 드롭다운), 계좌번호, 예금주 입력
- 저장/취소 버튼

## 비즈니스 규칙

- 첫 번째 등록 계좌는 자동으로 주 계좌(isPrimary) 지정
- 주 계좌 삭제 시 남은 첫 번째 계좌가 자동으로 주 계좌 승격
- 은행·계좌번호·예금주 모두 입력해야 저장 가능
