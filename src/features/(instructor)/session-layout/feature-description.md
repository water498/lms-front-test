# 세션 상세 레이아웃 (instructor)

강사가 담당 세션의 세부 정보를 탭으로 탐색하는 레이아웃 셸.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionInstructor | course | 강사-세션 배정 |
| Session | course | 과정 차수 |

## 화면 구성

### 섹션: 헤더
- 뒤로가기 버튼, 과정명, 차수명, 수강생 수, 역할(주/보조) 표시

### 섹션: 탭 네비게이션
- 수강생, 출결, 채점, Q&A, 자료 5개 탭
- pathname 기반 활성 탭 판별, 탭 콘텐츠는 children으로 렌더링

## 비즈니스 규칙

- sessionId URL 파라미터로 세션 식별
- 존재하지 않는 세션 접근 시 "세션을 찾을 수 없습니다" 메시지 표시
