# 강사 프로필 (instructor)

수강생에게 표시되는 강사 프로필 정보를 편집하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorProfile | course | 강사 프로필 |

## 화면 구성

### 섹션: 프로필 폼
- 헤드라인, 전문 분야, 강사 소개(textarea), 경력 사항(textarea)
- 소속 기관, 웹사이트 URL
- 프로필 공개 토글 (비공개 시 강사 목록에 미표시)
- 저장 버튼 클릭 시 "저장됨" 피드백 2초간 표시

## 비즈니스 규칙

- 프로필 공개 여부(isPublic)로 강사 목록 노출 제어
- 모든 필드는 선택사항 (optional)
