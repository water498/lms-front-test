# 차시 Q&A (Instructor)

강사가 수강생 질문을 확인하고 답변하는 화면.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| QnaPost | course | 수강생 질문 게시글 |
| QnaReply | course | 강사 답변 |

## 화면 구성

- 헤더: 총 질문 수, 미답변 건수 배지 (전체 답변 완료 시 초록 배지)
- 질문 목록: 아코디언 카드 형태 (클릭으로 펼침/접힘)
  - 접힌 상태: 답변완료/미답변 배지, 수강생명, 작성일, 제목
  - 펼친 상태: 질문 본문, 기존 답변 목록, 답변 입력 폼
- 답변 표시: 강사 아바타("강") + 이름 + 작성일 + 본문
- 답변 입력 폼: textarea + 전송 버튼 (미답변 질문에만 표시)

## 비즈니스 규칙

- 숨김(isHidden) 처리된 질문은 목록에서 제외
- 답변이 없는 질문에만 입력 폼 노출
- 답변 작성 시 현재 강사 정보 자동 설정
