# 정산 내역 (instructor)

강사의 월별 정산 현황을 테이블로 조회하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorRevenue | course | 강사 정산 |

## 화면 구성

### 섹션: 요약 카드
- 지급 완료 총액(PAID 합산), 지급 대기/승인 총액(PENDING+APPROVED 합산)

### 섹션: 정산 테이블
- 정산 기간, 유형(강의 판매 등), 매출, 수수료율, 정산액, 상태, 지급일
- 상태 배지: 지급 대기(amber), 승인됨(sky), 지급 완료(emerald), 취소됨(zinc)
- 내역 없으면 빈 상태 메시지

## 비즈니스 규칙

- 정산 상태: PENDING → APPROVED → PAID 또는 CANCELLED
- 정산액 = 매출 - (매출 * 수수료율)
