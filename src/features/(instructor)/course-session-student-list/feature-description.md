# 차시 수강생 목록 (Instructor)

강사가 담당 차시의 수강생 현황을 테이블로 조회하는 화면.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Enrollment | progress | 수강 등록 (상태·진도율 포함) |
| CourseSession | course | 차시 (과정의 운영 단위) |

## 화면 구성

- 수강생 테이블: 이름(아바타 이니셜), 이메일, 진도(프로그레스바 %), 상태 배지, 등록일
- 상태 배지: 수강 중(ACTIVE), 수료(COMPLETED), 취소(CANCELLED)
- 수강생이 없을 경우 빈 상태 메시지 표시

## 비즈니스 규칙

- 데이터는 sessionId 기준으로 필터링
- 강사는 조회만 가능하며 수강생 등록·삭제 권한 없음
- 진도율은 0~100% 프로그레스바로 시각화
