# 강사 대시보드 (instructor)

강사의 담당 과정, 수강생, 평점, 정산 현황을 한눈에 요약하는 메인 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionInstructor | course | 강사-세션 배정 |
| Enrollment | progress | 수강 등록 |
| InstructorReview | course | 강사 리뷰 |
| InstructorRevenue | course | 강사 정산 |

## 화면 구성

### 섹션: 통계 카드
- 담당 과정 수, 총 수강생 수, 평균 평점(공개 리뷰 기준), 정산 대기 금액
- 각 카드 클릭 시 해당 상세 페이지로 이동

### 섹션: 담당 과정 테이블
- 과정명, 차수, 수강생 수, 역할(주 강사/보조 강사), 시작일 표시
- "전체 보기" 링크로 세션 목록 이동

### 섹션: 최근 리뷰
- 최대 3건 표시, 작성자명, 별점, 비공개 여부 표시
- "전체 보기" 링크로 리뷰 목록 이동

## 비즈니스 규칙

- 평균 평점은 공개(visible) 리뷰만 대상으로 계산
- 정산 대기 금액은 PENDING 상태인 정산만 합산
- 수강생 수는 담당 세션의 enrollment 합산
