# 유저 상세 레이아웃 (Admin)

개별 유저의 상세 페이지를 탭 내비게이션으로 구성하는 레이아웃 셸.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 유저 정보 |

## 화면 구성

- 브레드크럼: "유저 목록" 링크
- **기본 탭 5개**: 기본 정보, 수강 이력, 활동 로그, 접속 기기, 접속 이력
- **강사 전용 탭 4개** (역할이 INSTRUCTOR일 때 추가): 담당 과정, 강사 평가, 정산 내역, 계좌 정보
- 탭 콘텐츠는 children으로 렌더링
- UserDetailProvider 컨텍스트로 userId 공유

## 비즈니스 규칙

- 존재하지 않는 userId 접근 시 "존재하지 않는 유저입니다" 표시
- 강사 역할(INSTRUCTOR)일 때만 강사 관련 탭 노출
