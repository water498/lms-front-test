# 계좌 정보

정산금 수령 계좌를 등록·관리하는 페이지.

## 누가, 언제
- **역할**: 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 계정 > 계좌
- **URL**: /backoffice/account/bank
- **목적**: 정산금 수령 계좌 등록, 주 계좌 설정, 계좌 삭제

## 화면 구성
### 레이아웃
상단 제목 + 계좌 추가 버튼 / 계좌 등록 폼(인라인) / 계좌 카드 목록.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 계좌 추가 버튼 | 인라인 등록 폼 표시 | 폼 열기 |
| 계좌 등록 폼 | 은행(9개 드롭다운), 계좌번호, 예금주 입력 | 저장/취소 |
| 계좌 카드 | 은행명, 계좌번호, 예금주, 주 계좌 뱃지(violet) | - |
| "주 계좌로 설정" 버튼 | 해당 계좌를 주 계좌로 지정 | 상태 변경 |
| 삭제 버튼 (휴지통) | 계좌 삭제 | 즉시 삭제 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 계좌 있음 | 계좌 카드 목록 |
| 계좌 없음 | 빈 상태 + "계좌 추가" CTA |
| 등록 폼 열림 | 인라인 등록 폼 표시 (계좌 추가 버튼 숨김) |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 주 계좌 | violet 테두리, "주 계좌" 뱃지 표시 |
| 비주 계좌 | "주 계좌로 설정" 버튼 표시 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorBankAccount | instructor | 강사 계좌 (은행명, 계좌번호, 예금주, 주 계좌 여부) |

## 비즈니스 규칙
- 첫 번째 등록 계좌는 자동으로 주 계좌(isPrimary) 지정
- 주 계좌 삭제 시 남은 첫 번째 계좌가 자동 승격
- 은행·계좌번호·예금주 모두 입력해야 저장 가능
- 지원 은행: 카카오뱅크, 신한, 국민, 우리, 하나, 기업, 농협, 토스뱅크, 케이뱅크
