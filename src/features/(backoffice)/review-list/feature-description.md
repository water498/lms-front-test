# 내 리뷰

수강생이 남긴 강사 리뷰를 조회하는 페이지.

## 누가, 언제
- **역할**: 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 계정 > 리뷰
- **URL**: /backoffice/account/reviews
- **목적**: 수강생이 남긴 강사 평가 리뷰 확인

## 화면 구성
### 레이아웃
평점 요약 카드 + 리뷰 목록.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 평균 평점 | 숫자(대) + 별(5개) + 총 리뷰 수 | 읽기 전용 |
| 별점 분포 차트 | 5~1점 막대 그래프 + 건수 | 읽기 전용 |
| 리뷰 카드 | 작성자 이니셜 아바타, 이름, 별점, 비공개 뱃지, 작성일, 본문 | 읽기 전용 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 리뷰 있음 | 요약 + 리뷰 목록 |
| 리뷰 없음 | "아직 리뷰가 없습니다" 빈 상태 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| visible = false | "비공개" 뱃지 표시 (강사에게는 내용 표시됨) |
| 리뷰 1건 이상 | 평점 요약 카드 표시 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorReview | instructor | 강사 리뷰 (작성자, 별점, 본문, 공개여부) |

## 비즈니스 규칙
- 평균 평점과 분포는 공개(visible) 리뷰만 대상으로 계산
- 비공개 리뷰도 강사에게는 목록에 표시되나 "비공개" 뱃지 부착
- 강사는 리뷰 조회만 가능 (삭제/수정 불가)
