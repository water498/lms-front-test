# 포털 공지 관리

조직 내부 공지사항을 작성하고 발송하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 포털 > 공지
- **URL**: /backoffice/org/portal/announcements
- **목적**: 조직 내 공지 작성, 대상 지정, 발송 이력 관리

## 화면 구성
### 레이아웃
공지 테이블 + 새 공지 작성 모달.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 공지 테이블 | 제목, 유형(공지/시스템), 대상(전체/특정 과정), 발송일, 조회 수 | 읽기 전용 |
| + 새 공지 버튼 | 새 공지 작성 모달 열기 | NewAnnouncementForm 표시 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 공지 있음 | 테이블에 행 표시 + 건수 |
| 공지 없음 | 빈 테이블 |

## 모달
### 새 공지 작성 (NewAnnouncementForm)
- 필드: 제목, 내용(RichEditor), 대상(전체 조직 또는 특정 과정)
- 동작: "발송" 버튼으로 공지 발송

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgAnnouncement | org | 조직 공지 (제목, 유형, 대상, 조회 수) |

## 비즈니스 규칙
- 유형: NOTICE(공지), UPDATE(시스템)
- 대상: ALL_MEMBERS(전체) 또는 특정 과정 수강생
- 발송 후 조회 수 추적
