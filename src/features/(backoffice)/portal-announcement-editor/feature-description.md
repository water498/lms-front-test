# 포털 공지 관리 (Admin)

조직 내부 공지사항을 작성하고 발송하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgAnnouncement | org | 조직 내부 공지 |

## 화면 구성

- 테이블 컬럼: 제목, 유형(공지/시스템), 대상(전체/특정 과정), 발송일, 조회 수
- "+ 새 공지" 버튼

## 모달

### 새 공지 작성
- 필드: 제목, 내용(리치 에디터), 대상(전체 조직 / 특정 과정)
- 발송 버튼

## 비즈니스 규칙

- 대상을 특정 과정으로 지정하면 해당 과정 수강생에게만 발송
