# 발급된 수료증 (Admin)

학습자에게 발급된 수료증 목록을 조회하고 취소/재발급하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| IssuedCertificate | certificate | 발급된 수료증 (상태, 검증 토큰) |
| CertificateTemplate | certificate | 수료증 템플릿 |

## 화면 구성

- 과정별 필터, 상태 필터(전체/유효/취소됨/만료됨)
- 테이블 컬럼: 학습자, 과정, 발급일, 상태(유효/취소됨/만료됨)
- 액션: 다운로드, 검증 링크 복사, 재발급, 취소

## 모달

### 수료증 취소
- 취소 사유 입력 후 확인

### 수료증 재발급
- 재발급 확인

## 비즈니스 규칙

- 취소된 수료증은 검증 링크에서 무효 표시
- 재발급 시 기존 수료증은 대체됨
