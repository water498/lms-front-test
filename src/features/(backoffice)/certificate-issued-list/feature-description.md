# 발급된 수료증

학습자에게 발급된 수료증 목록을 조회하고 취소/재발급하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 수료증 > 발급 내역 탭
- **URL**: /backoffice/org/certificates/issued
- **목적**: 발급 이력 확인, 수료증 취소/재발급, 검증 링크 관리

## 화면 구성
### 레이아웃
과정/상태 필터 + 발급 내역 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 과정 필터 | 전체/특정 과정 선택 | 테이블 필터 |
| 상태 필터 | 전체/유효/취소됨/만료됨 | 테이블 필터 |
| 발급 테이블 | 수료증 번호, 수령인, 과정, 상태, 발급일, 만료일, 재발급일 | - |
| 다운로드 버튼 | PDF 다운로드 | 다운로드 |
| 검증 링크 복사 | 검증 URL 클립보드 복사 | 복사 |
| 재발급 버튼 | 수료증 재발급 | ReissueModal 열기 |
| 취소 버튼 | 수료증 무효화 | RevokeModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 발급 내역 있음 | 테이블 + 건수 표시 |
| 발급 내역 없음 | 빈 상태 |

## 모달
### 수료증 취소 (RevokeModal)
- 취소 사유 입력 후 확인

### 수료증 재발급 (ReissueModal)
- 재발급 확인

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| IssuedCertificate | certificate | 발급된 수료증 (상태, 검증 토큰, 만료일) |
| CertificateTemplate | certificate | 수료증 템플릿 |

## 비즈니스 규칙
- 수료증 상태: VALID(유효), REVOKED(취소됨), EXPIRED(만료됨)
- 취소된 수료증은 검증 링크에서 무효 표시
- 재발급 시 기존 수료증은 대체됨
