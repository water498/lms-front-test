# 카테고리 관리

과정 분류용 카테고리를 3단계 계층 구조로 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 리소스 > 카테고리
- **URL**: /backoffice/resources/categories
- **목적**: 과정에 적용할 카테고리 체계(대/중/소) 구성

## 화면 구성
### 레이아웃
상단 제목 + 대분류 추가 버튼 / 트리 구조 카테고리 목록 / 하단 안내 텍스트.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 대분류 추가 버튼 | 최상위 카테고리 생성 | 인라인 입력 활성화 |
| 카테고리 노드 | 이름, 깊이 라벨(대/중/소), 사용 과정 수 뱃지 | 펼침/접힘 토글 |
| 순서 이동 (위/아래) | 같은 레벨 내 순서 변경 | hover 시 표시 |
| 하위 추가 (+) | 자식 카테고리 추가 | 인라인 입력 |
| 편집 (연필) | 이름 인라인 변경 | 입력 모드 전환 |
| 삭제 (휴지통) | 카테고리 제거 | 사용 과정 있으면 경고 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 카테고리 있음 | 트리 구조 표시 |
| 카테고리 없음 | "카테고리가 없습니다. 대분류를 추가해보세요." |
| 편집 모드 | 이름 입력 필드 + 확인/취소 버튼 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 과정 연결된 카테고리 삭제 시 | 빨간 경고 + 사용 과정 목록 나열 |
| depth = 3 (소분류) | 하위 추가 버튼 숨김 |
| 첫 번째/마지막 항목 | 위/아래 이동 버튼 비활성화 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | course-info | 과정 생성/편집 시 카테고리 선택 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| Category | taxonomy | 카테고리(이름, 부모ID, 순서) |

## 비즈니스 규칙
- 최대 3단계 계층: 대분류 > 중분류 > 소분류
- 대분류 삭제 시 하위 중/소분류도 함께 삭제
- 과정이 연결된 카테고리는 모든 과정의 카테고리를 변경한 후 삭제 가능
- 같은 레벨 내 순서 변경 가능 (위/아래 화살표)
- zustand taxonomy-store 기반 상태 관리
