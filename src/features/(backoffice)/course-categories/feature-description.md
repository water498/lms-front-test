# 과정 카테고리 관리 (Admin)

과정에 적용할 카테고리를 최대 3단계(대/중/소) 계층으로 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseCategory | course | 과정 카테고리 (계층 구조) |

## 화면 구성

- 트리 구조로 카테고리 표시 (대분류 > 중분류 > 소분류)
- 각 노드에 depth 라벨(대분류/중분류/소분류) 표시
- 과정 연결 건수 뱃지 (예: "3개 과정")
- hover 시 액션 버튼: 순서 이동(위/아래), 하위 추가, 이름 편집, 삭제
- 인라인 편집: Enter로 확인, Escape로 취소
- "+ 대분류 추가" 버튼

## 비즈니스 규칙

- 최대 깊이 3단계 (대/중/소) 초과 시 하위 추가 버튼 숨김
- 과정이 연결된 카테고리는 삭제 불가 — 경고 표시 및 해당 과정 목록 나열
- 대분류 삭제 시 하위 중/소분류도 함께 삭제
- 동일 레벨 내 중복 이름 방지 (대분류 기준)
