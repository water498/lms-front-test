# 과제 템플릿 목록

과제 템플릿을 조회·관리하고 새 과제를 생성하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 리소스 > 평가 > 과제 탭
- **URL**: /backoffice/resources/assessments/assignments
- **목적**: 등록된 과제 템플릿을 확인하고 편집·보관·삭제

## 화면 구성
### 레이아웃
상단 필터 + 테이블 형태. AssignmentTable 섹션 컴포넌트로 구성.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 필터 탭 (활성/보관됨/전체) | 과제 상태별 필터링 | 해당 상태 목록 표시 |
| 과제 행 | 제목, 제출방식(파일/텍스트/둘 다), 사용 과정 수, 생성일 | 에디터로 이동 |
| + 새 과제 버튼 | 새 과제 템플릿 생성 | /backoffice/resources/assessments/assignment/new |
| 보관/복원/삭제 버튼 | 상태 전환 및 삭제 | 해당 액션 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 과제 있음 | 테이블에 행 표시 |
| 과제 없음 | 빈 상태 안내 |
| 보관됨 필터 | 보관된 과제만 표시 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | assessment-assignment-editor | 행 클릭 또는 새 과제 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentTemplate | assessment | 과제 템플릿 (제출방식, 합격점수, 루브릭) |

## 비즈니스 규칙
- 제출 방식: FILE(파일), TEXT(텍스트), BOTH(파일+텍스트)
- 보관 시 목록에서 숨김, 복원으로 재활성화
