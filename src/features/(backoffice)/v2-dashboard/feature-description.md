# Backoffice 대시보드

관리자/강사 역할에 따른 KPI 현황, 오늘 할 일, 일정 캘린더, 플랫폼 공지를 한눈에 보여주는 메인 대시보드.

## 누가, 언제

- **역할**: ORG_ADMIN, SUPER_ADMIN, INSTRUCTOR
- **진입 경로**: Backoffice 로그인 후 기본 랜딩
- **URL**: `/backoffice`
- **목적**: 하루의 업무 파악 (미처리 건, 핵심 지표, 다가오는 일정)

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 플랫폼 배너 | URGENT(긴급)/MAINTENANCE(점검) 공지, 닫기 가능 | 공지 제목 클릭 시 공지사항 페이지 이동 |
| KPI 카드 x4 | 역할별 핵심 지표 + 증감 표시 | — |
| 오늘 할 일 | 긴급 건수 뱃지, 항목별 아이콘+제목+서브타이틀+건수 | 해당 페이지로 이동 (Link) |
| 다가오는 일정 | 캘린더/리스트 뷰 전환 가능 | — |
| 미니 캘린더 | 월간 달력, 일정 있는 날에 색상 도트 표시 | hover 시 일정 tooltip |
| 리스트 뷰 | 시작/종료/마감 뱃지 + 일정 제목 + 과정명 + 날짜 | — |
| 배너 닫기(X) | 배너별 개별 닫기 | 해당 배너 숨김 (세션 내) |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 할 일 0건 | "처리할 항목이 없습니다" |
| 긴급 건 존재 | 할 일 섹션 헤더에 빨간 "긴급 N건" 뱃지 |
| 긴급 할 일 항목 | 빨간 배경 아이콘 + 빨간 건수 |
| 플랫폼 공지 없음 | 배너 영역 미노출 |
| 모든 배너 닫음 | 배너 영역 미노출 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| role = ORG_ADMIN / SUPER_ADMIN | Admin KPI (활성 과정, 전체 수강생, 수료율, 이번 달 수료) + Admin 할 일 |
| role = INSTRUCTOR | Instructor KPI (내 과정, 총 수강생, 평균 평점, 정산 대기) + Instructor 할 일 |
| 긴급(URGENT) 배너 | 빨간 배경 + AlertTriangle 아이콘 |
| 점검(MAINTENANCE) 배너 | 노란 배경 + Wrench 아이콘 |
| 캘린더 뷰 | 미니 캘린더 표시, 일정 도트 (초록=시작, 회색=종료, 빨강=마감) |
| 리스트 뷰 | 일정 목록 카드 표시 |

## 비즈니스 규칙

- KPI와 할 일 목록은 로그인 역할에 따라 완전히 다른 데이터셋 표시
- Admin: 활성 과정 수, 전체 수강생, 수료율, 이번 달 수료 + 채점/Q&A/승인/리뷰 할 일
- Instructor: 내 과정 수, 총 수강생, 평균 평점, 정산 대기 + 채점/Q&A 할 일
- 플랫폼 배너는 PUBLISHED 상태의 URGENT/MAINTENANCE 공지만 표시
- 배너 닫기는 세션 내에서만 유지 (새로고침 시 복원)
- 할 일 항목은 urgent 플래그에 따라 빨간/기본 스타일 분기
- 캘린더 도트 색상: 시작(초록), 종료(회색), 마감(빨강)
