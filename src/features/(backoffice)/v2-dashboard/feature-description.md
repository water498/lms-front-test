# 통합 대시보드 v2 (Backoffice)

할 일 중심 통합 대시보드. ORG_ADMIN과 INSTRUCTOR 역할별 위젯 분기.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 차수 (일정) |
| Enrollment | enrollment | 수강 현황 |

## 화면 구성

### 섹션: KPI 카드
- ORG_ADMIN: 활성 과정, 전체 수강생, 수료율, 이번 달 수료
- INSTRUCTOR: 내 과정, 총 수강생, 평균 평점, 정산 대기

### 섹션: 오늘 할 일
- 채점 대기, 미답변 Q&A, 과정 승인, 새 리뷰 등
- 긴급 항목 빨간색 강조, 건수 표시
- 클릭 시 해당 차수/과정 상세로 바로 이동

### 섹션: 다가오는 일정
- 리스트 / 달력 뷰 토글
- 차수 시작/종료, 과제 마감 등 시간순 표시

## B2C/B2B 분기

- 동일 UI, 데이터만 역할/scope에 따라 다름
