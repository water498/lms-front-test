# 포털 정보

학습자 포털의 기본 정보(포털명, 로고, 파비콘, URL)를 설정하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 포털 > 기본 정보
- **URL**: /backoffice/org/portal/info
- **목적**: 포털의 브랜딩 기본 정보 설정

## 화면 구성
### 레이아웃
단일 컬럼 폼 (max-w-lg).

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 포털명 입력 | 브라우저 탭, 이메일 발신자명, 로그인 화면에 표시 | 편집 |
| 로고 업로드 | PNG/SVG 권장, 최소 200x80px | 파일 선택 |
| 파비콘 업로드 | ICO/PNG 권장, 32x32 또는 64x64px | 파일 선택 |
| 포털 URL | subdomain.lms.io 형식 (읽기 전용) + 외부 링크 | 새 탭 열기 |
| 저장 버튼 | 설정 저장 | 저장 실행 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgSettings | org | 조직 설정 (포털명, 서브도메인) |

## 비즈니스 규칙
- 포털 URL 변경은 플랫폼 관리자에게 문의 필요 (읽기 전용)
