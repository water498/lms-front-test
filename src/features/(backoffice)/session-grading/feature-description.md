# 차수 채점 (Admin)

차수 내 과제 제출물과 시험 주관식 답안을 채점하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentSubmission | assessment/assignment | 과제 제출 (점수, 피드백) |
| ExamAttempt | assessment/exam | 시험 응시 기록 |
| ExamAnswer | assessment/exam | 시험 답안 (주관식 채점 점수, 피드백) |

## 화면 구성

- 섹션 토글: 과제 채점 / 시험 주관식 채점
  - 미채점 건수 뱃지 표시
  - 전체 미채점 총 건수 또는 "전체 채점 완료" 표시

### 탭: 과제 채점
- 테이블: 수강생, 과제명, 제출일시, 점수(0-100), 피드백
- 인라인 편집: 점수 입력 + 피드백 입력 → 저장/취소
- 미채점 항목은 빨간 "미채점" 뱃지
- 점수에 따른 색상 분기 (90+ 초록, 70+ 기본, 미만 주황)

### 탭: 시험 주관식 채점
- 카드형 레이아웃: 학습자명, 시험명, 문제, 답안 전문
- 채점: 점수(0-10) 입력 + 피드백 텍스트에리어 → 저장/취소

## 비즈니스 규칙

- 과제 점수 범위: 0-100
- 주관식 점수 범위: 0-10
- 채점 완료 시 gradedAt 타임스탬프 자동 기록
