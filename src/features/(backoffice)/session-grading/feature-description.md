# 차수 채점 관리

차수 내 과제 제출물과 시험 주관식 답안을 채점하고 피드백을 작성하는 화면.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > 채점 탭
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/grading`
- **목적**: 과제 채점(0-100점) 및 시험 주관식 채점(0-10점), 피드백 작성

## 화면 구성

### 레이아웃
```
┌──────────────────────────────────────┐
│ [과제 채점 (N)] [시험 주관식 채점 (N)]   미채점 총 N건 │
├──────────────────────────────────────┤
│  ── 과제 채점 섹션 ──                 │
│  수강생 | 과제 | 제출 | 점수 | 피드백 | 액션  │
│  ─────────────────────────────────── │
│  박지호 | 실습과제 | 02-10 | 95 | 피드백.. | [수정] │
│  최유진 | 실습과제 | 02-11 | 미채점 | — | [채점] │
├──────────────────────────────────────┤
│  ── 시험 주관식 섹션 ──               │
│  ┌ 학습자 · 시험명         9점 ┐      │
│  │ Q: 질문 제목                │      │
│  │ [답변 내용 영역]            │      │
│  │ 점수 [  ]/10  피드백 [    ] │      │
│  └──────────────────────────┘      │
└──────────────────────────────────────┘
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 과제 채점 탭 | 미채점 건수 빨간 뱃지 표시 | 과제 섹션 전환 |
| 시험 주관식 탭 | 미채점 건수 빨간 뱃지 표시 | 주관식 섹션 전환 |
| 미채점 총 N건 | 우측 요약 (빨간색), 전체 완료 시 초록색 | — |
| 과제 테이블 행 | 수강생, 과제명, 제출일, 점수, 피드백 | — |
| 채점/수정 버튼 | 인라인 편집 모드 진입 | 점수/피드백 입력 필드 표시 |
| 저장 버튼 | 인라인 편집 확정 | 채점 결과 저장 |
| 취소 버튼 | 인라인 편집 취소 | 편집 전 상태 복원 |
| 주관식 카드 | 학습자명, 시험명, 질문, 답변 전문 표시 | — |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 과제 제출 없음 | "제출된 과제가 없습니다." |
| 주관식 답안 없음 | "주관식 답안이 없습니다." |
| 전체 채점 완료 | 우측에 초록색 "전체 채점 완료" 표시 |
| 미채점 존재 | 빨간 뱃지 + "미채점 총 N건" 빨간 텍스트 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| grade !== null (과제) | 점수 컬러: 90+ 초록, 70+ 기본, 70미만 amber |
| grade === null | "미채점" 빨간 뱃지 표시 |
| 인라인 편집 중 | 점수 input + 피드백 input/textarea + 저장/취소 버튼 |

## 모달

없음 (인라인 편집 방식)

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 상위 | 과정 상세 차수 탭 | 탭 네비게이션 |
| 동일 레벨 | 대시보드/수강생/Q&A/자료실/오프라인 탭 | 탭 전환 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentSubmission | assignment | 과제 제출물 (점수 0-100, 피드백) |
| EssayAnswer | exam | 시험 주관식 답안 (점수 0-10, 피드백) |
| CourseSession | course | 차수 식별 |

## 비즈니스 규칙

- 과제 채점 범위: 0~100점, 빈 값 허용 (미채점 상태 유지)
- 시험 주관식 채점 범위: 0~10점, 빈 값 허용
- 유효하지 않은 점수(범위 초과, NaN)는 저장 거부
- 채점 완료 후에도 수정 버튼으로 재채점 가능
- 피드백은 선택 사항 (빈 문자열 허용)
- 채점 시 gradedAt 타임스탬프 자동 기록
