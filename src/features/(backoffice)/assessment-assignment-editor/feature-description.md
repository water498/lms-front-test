# 과제 에디터 (Admin)

과제(AssignmentTemplate) 템플릿의 설명과 채점 루브릭을 편집하는 3패널 에디터.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentTemplate | assessment/assignment | 과제 템플릿 (제출 방식, 합격 기준) |
| AssignmentRubricItem | assessment/assignment | 채점 루브릭 항목 (평가 기준, 배점) |

## 화면 구성

- **상단 바**: 과제 제목 인라인 편집, 총 배점 표시(채점 활성 시), 저장 버튼
- **좌측 패널 (섹션)**: 과제 설명 / 채점 루브릭 (채점 활성 시만 표시)
- **중앙 패널 (편집)**:
  - 과제 설명: 리치 에디터로 안내문 작성
  - 채점 루브릭: 평가 항목 추가/삭제, 항목별 배점 설정, 총점 표시
- **우측 패널 (설정)**: 제출 방식(파일/텍스트/파일+텍스트), 채점 여부 토글, 합격 기준(%)

## 비즈니스 규칙

- 채점 비활성화 시 제출만으로 완료 처리, 루브릭 섹션 숨김
- 채점 활성화 시 합격 기준(%) 설정 필요
- 루브릭 총점 = 모든 항목 배점의 합
