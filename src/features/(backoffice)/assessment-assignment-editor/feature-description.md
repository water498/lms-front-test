# 과제 에디터

과제 템플릿의 설명, 채점 루브릭, 제출 방식을 설정하는 전체 화면 에디터.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 과제 목록에서 행 클릭 또는 + 새 과제
- **URL**: /backoffice/resources/assessments/assignment/[id] (fullscreen)
- **목적**: 과제의 안내문 작성, 채점 기준 설정, 제출 방식 선택

## 화면 구성
### 레이아웃
```
[상단 바: 뒤로가기 | 제목 입력 | 총점 | 저장]
[좌측: 섹션 네비] [중앙: 편집 캔버스] [우측: 과제 설정]
```
전체 화면 3-panel 구조.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 섹션 네비 (좌) | 과제 설명, 채점 루브릭 탭 | 해당 섹션 표시 |
| 과제 설명 (중) | RichEditor로 안내문 작성 | 편집 |
| 채점 루브릭 (중) | 평가 항목별 기준과 배점 테이블 | 항목 추가/편집/삭제 |
| 제출 방식 (우) | FILE/TEXT/BOTH 선택 | 변경 |
| 채점 여부 토글 (우) | 점수 기반 합격 판정 ON/OFF | 루브릭 섹션 활성화/숨김 |
| 합격 기준 (우) | 0-100% 입력 | 값 변경 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 채점 비활성 | 루브릭 탭 숨김, "제출만으로 완료 처리" 안내 |
| 채점 활성 | 루브릭 탭 + 합격기준 + 총점 표시 |
| 루브릭 항목 없음 | 빈 상태 + "항목 추가" 버튼 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 채점 OFF | 루브릭 섹션 숨김, 총점 표시 제거 |
| 채점 ON | 루브릭 섹션 및 합격기준 입력 활성화 |
| 루브릭 탭에서 채점 OFF | instructions 탭으로 강제 전환 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 뒤로가기 | assessment-assignment-list | 항상 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| AssignmentTemplate | assessment | 과제 메타(제출방식, 합격점수) |
| AssignmentRubricItem | assessment | 채점 루브릭 항목(기준명, 배점) |

## 비즈니스 규칙
- 채점 비활성 시 제출만으로 과제 완료 처리
- 채점 활성 시 루브릭 총점 대비 합격 기준(%) 적용
- 루브릭 항목은 순서가 있으며, 추가/삭제/배점 수정 가능
