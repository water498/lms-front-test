# 강사 정산 (Admin)

강사별 수익 정산 현황을 관리하고 지급을 처리하는 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorRevenue | instructor | 강사 수익 정산 기록 |
| Instructor | instructor | 강사 정보 |

## 화면 구성

- **요약 카드 3개**: 정산 대기 총액, 이번 달 지급 예정, 누적 지급액
- 상태 탭: 전체 / 정산 대기 / 확정 / 지급 완료
- 유형 필터: 전체 / 과정 판매 / 고정 계약 / 보너스 / 조정
- 테이블 컬럼: 강사, 정산 유형, 정산 기간, 총 매출, 수수료, 실 지급액, 상태, 지급일, 액션
- 강사명 클릭 시 강사 상세 페이지로 이동
- 액션: "정산 확정" (PENDING > APPROVED), "지급 처리" (APPROVED > PAID)

## 비즈니스 규칙

- 정산 흐름: PENDING > APPROVED > PAID
- 수수료 = 총 매출 x commissionRate (기본 20%)
- 실 지급액 = 총 매출 - 수수료
