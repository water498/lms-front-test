# 내 정산 내역

강사 본인의 월별 정산 현황을 조회하는 페이지.

## 누가, 언제
- **역할**: 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 재무 > 내 정산
- **URL**: /backoffice/finance/my-payouts
- **목적**: 본인의 정산 상태(대기/승인/지급)와 금액 확인

## 화면 구성
### 레이아웃
요약 카드 2개 + 정산 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 지급 완료 카드 | PAID 상태 정산액 합계 (emerald) | 읽기 전용 |
| 지급 대기/승인 카드 | PENDING+APPROVED 상태 정산액 합계 (amber) | 읽기 전용 |
| 정산 테이블 | 정산 기간, 유형, 매출, 수수료율, 정산액, 상태 뱃지, 지급일 | 읽기 전용 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 정산 내역 있음 | 요약 카드 + 테이블 |
| 정산 내역 없음 | "정산 내역이 없습니다" 빈 상태 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorRevenue | instructor | 강사 정산 기록 (매출, 수수료율, 정산액, 상태) |

## 비즈니스 규칙
- 상태 뱃지: 지급 대기(amber), 승인됨(sky), 지급 완료(emerald), 취소됨(zinc)
- 정산액 = 매출 - (매출 x 수수료율)
- 강사는 조회만 가능 (확정/지급 처리 불가 - 관리자 권한)
