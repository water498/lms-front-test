# 설정 - 감사 로그 (Admin)

관리자 작업에 의한 데이터 변경 이력을 조회하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgAuditLog | org | 감사 로그 (작업자, 작업 유형, 대상, 상세 내용) |

## 화면 구성

- CSV 내보내기 버튼
- 필터: 검색(작업자/대상/내용), 작업 유형 셀렉트, 기간(시작일-종료일)
- 감사 로그 테이블: 일시, 작업자, 작업 유형 뱃지, 대상, 내용
  - 행 클릭 시 상세 내용 확장
- 작업 유형: 수강 취소, 수강 등록, 과정 생성, 과정 수정, 역할 변경, 조직 구조 변경, 설정 변경, 수료증 발급
- 페이지네이션 (20건 단위)

## 비즈니스 규칙

- 모든 관리자 작업이 자동 기록됨
- 필터 변경 시 페이지 1로 리셋
