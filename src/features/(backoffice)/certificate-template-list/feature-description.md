# 수료증 템플릿

수료증 디자인 템플릿을 생성하고 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 수료증 > 템플릿 탭
- **URL**: /backoffice/org/certificates
- **목적**: 수료증 디자인 생성, 편집, 수동 발급

## 화면 구성
### 레이아웃
그리드 형태 카드 목록 (2~4열 반응형).

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 템플릿 카드 | iframe 기반 실시간 썸네일, 템플릿명, 생성일, 연결 과정 수 | - |
| 편집 버튼 (연필) | HTML 에디터로 디자인 수정 | EditTemplateModal 열기 |
| 수동 발급 버튼 | 특정 학습자에게 즉시 발급 | IssueCertModal 열기 |
| + 새 템플릿 버튼 | 새 수료증 템플릿 생성 | CreateTemplateModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 템플릿 있음 | 카드 그리드 |
| 템플릿 없음 | 빈 상태 |

## 모달
### 템플릿 생성/편집 (CreateTemplateModal / EditTemplateModal)
- HTML 에디터로 수료증 디자인 편집
- 배경 이미지 설정
- 변수 치환: 학습자명, 과정명, 발급일 등

### 수동 발급 (IssueCertModal)
- 과정, 학습자 선택 후 즉시 발급

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | course-info | 과정 설정에서 템플릿 연결 |
| 이동 | certificate-issued-list | 발급 내역 확인 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| CertificateTemplate | certificate | 수료증 템플릿 (HTML, 배경 이미지) |

## 비즈니스 규칙
- HTML 템플릿 내 변수는 발급 시 실제 데이터로 치환
- 과정 정보(course-info)에서 수료증 템플릿을 연결하여 자동 발급
