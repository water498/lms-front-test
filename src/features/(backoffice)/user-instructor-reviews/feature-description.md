# 강사 평가 (Admin)

강사에 대한 수강생 평가(리뷰)를 조회하고, 부적절 리뷰를 숨김 처리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorReview | instructor | 강사 평가 (별점, 본문, 공개 여부) |

## 화면 구성

### 섹션: 요약
- 평균 별점 (5점 만점), 별점 분포 막대 그래프, 총 후기 수

### 섹션: 전체 평가 목록
- 별점, 작성자명, 과정 ID, 작성일, 본문
- "숨기기/노출" 토글 버튼
- 숨김 처리된 리뷰는 반투명 표시

## 비즈니스 규칙

- 평균 별점과 분포는 공개(visible) 리뷰 기준으로 계산
- 강사 역할 사용자에게만 탭 노출
