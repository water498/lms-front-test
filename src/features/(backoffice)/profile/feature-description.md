# 강사 프로필

수강생에게 표시되는 강사 프로필 정보를 편집하는 페이지.

## 누가, 언제
- **역할**: 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 계정 > 프로필
- **URL**: /backoffice/account
- **목적**: 강사 본인의 공개 프로필 정보 편집

## 화면 구성
### 레이아웃
단일 컬럼 폼 (max-w-2xl). 상단 제목 + 프로필 폼 카드 + 저장 버튼.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 헤드라인 입력 | 한 줄 소개 (예: "풀스택 개발자 · 7년 경력") | 편집 |
| 전문 분야 입력 | 기술/분야 태그 (예: "React, Node.js") | 편집 |
| 강사 소개 (textarea) | 강의 철학, 경험 등 | 편집 |
| 경력 사항 (textarea, mono) | 줄바꿈으로 구분된 경력 | 편집 |
| 소속 기관 입력 | 소속 회사/기관명 | 편집 |
| 웹사이트 URL 입력 | 개인 웹사이트 | 편집 |
| 프로필 공개 토글 | 비공개 시 강사 목록에 미표시 | ON/OFF |
| 저장 버튼 | 프로필 저장 | "저장됨" 피드백 2초 표시 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 저장 전 | "저장" 버튼 (violet) |
| 저장 직후 | "저장됨" 버튼 + 체크 아이콘 (emerald, 2초) |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorProfile | instructor | 강사 프로필 (헤드라인, 분야, 소개, 경력, 공개여부) |

## 비즈니스 규칙
- 프로필 공개 여부(isPublic)로 강사 목록 노출 제어
- 모든 필드는 선택사항 (optional)
