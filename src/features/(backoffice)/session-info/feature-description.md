# 차수 정보 (Admin)

차수(CourseSession)의 기본 정보를 조회하고 편집하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 차수 이름, 상태, 일정, 정원, 강사, 수료 기준 등 |
| OrgTeam | org | 수강 대상 부서 |
| OrgPosition | org | 수강 대상 직급 |
| OrgSite | org | 수강 대상 사업장 |

## 화면 구성

### 읽기 모드
- 상태 뱃지 (준비중/모집중/진행중/종료/폐강) + 차수 이름
- 유형 (자유수강 / 정규 N기), 기간, 수강신청 기간
- 정원/수강 현황, 강사 (주강사 + 보조 수), 장소 (오프라인만)
- 판매/공개 여부, 수료 기준 진도율, 오프라인 출석 기준
- 최소 수강 인원 (COHORT만), 수강 대상 (사업장/부서/직급 태그)
- 편집 버튼

### 편집 모드
- 차수 이름, 상태 셀렉트, 정원 입력
- 시작일/종료일/수강신청 기간 (COHORT만)
- 강사 목록: 역할(주/보조) 토글, 삭제, 후보 추가
- 장소 입력 (오프라인만)
- 수료 기준 진도율 — 수강생 있으면 잠금(Lock)
- 오프라인 출석 기준 — 수강생 있으면 잠금
- 최소 수강 인원 (COHORT만)
- 공개/판매 토글
- 수강 대상: 사업장/부서/직급 필 토글 (빈 값 = 제한 없음)
- 저장/취소 버튼

## 비즈니스 규칙

- 수강생이 있는 차수(enrolled > 0)는 수료 기준, 출석 기준 수정 불가
- 수강 대상을 비워두면 전체 대상으로 운영
