# 강사 담당 차수 (Admin)

강사 역할 사용자가 배정된 차수 목록을 조회하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 차수 정보 |
| SessionInstructor | instructor | 강사-차수 배정 (역할: 주강사/보조강사) |

## 화면 구성

- 담당 차수 테이블: 과정명, 차수명, 역할(주 강사/보조 강사 뱃지), 수강생 수, 시작일, 종료일
- 배정된 차수 없으면 빈 상태 안내

## 비즈니스 규칙

- 강사 역할(INSTRUCTOR) 사용자에게만 탭 노출
