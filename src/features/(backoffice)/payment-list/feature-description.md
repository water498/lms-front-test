# 결제 관리 (Admin)

학습자 결제(Payment) 내역을 조회하고 환불을 처리하는 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Payment | payment | 결제 기록 |
| Order | payment | 주문 |
| OrderItem | payment | 주문 항목 (과정 단위) |

## 화면 구성

- 상태 필터: 전체 / 결제 완료 / 환불 / 취소
- 결제 합계 표시 (PAID 건의 총액)
- 테이블 컬럼: 주문번호, 학습자, 과정, 정가, 할인, 결제액, 수단(카드/계좌이체/카카오페이/네이버페이), 상태, 결제일, 액션
- 환불 처리 버튼

## B2C/B2B 분기

- 이 메뉴는 B2C 테넌트에서만 활성화 (B2B 조직은 개인 결제 없음)
- 상단에 B2C 전용 안내 배너 표시
