# 결제 관리

학습자 결제 내역을 조회하고 환불을 처리하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 재무 > 결제
- **URL**: /backoffice/finance/payments
- **목적**: 결제 현황 파악, 환불 처리

## 화면 구성
### 레이아웃
B2C 전용 안내 배너 + 상태 필터 + 결제 합계 + 결제 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| B2C 안내 배너 (amber) | "이 메뉴는 B2C 테넌트에서만 활성화됩니다" | 읽기 전용 |
| 상태 필터 | 전체/결제 완료/환불/취소 | 테이블 필터 |
| 결제 합계 | PAID 건의 총 결제액 | 읽기 전용 |
| 결제 테이블 | 주문번호, 학습자, 과정, 정가, 할인, 결제액, 수단, 상태, 결제일 | - |
| 환불 버튼 | 결제 완료 건의 환불 처리 | 환불 실행 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 결제 내역 있음 | 테이블 + 합계 |
| 필터 결과 없음 | 빈 테이블 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| PAID 상태 | 환불 버튼 표시 |
| REFUNDED/CANCELLED | 환불 버튼 숨김 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| Payment | payment | 결제 기록 (금액, 수단, 상태) |
| Order | payment | 주문 (주문번호, 정가, 할인) |
| OrderItem | payment | 주문 항목 (과정 단위) |

## 비즈니스 규칙
- 결제 상태: PAID(결제 완료), REFUNDED(환불), CANCELLED(취소)
- 결제 수단: CARD(카드), BANK_TRANSFER(계좌이체), KAKAO_PAY, NAVER_PAY
- 주문 1건에 여러 과정 포함 가능 ("외 N건" 표시)

## B2C/B2B 분기
- 이 페이지는 B2C 테넌트에서만 활성화
- B2B 조직(SSO 테넌트)에서는 개인 결제 기능 없음
- 상단에 B2C 전용 안내 배너 표시
