# 설문 템플릿 목록

설문 템플릿을 조회하고 새 설문을 생성하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 리소스 > 평가 > 설문 탭
- **URL**: /backoffice/resources/assessments/surveys
- **목적**: 등록된 설문 템플릿을 확인하고 에디터로 이동

## 화면 구성
### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 설문 테이블 | 제목, 트리거, 문항 구성(섹션별 출제 수 합), 응답 수, 익명 여부, 상태 | 에디터로 이동 |
| + 새 설문 버튼 | 새 설문 생성 | /backoffice/resources/assessments/survey/new |
| 문항 뱅크 버튼 | 문항 뱅크로 이동 | question-bank 페이지 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 설문 있음 | 테이블에 행 표시 |
| 설문 없음 | 빈 상태 안내 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | assessment-survey-editor | 행 클릭 또는 새 설문 |
| 이동 | assessment-question-bank | 문항 뱅크 버튼 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| SurveyTemplate | assessment | 설문 템플릿 (트리거, 익명여부, 출제규칙) |

## 비즈니스 규칙
- 트리거: MANUAL(수동), COURSE_COMPLETE(과정 완료 시 자동)
- 익명 응답 여부 표시
- 응답 수는 누적 카운트
