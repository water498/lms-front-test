# 강사 정산 (Admin)

강사의 수익 정산 내역을 조회하고, 확정/지급 처리를 수행하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorRevenue | instructor | 강사 수익 (유형, 기간, 총 매출, 실 지급액, 상태) |

## 화면 구성

### 섹션: 요약 카드 (3개)
- 정산 대기 총액
- 지급 예정 총액
- 누적 지급액

### 섹션: 정산 테이블
- 정산 유형 (과정 판매/고정 계약/보너스/조정)
- 정산 기간, 총 매출, 실 지급액, 상태(정산 대기/확정/지급 완료), 지급일
- 액션: 대기 → "확정" 버튼, 확정 → "지급 처리" 버튼

## 비즈니스 규칙

- 정산 흐름: PENDING → APPROVED → PAID
- 강사 역할 사용자에게만 탭 노출
