# 과정 기본정보

과정의 기본 속성(제목, 카테고리, 강사, 태그, 소개, 가격, 취소 규정 등)을 편집하는 폼 페이지.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 과정 상세 > 기본정보 탭
- **URL**: `/backoffice/courses/[courseId]/info`
- **목적**: 과정 메타데이터 관리, 상태 전환(게시/폐강), 취소/환불 규정 설정

## 화면 구성

### 레이아웃

```
┌──────────────────────────────────────┐
│ [임시저장] [게시하기]                  │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │    썸네일 이미지 업로드 (dashed)   │ │
│ └──────────────────────────────────┘ │
│                                      │
│ 과정명:    [___________________]     │
│ 카테고리:  [드롭다운______] [+]       │
│ 대표 강사: [드롭다운______]           │
│ 태그:      [태그1][태그2][입력...]    │
│ 수업 유형: (o)온라인 ( )오프라인 ( )혼합│
│ 과정 소개: [리치 에디터__________]    │
│ 판매가:    [____] 원                 │
│ 최소 수강: [____] 명                 │
│                                      │
│ 취소·환불 규정                        │
│ ┌────────────────────────────────┐   │
│ │ N일 이상 전 취소 │ 환불율 │ 삭제 │   │
│ │ [7]일           │ [100]% │  x  │   │
│ │ [3]일           │ [50]%  │  x  │   │
│ │ [+ 규정 추가]                  │   │
│ │ [v] 수강 시작 후 환불 없음     │   │
│ └────────────────────────────────┘   │
│                                      │
│                          [저장]       │
└──────────────────────────────────────┘
```

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 상태 배지 | 현재 상태(게시됨/임시저장/보관됨) 표시 | - |
| 게시하기 버튼 | DRAFT일 때 표시 | PUBLISHED로 전환 |
| 폐강 처리 버튼 | PUBLISHED일 때 표시 | 폐강 확인 모달 열기 |
| 썸네일 영역 | dashed border 플레이스홀더 | 이미지 업로드 (미구현) |
| 카테고리 + 버튼 | 계층형 카테고리 셀렉트 + 인라인 생성 | 새 카테고리 입력 UI 전환 |
| 태그 입력 | 칩 형태 + 자동완성 | Enter/쉼표로 추가, Backspace로 삭제 |
| 리치 에디터 | 과정 소개 본문 | 서식 편집 |
| 취소 규정 테이블 | daysBeforeStart / refundPct 행 | 값 직접 편집, 행 삭제 |
| 저장 버튼 | 환불 규정 daysBeforeStart 내림차순 정렬 후 저장 | API 호출 (미구현) |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| DRAFT | 노란 배지 + "게시하기" 버튼 표시 |
| PUBLISHED | 초록 배지 + "폐강 처리" 버튼 표시 |
| ARCHIVED | 회색 배지, 전환 버튼 없음 |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| 카테고리 + 버튼 클릭 | 인라인 입력 필드 표시 (Enter로 추가, Esc로 취소) |
| 태그 입력 중 | 기존 태그 중 매칭되는 자동완성 드롭다운 표시 |
| 선수과정 섹션 | MVP 이후로 숨김 처리 |
| 수료증 설정 | 설계 > 수료설정 탭으로 이동됨 (이 탭에서 제거) |

## 모달

### 폐강 확인 모달
- **용도**: PUBLISHED -> ARCHIVED 전환 전 경고
- **내용**: "폐강된 과정은 수강생에게 노출되지 않습니다. ONGOING 상태의 차수가 있다면 먼저 종료해 주세요."
- **버튼**: 취소 / 폐강 처리(빨간색)
- **동작**: 확인 시 상태를 ARCHIVED로 변경

## 연결 페이지

| 방향 | 대상 | 조건 |
|------|------|------|
| 부모 | 과정 레이아웃 (`/backoffice/courses/[courseId]`) | 탭 네비게이션 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 기본정보 (title, category, instructor, tags, description, price, mode 등) |
| CancellationPolicy | course | 취소/환불 규정 (noRefundAfterStart, rules[]) |
| CancellationRule | course | 환불 규정 행 (daysBeforeStart, refundPct) |
| CoursePrerequisite | course | 선수과정 (MVP 이후, 현재 숨김) |

## 비즈니스 규칙

- 상태 전이: DRAFT -> PUBLISHED -> ARCHIVED (단방향)
- 대표 강사는 과정 수준 설정이며, 실제 운영 강사는 차수별로 설정한다.
- 판매가 빈 값 = 무료 과정, 최소 수강 인원 빈 값 = 미설정
- 취소 규정 저장 시 daysBeforeStart 내림차순 자동 정렬
- 카테고리는 계층형(대 > 중 > 소) 구조이며 인라인으로 새 카테고리 추가 가능
- 태그는 기존 태그 자동완성 + 자유 입력 모두 지원
