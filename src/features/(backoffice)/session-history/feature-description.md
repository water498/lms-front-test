# 차수 학습 이력 (Admin)

차수 내 레슨 완료 기록과 시험 응시 기록을 조회하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| ActivityCompletion | progress | 레슨(Activity) 완료 기록 (완료일, 학습시간) |
| ExamAttempt | assessment/exam | 시험 응시 기록 (점수, 합격 여부, 소요시간) |

## 화면 구성

### 섹션: 레슨 완료 이력
- 학습자별 필터 셀렉트 (전체/개별)
- 테이블: 학습자, 레슨명, 완료일시, 학습시간
- 하단 총 건수 표시

### 섹션: 시험 응시 기록
- 테이블: 학습자, 시험명, 점수, 결과(합격/불합격 뱃지), 제출일시, 소요시간
- 하단 총 건수 + 합격/불합격 건수 요약

## 비즈니스 규칙

- 학습시간은 초 단위로 저장, 분/초로 변환 표시
