# 강사 정산

강사별 수익 정산 현황을 관리하고 지급을 처리하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 재무 > 강사 정산
- **URL**: /backoffice/finance/payouts
- **목적**: 정산 대기 건 확인, 정산 확정, 지급 처리

## 화면 구성
### 레이아웃
요약 카드 3개 + 상태/유형 필터 + 정산 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 요약 카드 (3개) | 정산 대기 총액(amber), 이번 달 지급 예정(blue), 누적 지급액(green) | 읽기 전용 |
| 상태 탭 | 전체/정산 대기/확정/지급 완료 | 테이블 필터 |
| 유형 필터 | 전체/과정 판매/고정 계약/보너스/조정 | 테이블 필터 |
| 정산 테이블 | 강사, 유형, 기간, 총 매출, 수수료, 실 지급액, 상태, 지급일 | - |
| 강사명 링크 | 강사 상세 페이지로 이동 | 강사 페이지 |
| "정산 확정" 버튼 | PENDING -> APPROVED 전환 | 상태 변경 |
| "지급 처리" 버튼 | APPROVED -> PAID 전환 | 상태 변경 + 지급일 기록 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 정산 내역 있음 | 테이블 + 요약 카드 |
| 필터 결과 없음 | "해당 조건의 정산 내역이 없습니다" |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | 강사 상세 | 강사명 클릭 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorRevenue | instructor | 강사 수익 정산 기록 (매출, 수수료, 상태) |

## 비즈니스 규칙
- 정산 흐름: PENDING -> APPROVED -> PAID
- 정산 유형: COURSE_SALE(과정 판매), FLAT_FEE(고정 계약), BONUS(보너스), ADJUSTMENT(조정)
- 수수료 = 총 매출 x commissionRate (기본 20%)
- 실 지급액 = 총 매출 - 수수료
