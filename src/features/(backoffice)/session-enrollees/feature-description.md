# 차수 수강생 (Admin)

차수에 등록된 수강생 목록을 조회하고, 수강생을 추가하거나 상세 정보를 확인하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseEnrollee | enrollment | 수강 등록 (학습자, 진행률, 신청일) |
| User | user | 학습자 정보 |

## 화면 구성

- 수강생 수 표시 + "수강생 추가" 버튼
- 수강생 테이블: 이름(클릭 시 사이드 드로어), 진행률 바, 수강 신청일
- 수강생 없으면 빈 상태 안내

## 모달

### 수강생 추가 (AddLearnerModal)
- 기존 등록자 제외한 사용자 검색/선택하여 차수에 수강생 추가

### 사용자 드로어 (UserDrawer)
- 수강생 이름 클릭 시 우측 사이드 드로어로 상세 프로필 표시

## 비즈니스 규칙

- 이미 등록된 학습자는 추가 모달에서 제외
