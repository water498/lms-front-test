# 차수 수강생 관리

차수에 등록된 수강생 목록을 확인하고, 새 수강생을 추가하거나 학습자 상세 정보를 조회하는 화면.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > 수강생 탭
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/enrollees`
- **목적**: 차수별 수강생 등록 현황 확인 및 수강생 추가

## 화면 구성

### 레이아웃
```
┌──────────────────────────────────┐
│  N명                [+ 수강생 추가] │
├──────────────────────────────────┤
│  학습자     | 진행률      | 수강 신청일 │
│  ─────────────────────────────── │
│  김철수     | ████░░ 65% | 2025-02-01 │
│  이영희     | ██████ 90% | 2025-02-03 │
│  ...                             │
└──────────────────────────────────┘
         ┌────────────────┐
         │ UserDrawer      │ ← 이름 클릭 시 우측 슬라이드
         └────────────────┘
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 수강생 수 표시 | 좌상단 "N명" 텍스트 | — |
| 수강생 추가 버튼 | 우상단 바이올렛 버튼 | AddLearnerModal 열기 |
| 수강생 테이블 | 이름, 진행률 바+%, 수강 신청일 | — |
| 학습자 이름 | 테이블 내 클릭 가능한 텍스트 | UserDrawer 열기 |
| 진행률 바 | 바이올렛 프로그레스 바 + 퍼센트 | — |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 수강생 0명 | 점선 테두리 빈 상태: "수강생이 없습니다." |
| 수강생 존재 | 테이블에 학습자 목록 표시 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| enrollees.length === 0 | 빈 상태 UI (점선 테두리 + 안내 문구) |

## 모달

### 수강생 추가 (AddLearnerModal)
- **용도**: 차수에 새 수강생을 등록
- **탭 구조**: 개인 / 그룹 / 조직 3개 탭
- **개인 탭**: 이름/이메일 검색, 체크박스로 개별 선택. 이미 수강 중인 사용자는 비활성
- **그룹 탭**: 사용자 그룹 카드 목록, 그룹 체크박스로 멤버 일괄 선택
- **조직 탭**: 사업장/부서(트리)/직급 3열 필터, 조건 해당 인원 전체 선택
- **하단**: 선택 인원 수 표시 + 확인/취소 버튼
- **제약**: 이미 등록된 학습자는 선택 불가 (체크박스 비활성, "이미 수강 중" 표시)

### UserDrawer
- **용도**: 학습자 상세 정보 확인 (이름 클릭 시 우측 슬라이드 패널)
- **내용**: course-enrollees 공유 컴포넌트 재사용

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 상위 | 과정 상세 차수 탭 | 탭 네비게이션 |
| 동일 레벨 | 대시보드/채점/Q&A/자료실/오프라인 탭 | 탭 전환 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseEnrollee | course | 수강 등록 정보 (진도율, 수강 신청일) |
| User | user | 학습자 정보 (이름, 이메일, 조직 소속) |
| UserGroup | user | 사용자 그룹 (그룹 탭에서 사용) |
| OrgStructure | org | 조직 구조 (사업장, 부서, 직급) |

## 비즈니스 규칙

- 이미 등록된 학습자는 모달에서 중복 추가 불가
- 그룹 선택 시 이미 수강 중인 멤버는 자동 제외
- 조직 탭은 사업장/부서/직급 교차 필터링 (AND 조건)
- 선택된 학습자 수는 모든 탭에서 공유 (탭 전환해도 유지)

## B2C/B2B 분기 (해당 시)

- 조직 탭(사업장/부서/직급 필터)은 B2B 전용 기능
- B2C에서는 개인 탭과 그룹 탭만 유효
