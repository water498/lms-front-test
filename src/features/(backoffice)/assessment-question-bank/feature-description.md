# 문항 뱅크

시험용/설문용 문항을 그룹별로 관리하고 편집하는 전체 화면 에디터.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 평가 목록의 "문항 뱅크" 버튼
- **URL**: /backoffice/resources/assessments/question-bank
- **목적**: 문항 생성·편집·삭제, 그룹 관리, 문항 태깅

## 화면 구성
### 레이아웃
```
[상단 바: 뒤로가기 | 문항 뱅크 | 시험용/설문용 탭 | + 문항 추가]
[좌측: 문항 그룹] [중앙: 문항 목록] [우측: 문항 에디터]
```
전체 화면 3-panel 구조.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 시험용/설문용 탭 | EXAM/SURVEY 문항 종류 전환 | 해당 종류 필터 |
| 문항 그룹 패널 (좌) | 전체/그룹별 필터. 드래그 앤 드롭 수신 대상 | 해당 그룹 필터 |
| 그룹 컨텍스트 메뉴 | 편집, 보관 | 모달/보관 처리 |
| 문항 목록 (중) | 문항 텍스트, 유형 뱃지, 미배정 표시. 드래그 가능 | 해당 문항 에디터 표시 |
| 문항 에디터 (우) | 문항 텍스트, 유형별 선지/미리보기, 태그, 삭제 | 편집 |
| + 그룹 추가 (좌 하단) | 새 문항 그룹 생성 | PoolModal 열기 |
| + 문항 추가 (중 하단/상단) | 새 문항 생성 | 목록에 추가 후 선택 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 문항 없음 | "문항이 없습니다" 안내 |
| 문항 미선택 | 우측 빈 상태 + "새 문항 추가" 버튼 |
| EXAM 문항 - 객관식 | 선지 편집(정답 지정) + 해설 입력 |
| EXAM 문항 - O/X | 고정 선지(True/False) + 해설 입력 |
| EXAM 문항 - 주관식 | 모범 답안(선택) + "점수 미산정" 안내 |
| SURVEY 문항 - 리커트 | 5/7점 척도 원형 미리보기 |
| SURVEY 문항 - 자유 서술 | 텍스트 입력 영역 미리보기 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| EXAM 모드 | 객관식(단일/복수), O/X, 주관식 유형 |
| SURVEY 모드 | 리커트, 객관식(단일/복수), 자유 서술 유형 |
| 미배정 문항 | amber "미배정" 뱃지 표시 |

## 모달
### 문항 그룹 편집 모달 (PoolModal)
- 용도: 새 문항 그룹 생성 또는 기존 그룹명/설명 수정
- 필드: 그룹 이름(필수), 설명(선택)

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 뒤로가기 | 평가 관리 (시험/과제/설문 목록) | 항상 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| Question | assessment | 문항(종류, 유형, 선지, 태그, 해설) |
| QuestionGroup | assessment | 문항 그룹(EXAM/SURVEY, 보관 여부) |

## 비즈니스 규칙
- 문항은 드래그 앤 드롭으로 그룹 간 이동 가능 (미배정으로도 이동)
- 그룹 보관 시 목록에서 숨김 (소속 문항은 유지)
- 태그는 기존 태그 기반 자동완성 지원 (Enter로 추가)
- O/X 유형은 선지 추가/삭제 불가 (True/False 고정)
- 주관식(SHORT) 문항은 점수 산정에서 제외
