# 시험 템플릿 목록

시험 템플릿을 조회·관리하고 새 시험을 생성하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 리소스 > 평가 > 시험 탭
- **URL**: /backoffice/resources/assessments/exams
- **목적**: 등록된 시험 템플릿을 확인하고 편집·보관·삭제

## 화면 구성
### 레이아웃
상단 필터 + 테이블 형태. ExamTable 섹션 컴포넌트로 구성.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 필터 탭 (활성/보관됨/전체) | 시험 상태별 필터링 | 해당 상태 목록 표시 |
| 시험 행 | 제목, 유형(단답/최종), 사용 과정 수, 생성일 | 에디터 페이지로 이동 |
| + 새 시험 버튼 | 새 시험 템플릿 생성 | /backoffice/resources/assessments/exam/new |
| 문항 뱅크 버튼 | 문항 뱅크로 이동 | question-bank 페이지 |
| 보관/복원 버튼 | 활성 <-> 보관 전환 | 상태 토글 |
| 삭제 버튼 | 템플릿 완전 삭제 | 목록에서 제거 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 시험 있음 | 테이블에 행 표시 |
| 시험 없음 | 빈 상태 안내 |
| 보관됨 필터 | 보관된 시험만 표시 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 보관된 시험 | 복원 버튼 표시 |
| 활성 시험 | 보관 버튼 표시 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | assessment-exam-editor | 행 클릭 또는 새 시험 |
| 이동 | assessment-question-bank | 문항 뱅크 버튼 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| ExamTemplate | assessment | 시험 템플릿 (유형, 통과점수, 출제 규칙) |

## 비즈니스 규칙
- 시험 유형: SHORT(단답 시험), FINAL(최종 시험)
- 보관 시 목록에서 숨김 처리, 복원으로 재활성화
