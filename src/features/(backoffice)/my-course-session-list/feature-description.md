# 내 과정 목록 (instructor)

강사가 담당하는 과정 차수(세션) 목록을 카드 형태로 표시하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionInstructor | course | 강사-세션 배정 |
| Session | course | 과정 차수 |
| Enrollment | progress | 수강 등록 |

## 화면 구성

### 섹션: 세션 카드 목록
- 역할 배지(주 강사/보조 강사), 진행 상태(진행 중/종료)
- 과정명, 차수명, 수강생 수(활성 인원 별도 표시), 기간
- 카드 클릭 시 해당 세션 상세(session-layout)로 이동
- 담당 과정이 없으면 빈 상태 메시지 표시

## 비즈니스 규칙

- 종료일이 없는 세션은 "진행 중"으로 표시
- 활성 수강생 수는 enrollment status가 ACTIVE인 건만 집계
