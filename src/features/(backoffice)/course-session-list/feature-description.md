# 차수 전체 목록 (Admin)

전체 과정의 차수(CourseSession)를 한 곳에서 조회하는 통합 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 과정 차수 (기간, 정원, 상태) |
| Course | course | 소속 과정 |

## 화면 구성

- 필터: 과정별 드롭다운, 상태별 드롭다운 (초안/모집중/진행중/종료/폐강)
- 결과 건수 표시
- 테이블 컬럼: 과정명, 차수명, 유형(정규/상시), 상태, 수강생(현재/정원), 기간
- 차수명 클릭 시 차수 상세 페이지로 이동

## 비즈니스 규칙

- 유형: COHORT(정규) — 기간 제한, SELF_PACED(상시) — 상시 운영
- 상태: DRAFT > OPEN > ONGOING > CLOSED, 또는 CANCELLED
