# 포털 테마

학습자 포털의 브랜드 컬러를 설정하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 포털 > 테마
- **URL**: /backoffice/org/portal/theme
- **목적**: 포털의 메인 컬러를 설정하여 브랜딩 적용

## 화면 구성
### 레이아웃
단일 컬럼 폼 (max-w-lg).

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 프리셋 컬러 (8색) | violet, blue, cyan, emerald, amber, red, pink, slate | 해당 색상 선택 |
| HEX 직접 입력 | 커스텀 컬러 코드 입력 + 미리보기 사각형 | 값 변경 |
| 적용 예시 | 헤더 배경, 버튼 스타일 실시간 프리뷰 | 읽기 전용 |
| 저장 버튼 | 테마 저장 | 저장 실행 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgSettings | org | 조직 설정 (brandColor) |

## 비즈니스 규칙
- 메인 컬러는 포털 헤더, 버튼, 링크 등에 일괄 적용
- 프리셋 선택 또는 HEX 직접 입력 가능
