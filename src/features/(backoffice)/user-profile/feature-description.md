# 유저 프로필

유저의 계정 정보, 학습 현황, 조직 이동 이력을 조회하고 역할 변경/계정 관리를 수행하는 탭.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 유저 상세 > 기본 정보 탭
- **URL**: /backoffice/org/users/[uid]/profile
- **목적**: 유저 계정 정보 확인, 역할 변경, 계정 관리, 임퍼소네이션

## 화면 구성
### 레이아웃
2열 그리드. 프로필 헤더(전체 너비) + 계정 정보/학습 현황(각 1열) + 계정 관리/강사 프로필/조직 이동 이력(전체 너비).

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 프로필 헤더 | 아바타, 이름, 역할 뱃지, 상태 뱃지, 이메일 | - |
| "이 유저로 보기" 버튼 | 학습자 화면으로 임퍼소네이션 | /student 이동 |
| "역할 변경" 버튼 | 역할 변경 모달 열기 | 모달 표시 |
| 계정 정보 카드 | 이메일, 역할, 가입일, 마지막 로그인, 인증 방식 | 읽기 전용 |
| 학습 현황 카드 | 수강/완료 과정 수, 수료증 수, 사업장/부서/직급 | 읽기 전용 |
| 계정 관리 | 비밀번호 초기화, 계정 비활성화 | 해당 액션 |
| 강사 프로필 섹션 | 한 줄 소개, 전문 분야, 유형, 소개, 경력, 공개 토글 | 읽기/토글 |
| 조직 이동 이력 | 날짜별 사업장/부서/직급 변경 타임라인 | 읽기 전용 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| LEARNER 역할 | "이 유저로 보기" 버튼 표시 |
| SUPER_ADMIN 역할 | 역할 변경 버튼 숨김 |
| ACTIVE + 비 SUPER_ADMIN | 계정 관리 섹션 표시 |
| INSTRUCTOR 역할 | 강사 프로필 섹션 표시 |
| 조직 이동 이력 있음 | 타임라인 섹션 표시 |

## 모달
### 역할 변경
- 수강생/강사/관리자 중 라디오 선택 후 "변경 적용"
- SUPER_ADMIN은 변경 대상 아님

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | /student | "이 유저로 보기" (임퍼소네이션) |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 유저 (이름, 이메일, 역할, 상태, 인증 방식) |
| OrgTeam | org | 소속 부서 |
| OrgPosition | org | 직급 |
| OrgSite | org | 사업장 |
| InstructorProfile | instructor | 강사 프로필 (INSTRUCTOR만) |
| OrgTransfer | org | 조직 이동 이력 |

## 비즈니스 규칙
- 인증 방식: LOCAL(이메일/비밀번호), SOCIAL(구글/카카오/네이버/애플), SSO(회사 계정)
- SSO 사용자는 IdP 관리 필드가 읽기 전용
- 임퍼소네이션은 LEARNER 역할에만 허용
