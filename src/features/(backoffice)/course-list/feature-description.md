# 과정 목록

Backoffice에서 관리하는 전체 과정을 테이블 형태로 조회하고, 새 과정을 생성하는 진입점.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 과정 관리
- **URL**: `/backoffice/courses`
- **목적**: 과정 전체 현황 파악, 상태별 필터링, 새 과정 생성, 과정 상세 진입

## 화면 구성

### 레이아웃

```
┌─────────────────────────────────────────────┐
│ [전체][게시됨][임시저장][보관됨]  [검색...]  [+ 새 과정] │
├─────────────────────────────────────────────┤
│ 과정명          │ 강사  │ 상태  │ 차수 │ 수강생 │ 생성일 │
│ ─────────────── │ ───── │ ───── │ ──── │ ────── │ ────── │
│ 산업안전교육     │ 김안전 │ 게시됨 │  3  │  177  │ 24.01  │
│  [온라인] [안전] │       │       │     │       │        │
│ ...             │       │       │     │       │        │
└─────────────────────────────────────────────┘
```

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 상태 필터 탭 | 전체 / 게시됨 / 임시저장 / 보관됨 | 해당 상태만 필터링 |
| 검색 입력창 | 과정명 또는 강사명으로 검색 | 실시간 필터링 |
| + 새 과정 버튼 | 바이올렛 CTA 버튼 | 새 과정 생성 모달 열기 |
| 과정 행 | 과정명(모드 배지 + 카테고리), 강사, 상태, 차수, 수강생, 생성일 | 과정 상세(`/backoffice/courses/{id}`)로 이동 |
| 모드 배지 | 온라인(하늘), 오프라인(주황), 혼합(보라) | - |
| 상태 배지 | 게시됨(초록), 임시저장(노랑), 보관됨(회색) | - |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| 과정 존재 | 테이블에 행 표시 |
| 검색 결과 없음 | "검색 결과가 없습니다." 중앙 메시지 |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| 필터 = 전체 | 모든 과정 표시 |
| 필터 = 특정 상태 | 해당 상태만 표시 |
| 검색어 입력 | 과정명 또는 강사명에 포함된 행만 표시 |

## 모달

### 새 과정 만들기
- **용도**: 과정 초기 정보 입력 후 DRAFT 상태로 생성
- **필드**: 과정명(텍스트), 카테고리(셀렉트, 최상위 카테고리만), 강사(셀렉트), 수업 유형(라디오: 온라인/오프라인/혼합)
- **동작**: 생성 클릭 시 DRAFT 상태 과정 생성 후 과정 상세 페이지로 리다이렉트
- **안내**: "생성하면 DRAFT로 저장되며, 상세 페이지에서 썸네일/소개/취소규정 등을 설정할 수 있습니다."

## 연결 페이지

| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | 과정 상세 (`/backoffice/courses/{id}`) | 행 클릭 |
| 이동 | 과정 상세 (DRAFT) | 새 과정 생성 완료 시 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 템플릿 (title, instructor, status, mode, category, sessions, enrollees, createdAt) |

## 비즈니스 규칙

- 새로 생성된 과정은 항상 DRAFT 상태로 시작한다.
- 상태 값: PUBLISHED(게시됨), DRAFT(임시저장), ARCHIVED(보관됨)
- 모드 값: ONLINE(온라인), OFFLINE(오프라인), BLENDED(혼합)
- 검색은 과정명과 강사명 모두 매칭한다(OR 조건).
