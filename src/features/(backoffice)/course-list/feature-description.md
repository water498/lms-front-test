# 과정 목록 (Admin)

전체 과정(Course) 템플릿을 조회하고 새 과정을 생성하는 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 템플릿 |
| CourseCategory | course | 과정 카테고리 |

## 화면 구성

- 상태별 필터 탭: 전체 / 게시됨 / 임시저장 / 보관됨
- 검색: 과정명 또는 강사명으로 필터
- 테이블 컬럼: 과정명, 강사, 카테고리, 모드(온라인/오프라인/혼합), 상태, 수강생 수
- 과정명 클릭 시 과정 상세(course-layout)로 이동
- "+ 새 과정" 버튼

## 모달

### 새 과정 만들기
- 필드: 과정명, 카테고리(대분류), 강사, 유형(온라인/오프라인/혼합)
- 생성 후 DRAFT 상태의 과정 상세 페이지로 이동

## 비즈니스 규칙

- 새 과정은 항상 DRAFT 상태로 생성
