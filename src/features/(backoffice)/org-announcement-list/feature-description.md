# 플랫폼 공지

플랫폼 운영팀에서 전달한 공지사항을 읽기 전용으로 조회하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 플랫폼 공지
- **URL**: /backoffice/org/announcements
- **목적**: 플랫폼 운영팀이 발신한 공지(긴급, 점검, 업데이트 등) 확인

## 화면 구성
### 레이아웃
상단 안내 문구 + 공지 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 안내 문구 | "플랫폼 운영팀에서 전달한 공지입니다 (읽기 전용)" | - |
| 공지 테이블 | 유형 뱃지(긴급/점검/업데이트/일반), 제목, 발송 대상, 게시일 | 아코디언 펼침 |
| 상세 내용 (아코디언) | 공지 본문 | 토글 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 공지 있음 | 테이블에 행 표시 + 건수 |
| 공지 없음 | 빈 테이블 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| PlatformAnnouncement | platform | 플랫폼 공지 (유형, 제목, 내용, 상태) |

## 비즈니스 규칙
- PUBLISHED 상태의 공지만 표시
- 테넌트 관리자는 조회만 가능 (작성/수정/삭제 불가)
- 유형: URGENT(긴급), MAINTENANCE(점검), UPDATE(업데이트), GENERAL(일반)
