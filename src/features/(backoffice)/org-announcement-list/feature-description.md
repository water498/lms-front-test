# 플랫폼 공지 (Admin)

플랫폼 운영팀에서 전달한 공지사항을 읽기 전용으로 조회하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| PlatformAnnouncement | org | 플랫폼 공지 (긴급/점검/업데이트/일반) |

## 화면 구성

- 읽기 전용 안내 문구 표시
- 테이블 컬럼: 유형(긴급/점검/업데이트/일반), 제목, 발송 대상, 게시일
- 행 클릭 시 아코디언으로 상세 내용 펼침

## 비즈니스 규칙

- PUBLISHED 상태의 공지만 표시
- 테넌트 관리자는 조회만 가능 (작성/수정 불가 — 플랫폼 관리자 권한)
