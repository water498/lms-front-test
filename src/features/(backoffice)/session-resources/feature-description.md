# 차수 자료실

차수에 연결된 학습 자료(문서)를 분류별로 관리하고, 공개/비공개 설정 및 업로드를 수행하는 화면.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > 자료실 탭
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/resources`
- **목적**: 수강생 다운로드용 학습 자료 등록, 분류 관리, 공개 여부 제어

## 화면 구성

### 레이아웃
```
┌────────────────────────────────────┐
│  자료실                  [자료 등록] │
│  수강생이 다운로드할 수 있는 문서..  │
├────────────────────────────────────┤
│  ▼ 강의자료 (2건)                  │
│  ├ 📄 안전수칙 교재 (전체)  5.0MB  │
│  ├ 📊 1장 보충 슬라이드 [안전수칙..] │
│  ▼ 서식 (1건)                      │
│  ├ 📗 위험성 평가 체크리스트 102KB  │
│  ▼ 참고문헌 (1건)                  │
│  ├ 📄 참고 법령 모음 [비공개] 8.0MB │
└────────────────────────────────────┘
  각 행 hover 시: [공개/비공개] [편집] [삭제]
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 자료 등록 버튼 | 우상단 Upload 아이콘 + 텍스트 | AddResourceModal 열기 |
| 카테고리 헤더 | 분류명 + 건수, 접기/펼치기 가능 | 카테고리 토글 |
| 자료 행 | 파일 아이콘 + 제목 + 비공개 뱃지 + 과목 뱃지 + 설명 + 메타 | — |
| 공개/비공개 토글 | hover 시 노출되는 Eye/EyeOff 아이콘 | isVisible 전환 |
| 편집 버튼 | hover 시 노출되는 Pencil 아이콘 | (미구현) |
| 삭제 버튼 | hover 시 노출되는 Trash 아이콘 | 자료 삭제 |
| 파일 아이콘 | MIME 타입별 아이콘 (PDF=빨강, PPT=주황, XLS=초록) | — |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 자료 0건 | 점선 테두리 빈 상태: FileText 아이콘 + "등록된 자료가 없습니다" + "첫 자료 등록하기" 버튼 |
| 자료 존재 | 카테고리별 그룹핑된 목록 |
| 비공개 자료 | 행 배경 흐리게 + "비공개" 뱃지 |
| 과목 연결 자료 | 바이올렛 뱃지로 과목명 표시 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| isVisible = false | 행 배경 흐리게, "비공개" 뱃지 표시 |
| subjectTitle 존재 | 바이올렛 과목 뱃지 표시 |
| description 존재 | 제목 아래 설명 텍스트 표시 |
| 카테고리 접힘 | 해당 카테고리 자료 행 숨김 |

## 모달

### 자료 등록 (AddResourceModal)
- **용도**: 새 학습 자료 업로드
- **필드**: 파일 선택 (드래그 앤 드롭), 자료명 (파일명에서 자동 채움), 분류 (프리셋 4개 + 직접 입력), 설명 (선택)
- **허용 파일**: PDF, PPT, PPTX, DOC, DOCX, XLS, XLSX, HWP, HWPX, ZIP
- **동작**: 등록 시 isVisible=true로 자동 공개
- **제약**: 자료명과 파일 모두 필수. 미입력 시 등록 버튼 비활성

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 상위 | 과정 상세 차수 탭 | 탭 네비게이션 |
| 동일 레벨 | 대시보드/수강생/채점/Q&A/오프라인 탭 | 탭 전환 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionResource | course | 차수 학습 자료 (파일, 분류, 공개 여부) |
| CourseSession | course | 차수 식별 |

## 비즈니스 규칙

- 자료는 카테고리(강의자료, 참고문헌, 서식, 기타 등)로 그룹핑
- 카테고리 미지정 시 "미분류"로 자동 분류
- 비공개 자료는 관리자만 확인 가능, 수강생에게 미노출
- 자료는 특정 과목(subject)에 연결 가능 (선택 사항)
- 파일 크기와 업로더 정보가 메타데이터로 표시
