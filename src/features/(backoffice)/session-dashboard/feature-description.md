# 차수 대시보드 (Admin)

차수의 KPI, 진도율 분포, 수료 기준 미달 학습자를 한눈에 보고 독려/알림을 발송하는 대시보드.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 차수 상태, 수료 기준, 정원 등 |
| CourseEnrollee | enrollment | 수강생별 진행률 |

## 화면 구성

### 섹션: 라이프사이클 타임라인
- 단계 표시: 모집 준비 → 모집 중 → 진행 중 → 종료
- 현재 단계 강조, 폐강(CANCELLED) 시 배너 표시
- 등록 현황 (정원 대비), 최소 인원 미달 경고
- 개강/종강 D-Day 표시
- 다음 상태로 전환 버튼, 폐강 버튼
- 알림 발송 버튼 (컨텍스트 자동 계산)

### 섹션: KPI 카드 (4개)
- 수강 인원 (등록/정원)
- 평균 진도율
- 수료율 (기준 N% 기반)
- 수료 기준 미달 인원

### 섹션: 진도율 분포
- 0-24%, 25-49%, 50-74%, 75-99%, 100% 구간 막대 그래프

### 섹션: 수료 기준 미달 테이블
- 체크박스로 다중 선택 → 독려 메시지 발송
- 이름, 진도율 바, 수강 시작일 표시

## 모달

### 독려 메시지 (EncourageModal)
- 선택된 미달 학습자에게 독려 메시지 발송

### 알림 발송 (NotifyModal)
- 차수 전체 수강생 대상 알림 발송
- 수료 기준 미달 인원 수 표시
- 컨텍스트(모집 시작, 종강 임박, 독려 등) 자동 설정

## 비즈니스 규칙

- 폐강 상태면 타임라인 흐리게 표시 + 사유 배너
- 최소 인원 미달 시 "진행 중" 전환 경고 표시
