# 차수 대시보드

차수(Session)의 수강 현황, 진도율 분포, 수료 기준 미달 학습자를 한눈에 파악하고 독려/알림을 발송하는 대시보드.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > 대시보드 탭
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/dashboard`
- **목적**: 차수 라이프사이클 관리, 수강 현황 모니터링, 수료 기준 미달 학습자 독려

## 화면 구성

### 레이아웃
```
┌─────────────────────────────────────┐
│  라이프사이클 타임라인               │
│  [모집준비] ─ [모집중] ─ [진행중] ─ [종료]  │
│  등록 현황 · 일정 D-Day · 상태 전환 버튼    │
├─────────────────────────────────────┤
│  KPI 카드 x4                        │
│  수강인원 | 평균진도율 | 수료율 | 미달인원   │
├─────────────────────────────────────┤
│  진도율 분포 (5구간 수평 바 차트)     │
├─────────────────────────────────────┤
│  수료 기준 미달 테이블               │
│  [체크박스] 이름 | 진도 바 | 수강시작일     │
│              [독려 메시지 발송] 버튼         │
└─────────────────────────────────────┘
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 라이프사이클 바 | DRAFT > OPEN > ONGOING > CLOSED 4단계, 현재 단계 강조 | — |
| 상태 전환 버튼 | 다음 단계로 전환 (예: "모집 중(으)로 전환") | 상태 변경 |
| 폐강 버튼 | DRAFT/OPEN/ONGOING 에서 노출 | 차수 폐강 |
| 알림 발송 버튼 | 라이프사이클 영역 우상단 | NotifyModal 열기 |
| KPI 카드 | 수강 인원, 평균 진도율, 수료율, 미달 인원 | — |
| 진도율 분포 | 0-24 / 25-49 / 50-74 / 75-99 / 100% 5구간 | — |
| 미달 테이블 | completionThreshold 미만 학습자 목록, 체크박스 선택 | — |
| 독려 메시지 발송 | 선택된 학습자에게 독려 메시지 발송 | EncourageModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 수강생 0명 | KPI 0, 분포 "수강생 데이터가 없습니다", 미달 테이블 비어있음 |
| 전원 수료 달성 | 미달 섹션에 "모든 수강생이 수료 기준을 달성했습니다" 표시 |
| 미달자 존재 | 미달 카드 amber 하이라이트, 테이블에 학습자 목록 |
| CANCELLED | 폐강 배너 표시 (사유 포함), 타임라인 흐리게 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| OPEN + 최소 인원 미달 | amber 경고: "최소 인원 미달 (최소 N명)" |
| OPEN + minEnrollWarning | 상태 전환 시 경고 문구 표시 |
| capacity === 0 | 수강 인원에 "무제한" 표시 |
| ONGOING + 종강 7일 이내 | 알림 컨텍스트 자동으로 SESSION_CLOSE |
| CLOSED | 상태 전환 버튼 비노출 |

## 모달

### 독려 메시지 발송 (EncourageModal)
- **용도**: 수료 기준 미달 학습자에게 독려 메시지 발송
- **필드**: 발송 대상 (태그 표시), 메시지 템플릿 선택 (라디오), 메시지 미리보기/편집
- **채널**: 이메일 / 알림톡 / SMS (템플릿에 따라 결정)
- **제약**: 선택된 학습자가 0명이면 발송 버튼 비활성

### 알림 발송 (NotifyModal)
- **용도**: 차수 수강생 대상 일괄 알림 (모집 안내, 종강 안내 등)
- **필드**: 수신 대상 (전체 / 미달 / 미등록), 템플릿 선택, 제목 (이메일), 내용, 발송 시점 (즉시/예약)
- **동작**: 발송 완료 후 확인 화면 1.5초 표시 후 자동 닫힘
- **제약**: 내용 비어있거나 예약 발송인데 날짜 미선택 시 비활성

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 상위 | 과정 상세 차수 탭 | 탭 네비게이션 |
| 동일 레벨 | 수강생/채점/Q&A/자료실/오프라인 탭 | 탭 전환 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | course | 차수 (상태, 기간, 정원, 수료 기준) |
| CourseEnrollee | course | 수강생 등록 정보 (진도율 포함) |
| MessageTemplate | messaging | 독려/알림 메시지 템플릿 |

## 비즈니스 규칙

- 수료 기준(completionThreshold)은 차수 단위로 설정되며, 진도율이 기준 이상이면 수료
- 라이프사이클 전환은 DRAFT > OPEN > ONGOING > CLOSED 순서만 허용
- OPEN 상태에서 최소 인원(minEnrollment) 미달 시 전환 경고
- 폐강(CANCELLED) 시 사유 표시, 라이프사이클 비활성
- 독려 메시지는 미달 테이블에서 선택한 학습자에게만 발송
- 알림 발송은 수신 대상을 3가지(전체/미달/미등록)로 구분

## B2C/B2B 분기 (해당 시)

- NotifyModal의 "미등록 대상자" 옵션은 B2B 전용 (수강 대상자 중 미등록)
