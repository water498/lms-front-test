# 과정 상세 레이아웃 v2 (Backoffice)

과정 상세 페이지의 2단 탭 구조 레이아웃. 설계/운영 메타탭 + 각 메타탭 내부 서브탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 템플릿 |

## 화면 구성

### 과정 요약 바
- 과정명 + 상태 뱃지 (초안/게시됨/보관됨)
- 카테고리, 모드 표시

### 메타탭: 설계
- 에디터 느낌의 과정 설계 영역
- 서브탭: 기본정보 | 커리큘럼 | 수료설정

### 메타탭: 운영
- 운영 대시보드 느낌의 과정 운영 영역
- 서브탭: 차수 관리 | 리뷰

## 비즈니스 규칙

- pathname 기반으로 활성 메타탭/서브탭 자동 판단
- 과정 미존재 시 안내 메시지 표시
- CourseDetailProvider로 하위 탭에 context 공유
