# 설문 에디터

설문 템플릿의 섹션 구성과 출제 규칙을 설정하는 전체 화면 에디터.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 설문 목록에서 행 클릭 또는 + 새 설문
- **URL**: /backoffice/resources/assessments/survey/[id] (fullscreen)
- **목적**: 설문의 섹션 구성, 문항 그룹 연결, 트리거/익명 설정

## 화면 구성
### 레이아웃
```
[상단 바: 뒤로가기 | 제목 입력 | 총 문항 수 | 저장]
[좌측: 섹션 목록] [중앙: 섹션 편집기] [우측: 설문/섹션 설정]
```
전체 화면 3-panel 구조. 시험 에디터와 동일 레이아웃.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 섹션 목록 (좌) | 순서 변경, 선택, 추가. 그룹명·출제 수 표시 | 해당 섹션 편집 |
| 섹션 편집기 (중) | 섹션명, 문항 그룹, 유형 필터, 출제 수, 셔플 | 값 변경 |
| 문항 미리보기 (중 하단) | 선택된 그룹의 문항 목록 | 읽기 전용 |
| 트리거 설정 (우) | 수동 / 과정 완료 시 자동 | 값 변경 |
| 익명 응답 토글 (우) | 응답자 식별 여부 | ON/OFF |
| 섹션 설정 (우 하단) | 출제 수, 셔플, 섹션 삭제 | 값 변경 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 섹션 없음 | 빈 상태 + "첫 번째 섹션 추가" 버튼 |
| 섹션 선택됨 | 섹션 편집 폼 + 우측 섹션 설정 표시 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 출제 수 > 그룹 보유 문항 | 빨간색 경고, 저장 버튼 비활성화 |
| 유형 필터 적용 | 매칭 문항 수 갱신 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 뒤로가기 | assessment-survey-list | 항상 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| SurveyTemplate | assessment | 설문 메타(트리거, 익명) |
| AssessmentSection | assessment | 섹션별 출제 규칙(그룹, 출제 수, 셔플) |
| QuestionGroup | assessment | 문항 그룹(SURVEY 종류) |
| Question | assessment | 개별 문항(리커트/객관식/서술) |

## 비즈니스 규칙
- 설문 문항 유형: 리커트 척도, 객관식(단일/복수), 자유 서술
- 시험과 달리 셔플 기본값 false, 정답 개념 없음
- 트리거: MANUAL(수동) 또는 COURSE_COMPLETE(과정 완료 시 자동)
- SURVEY 그룹만 선택 가능
