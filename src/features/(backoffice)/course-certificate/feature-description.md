# 과정 수료설정

수료증 템플릿 연결, 수료 기준(진도율/출석률) 설정, 자동 발급 여부를 관리하는 탭.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 과정 상세 > 수료설정 탭
- **URL**: `/backoffice/courses/[courseId]/certificate`
- **목적**: 과정의 수료증 발급 조건과 템플릿을 설정

## 화면 구성

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 진행 중 차수 배너 | 노란색 경고: 변경 사항은 새 차수부터 적용 | - |
| 템플릿 관리 링크 | `/backoffice/org/certificates` | 새 탭 열기 |
| 템플릿 카드 (미사용) | 수료증 비발급 옵션 | 선택 시 수료 기준/발급 설정 섹션 숨김 |
| 템플릿 카드 (active) | 이름, 유효기간 표시, 체크 아이콘 | 해당 템플릿 선택 |
| 템플릿 카드 (inactive) | 반투명 + "비활성" 라벨, 클릭 불가 | - |
| 학습 진도율 입력 | 필수, 0-100% | 직접 숫자 입력 |
| 출석률 체크박스 | 선택적 기준 활성화/비활성화 | 토글 시 입력 필드 표시/숨김 |
| 출석률 입력 | 체크 시 표시, 0-100% | 직접 숫자 입력 |
| 자동 발급 토글 | ON: 기준 충족 시 자동 발급, OFF: 수동 발급 | ON/OFF 전환 |
| 저장 버튼 | 우하단 | API 호출 (미구현) |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| 템플릿 미선택 (미사용) | 템플릿 카드만 표시, 수료 기준/발급 설정 숨김 |
| 템플릿 선택됨 | 수료 기준 + 발급 설정 섹션 추가 표시 |
| 진행 중 차수 있음 | 상단에 노란색 안내 배너 표시 |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| selectedTemplate === null | 수료 기준, 발급 설정 섹션 숨김 |
| selectedTemplate !== null | 수료 기준, 발급 설정 섹션 표시 |
| 템플릿 active = false | 카드 반투명 + 클릭 불가 |
| 출석률 체크 해제 | 출석률 입력 필드 숨김 |
| hasOngoingSessions = true | "새로 열리는 차수부터 적용" 배너 표시 |

## 연결 페이지

| 방향 | 대상 | 조건 |
|------|------|------|
| 부모 | 과정 레이아웃 | 탭 네비게이션 |
| 외부 링크 | 수료증 템플릿 관리 (`/backoffice/org/certificates`) | 링크 클릭 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CertConfig | certificate | 수료증 설정 (templateId, completionThreshold, attendanceThreshold, autoIssue) |
| CertTemplate | certificate | 수료증 템플릿 (name, active, validityYears) |

## 비즈니스 규칙

- 수료증 템플릿은 조직 수준에서 관리하며, 과정에서는 연결만 한다.
- 비활성(inactive) 템플릿은 선택할 수 없다.
- 학습 진도율은 필수 기준이며, 출석률은 오프라인/블렌디드 과정에서만 의미 있다.
- 진행 중인 차수가 있을 때 설정 변경은 새로 열리는 차수부터 적용된다.
- 차수별로 수료 기준을 개별 조정할 수 있으며, 여기서 설정하는 값은 기본값이다.
- 자동 발급 비활성화 시 관리자가 수동으로 수료증을 발급해야 한다.
