# 수료 설정 (Backoffice)

과정 설계 탭 내 수료증 연결 및 수료 기준 설정 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 템플릿 |
| CertificateTemplate | certificate | 수료증 템플릿 |

## 화면 구성

### 섹션: 수료증 템플릿
- 조직에서 생성한 템플릿 목록 카드 표시
- 선택 시 해당 과정과 연결

### 섹션: 수료 기준
- 학습 진도율, 시험 점수, 출석률, 과제 제출 체크리스트
- 각 기준 활성화/비활성화 + 임계값(%) 설정
- 모든 활성 기준 충족 시 수료 인정

### 섹션: 발급 설정
- 자동 발급 토글 (기준 충족 시 즉시 vs 관리자 수동)

## 비즈니스 규칙

- 수료증 템플릿은 조직 > 수료증 관리에서 생성
- 과정에서는 연결만 함 (템플릿 편집 불가)
- 최소 1개 기준이 활성화되어야 저장 가능
