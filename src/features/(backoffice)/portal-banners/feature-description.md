# 배너 / 팝업 관리

학습자 포털 메인에 노출할 배너와 팝업을 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 포털 > 배너
- **URL**: /backoffice/org/portal/banners
- **목적**: 포털 메인 배너 및 팝업의 등록·활성화·삭제

## 화면 구성
### 레이아웃
탭(배너/팝업) + 항목 카드 리스트.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 배너/팝업 탭 | 배너와 팝업을 별도 탭으로 분리 | 해당 목록 표시 |
| 항목 카드 | 이미지 썸네일, 제목, 노출 기간 | - |
| 활성화 토글 | 노출/숨김 전환 | 상태 토글 |
| 편집 버튼 (연필) | 배너/팝업 수정 | 편집 모드 |
| 삭제 버튼 (휴지통) | 삭제 | confirm 후 제거 |
| + 추가 버튼 | 새 배너/팝업 등록 | 추가 모드 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 항목 있음 | 카드 리스트 |
| 항목 없음 | "등록된 배너/팝업가 없습니다" 안내 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| PortalBanner | portal | 배너/팝업 (제목, 이미지, 기간, 활성 여부) |

## 비즈니스 규칙
- 배너와 팝업은 별도 목록으로 관리
- 노출 기간(startDate ~ endDate) 설정
- 삭제 시 confirm 다이얼로그 표시
