# 유저 목록

조직 내 전체 유저를 조회하고 관리하는 목록 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 유저
- **URL**: /backoffice/org/users
- **목적**: 유저 검색·필터링, 개별 유저 상세 진입, 신규 유저 추가

## 화면 구성
### 레이아웃
상단 필터/검색 + 유저 테이블. UserTable 섹션 컴포넌트로 구성.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 유저 테이블 | 이름, 이메일, 역할(수강생/강사/관리자), 상태, 가입일 | 유저 상세(user-layout)로 이동 |
| 역할/상태 필터 | 역할별·상태별 필터링 | 테이블 갱신 |
| 검색 | 이름·이메일 검색 | 실시간 필터 |
| + 유저 추가 버튼 | 신규 유저 생성 | CreateUserModal 열기 |
| 일괄 가져오기 버튼 | CSV/엑셀 일괄 등록 | ImportUsersModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 유저 있음 | 테이블에 행 표시 |
| 검색 결과 없음 | 빈 상태 안내 |

## 모달
### 유저 추가 (CreateUserModal)
- 필드: 이름, 이메일, 역할 선택
- 동작: 초대 이메일 발송

### 일괄 가져오기 (ImportUsersModal)
- CSV/엑셀 파일 업로드로 다수 유저 등록

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 이동 | user-layout > user-profile | 유저명 클릭 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 유저 (이름, 이메일, 역할, 상태) |

## 비즈니스 규칙
- 신규 유저는 초대 이메일을 통해 비밀번호 설정
- 역할: LEARNER, INSTRUCTOR, ORG_ADMIN, SUPER_ADMIN
