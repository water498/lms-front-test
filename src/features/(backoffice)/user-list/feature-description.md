# 유저 목록 (Admin)

조직 내 전체 유저를 조회하고 관리하는 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| User | user | 유저 (이름, 이메일, 역할, 상태) |

## 화면 구성

- 유저 테이블 (UserTable 컴포넌트)
- 역할별/상태별 필터, 검색
- 테이블 컬럼: 이름, 이메일, 역할(수강생/강사/관리자), 상태, 가입일
- 유저명 클릭 시 유저 상세(user-layout)로 이동
- "+ 유저 추가" 버튼, "일괄 가져오기" 버튼

## 모달

### 유저 추가
- 필드: 이름, 이메일, 역할 선택
- 초대 이메일 발송

### 일괄 가져오기
- CSV/엑셀 파일 업로드로 다수 유저 등록

## 비즈니스 규칙

- 신규 유저는 초대 이메일을 통해 비밀번호 설정
