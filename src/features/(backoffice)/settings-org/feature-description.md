# 설정 - 조직 구조 (Admin)

조직의 부서 트리, 직급, 사업장을 관리하고 구성원을 배치하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OrgTeam | org | 부서 (트리 구조, 상위-하위) |
| OrgPosition | org | 직급 (순서, 역할 유형) |
| OrgSite | org | 사업장 |
| User | user | 구성원 (소속 부서/직급/사업장) |

## 화면 구성

### 섹션: 부서 트리
- 계층형 트리 UI: 접기/펼치기, 소속 인원 수 표시
- 인라인 편집: 부서명 수정, 하위 부서 추가
- 삭제: 확인 모달 (소속 구성원/하위 부서 수 경고)
- 부서 선택 시 우측에 소속 구성원 목록 표시

### 섹션: 직급 관리
- 직급 목록: 이름, 역할 유형(LEADER/MEMBER/EXECUTIVE), 순서
- 추가/편집/삭제

### 섹션: 사업장 관리
- 사업장 목록: 이름, 소속 인원 수
- 추가/편집/삭제, 선택 시 소속 구성원 표시

### 섹션: 구성원 배치
- 선택된 부서/사업장의 소속 구성원 목록
- 검색, 부서/사업장/직급 변경
- CSV 일괄 업로드/다운로드

## 모달

### 삭제 확인 (DeleteConfirmModal)
- 부서/직급/사업장 삭제 시 영향받는 구성원/하위 부서 수 표시

## 비즈니스 규칙

- 부서 삭제 시 소속 구성원의 부서 배정 해제
- CSV 업로드로 구성원 일괄 배치 가능

## B2C/B2B 분기

- orgStructure feature flag가 활성화된 B2B 테넌트에서만 의미 있음
