# 메시징 자동화

SMS, 알림톡(카카오), 이메일 채널별 메시지 발송 이력, 템플릿, 자동화 규칙, 채널 설정을 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 메시징 > SMS/카카오/이메일
- **URL**: /backoffice/org/messaging/{sms|kakao|email} (channel prop)
- **목적**: 채널별 메시지 발송, 템플릿 관리, 자동화 규칙 설정

## 화면 구성
### 레이아웃
크레딧 잔액 바 + 서브탭 4개.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 크레딧 잔액 바 | 잔액, 건당 비용, 예상 발송 가능 건수, 부족 경고 | 읽기 전용 |
| 발송 이력 탭 | 발송된 메시지 목록(상태, 수신자, 시간) | - |
| 템플릿 탭 | 채널별 메시지 템플릿 관리 | 생성/편집 |
| 자동화 탭 | 이벤트 기반 자동 발송 규칙 | 규칙 추가/편집 |
| 설정 탭 | 채널별 발신 설정 | 설정 변경 |
| 메시지 발송 버튼 | 수동 메시지 발송 | SendMessageModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 잔액 충분 | 정상 표시 |
| 잔액 부족 (< 100건 비용) | 빨간색 "잔액 부족" 경고 |

## 모달
### 메시지 발송 (SendMessageModal)
- 수신 대상 선택, 템플릿 선택, 내용 편집 후 발송

### 템플릿 생성/편집 (CreateTemplateModal)
- 채널, 제목, 내용(변수 치환 지원) 설정

### 자동화 규칙 (MessageEventRuleModal)
- 트리거 이벤트, 채널, 템플릿, 활성화 여부 설정

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | messaging-credit | 크레딧 잔액 공유 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| MessageTemplate | messaging | 메시지 템플릿 |
| MessageEventRule | messaging | 이벤트 기반 자동 발송 규칙 |
| MessageLog | messaging | 발송 이력 |
| CreditPool | credit | 메시징 크레딧 잔액 |

## 비즈니스 규칙
- 채널별 건당 크레딧 비용이 다름 (SMS, 알림톡, 이메일)
- 크레딧 부족 시 발송 불가
- 자동화 규칙: 수강 신청, 수료 등 이벤트 발생 시 자동 메시지 발송
