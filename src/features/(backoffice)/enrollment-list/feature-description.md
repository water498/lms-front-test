# 수강 관리 (Admin)

전체 수강 신청(Enrollment) 내역을 조회하고 관리하는 목록 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Enrollment | enrollment | 수강 신청 (학습자-차수 연결) |
| CourseSession | course | 소속 차수 |
| Course | course | 소속 과정 |

## 화면 구성

- 상태 필터: 전체 / 활성 / 완료 / 수료 불가 / 취소됨 / 만료됨
- 추가 필터: 기간(전체/이번 주/이번 달/최근 3개월), 과정별, 차수별, 진행률(전체/미시작/진행 중/완료)
- 체크박스 다중 선택 지원
- 테이블 컬럼: 학습자, 과정, 차수, 진행률, 상태, 등록일
- 독촉 알림 발송 기능 (진행률 0% 수강생 대상)

## 비즈니스 규칙

- 상태: ACTIVE > COMPLETED 또는 FAILED 또는 CANCELLED 또는 EXPIRED
