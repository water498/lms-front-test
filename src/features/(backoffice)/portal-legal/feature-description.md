# 약관 / 개인정보 (Admin)

포털에 게시되는 법적 문서(이용약관, 개인정보처리방침, 마케팅 동의)를 버전별로 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| LegalDocument | portal | 법적 문서 (유형, 버전, 시행일, 내용) |

## 화면 구성

- 유형 필터 탭: 전체 / 이용약관 / 개인정보 / 마케팅(이메일) / 마케팅(SMS)
- 테이블 컬럼: 유형, 버전, 시행일, 작성일
- 행 클릭 시 상세 모달 열기
- "+ 새 문서" 버튼

## 모달

### 새 문서 생성
- 필드: 문서 유형(드롭다운), 시행일(날짜), 내용(HTML/마크다운 편집)

### 문서 상세/편집
- 유형, 버전, 시행일, 작성일 표시
- 내용 편집 및 저장

## 비즈니스 규칙

- 같은 유형의 문서는 버전별로 관리 (v1, v2, ...)
- 시행일 기준으로 현재 적용 중인 문서 결정
