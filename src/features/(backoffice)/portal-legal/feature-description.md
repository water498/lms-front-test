# 약관 / 개인정보

포털에 게시되는 법적 문서를 버전별로 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 포털 > 약관
- **URL**: /backoffice/org/portal/legal
- **목적**: 이용약관, 개인정보처리방침, 마케팅 동의 문서의 작성·관리

## 화면 구성
### 레이아웃
유형 필터 탭 + 문서 테이블.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 유형 필터 탭 | 전체/이용약관/개인정보/마케팅(이메일)/마케팅(SMS) | 해당 유형 필터 |
| 문서 테이블 | 유형 뱃지, 버전, 시행일, 작성일 | DetailModal 열기 |
| + 새 문서 버튼 | 새 법적 문서 작성 | CreateModal 열기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 문서 있음 | 테이블에 행 표시 + 건수 |
| 문서 없음 | "등록된 문서가 없습니다" |

## 모달
### 새 문서 생성 (CreateModal)
- 필드: 문서 유형(드롭다운), 시행일(날짜), 내용(HTML/마크다운 편집)

### 문서 상세/편집 (DetailModal)
- 유형, 버전, 시행일, 작성일 표시
- 내용 편집 후 저장

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | 학습자 포털 | 시행일 기준 현재 적용 문서 노출 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| LegalDocument | portal | 법적 문서 (유형, 버전, 시행일, 내용) |

## 비즈니스 규칙
- 문서 유형: TERMS(이용약관), PRIVACY(개인정보), MARKETING_EMAIL, MARKETING_SMS
- 같은 유형은 버전별로 관리 (v1, v2, ...)
- 시행일 기준으로 현재 적용 중인 문서 결정
