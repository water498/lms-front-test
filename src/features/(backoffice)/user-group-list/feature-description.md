# 그룹 관리

유저 그룹을 생성하고 멤버를 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 그룹
- **URL**: /backoffice/org/groups
- **목적**: 과정 일괄 배정 및 공지 대상 지정용 그룹 관리

## 화면 구성
### 레이아웃
```
[좌측: 그룹 목록 (w-80)] [우측: 멤버 패널 (flex-1)]
```
좌우 2-panel 구조.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 그룹 카드 (좌) | 이름, 설명, 멤버 수, 생성일. hover 시 삭제 버튼 | 선택 하이라이트 + 멤버 표시 |
| 그룹 생성 버튼 | 새 그룹 생성 | CreateGroupModal 열기 |
| 멤버 패널 (우) | 그룹명, 설명, 멤버 목록(이름, 이메일, 역할 뱃지) | - |
| 멤버 추가 버튼 | 기존 유저를 그룹에 추가 | AddMembersModal 열기 |
| 멤버 제거 (X) | 그룹에서 멤버 제거 | 즉시 제거 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 그룹 미선택 | 우측 "그룹을 선택하면 멤버 목록이 표시됩니다" |
| 그룹 선택 + 멤버 있음 | 멤버 목록 표시 |
| 그룹 선택 + 멤버 없음 | "멤버가 없습니다" 안내 |

## 모달
### 그룹 생성 (CreateGroupModal)
- 필드: 그룹명(필수), 설명(선택)

### 멤버 추가 (AddMembersModal)
- 기존 유저 검색 후 체크박스로 다중 선택

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | enrollment-list | 그룹 기반 일괄 수강 배정 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| UserGroup | user | 유저 그룹 (이름, 설명, 멤버 ID 목록) |
| User | user | 그룹 멤버 |

## 비즈니스 규칙
- 그룹 삭제 시 확인 다이얼로그 (기존 수강 배정에는 영향 없음)
- 같은 유저를 중복 추가 시 자동 무시 (Set 기반)
