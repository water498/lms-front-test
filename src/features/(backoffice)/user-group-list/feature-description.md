# 그룹 관리 (Admin)

유저 그룹을 생성하고 멤버를 관리하는 페이지. 과정 일괄 배정 및 공지 대상 지정에 활용.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| UserGroup | user | 유저 그룹 (이름, 설명, 멤버 목록) |
| User | user | 그룹 멤버 |

## 화면 구성

- **좌측 (그룹 목록)**: 그룹 카드 (이름, 설명, 멤버 수, 생성일). 선택 시 하이라이트. 삭제 버튼(hover)
- **우측 (멤버 패널)**: 선택된 그룹의 멤버 목록 (이름, 이메일, 역할). 멤버 추가/제거
- "+ 그룹 생성" 버튼

## 모달

### 그룹 생성
- 필드: 그룹명(필수), 설명

### 멤버 추가
- 기존 유저 검색 후 체크박스로 다중 선택

## 비즈니스 규칙

- 그룹 삭제 시 확인 다이얼로그 표시 (기존 수강 배정에는 영향 없음)
- 같은 유저를 중복 추가 시 자동 무시
