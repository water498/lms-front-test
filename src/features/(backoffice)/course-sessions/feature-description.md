# 과정 차수 관리

과정에 속한 차수(Session) 목록을 조회하고, 차수를 추가/복사/삭제하며, 차수 상세로 진입하는 페이지.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 과정 상세 > 차수 탭
- **URL**: `/backoffice/courses/[courseId]/sessions`
- **목적**: 차수 목록 관리, 새 차수 생성, 차수 상세 진입

## 화면 구성

### 레이아웃

```
┌──────────────────────────────────────────────────┐
│ 4개 차수                              [+ 차수 추가] │
├──────────────────────────────────────────────────┤
│ 차수명     │ 유형  │ 기간         │ 수강/정원 │ 강사   │ 상태  │     │
│ ────────── │ ───── │ ──────────── │ ──────── │ ────── │ ───── │ ─── │
│ 1기 (Q1)  │ 1기   │ 01.06~03.31 │ 28/30   │ 김안전 │ 종료  │     │
│ 2기 (Q2)  │ 2기   │ 04.01~06.30 │ 50/50 미달│ 박교육+1│ 진행중│[복사][삭제]│
│ 자유수강   │ 자유  │ 상시        │ 87/∞    │ 김안전 │ 진행중│     │
└──────────────────────────────────────────────────┘
```

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 차수 수 표시 | 좌상단 "N개 차수" 텍스트 | - |
| + 차수 추가 버튼 | 바이올렛 CTA | 차수 생성 모달 열기 |
| 차수 행 | 차수명, 유형, 기간, 수강/정원, 강사, 상태 | 차수 상세로 이동 |
| 유형 배지 | 정규(N기, 노란색) / 자유수강(보라색) | - |
| 상태 배지 | 준비중/모집중/진행중/종료/폐강 | - |
| 수강/정원 셀 | enrolled/capacity, 정원 0은 무한대 표시 | - |
| 미달 배지 | 최소 인원 미달 시 빨간 "미달" 배지 (OPEN/ONGOING만) | - |
| 강사 셀 | 주강사명 + 보조강사 수(+N) | - |
| 복사 버튼 | hover 시 표시 | 차수 복사 (미구현) |
| 삭제 버튼 | hover 시 표시 | 삭제 확인 모달 열기 |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| 차수 존재 | 테이블에 행 표시 |
| 차수 없음 | dashed border 빈 상태: "등록된 차수가 없습니다. 첫 차수를 만들어보세요" |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| session.type === SELF_PACED | 기간 컬럼에 "상시" 표시 |
| session.type === COHORT | 기간 컬럼에 시작일~종료일, 유형에 N기 표시 |
| capacity === 0 | 정원에 무한대 표시 |
| enrolled >= capacity (> 0) | 수강 수 빨간색 강조 |
| enrolled < minEnrollment (OPEN/ONGOING) | "미달" 배지 표시 |

## 모달

### 차수 추가 모달 (CreateSessionModal)
- **용도**: 새 차수 생성
- **필드**:
  - 운영 유형: 정규(COHORT) / 상시(SELF_PACED) 라디오 카드
  - 차수명 (텍스트)
  - 기수 번호 (정규만)
  - 시작일/종료일 (정규만, date picker)
  - 정원 (숫자, 0 = 무제한)
  - 최소 수강 인원 (정규만, 과정 기본값 상속)
  - 강사 배정 (체크박스 + 주강사/보조강사 역할 선택)
  - 장소 (오프라인 과정만)
  - 노출 여부 토글 (수강신청 페이지 표시)
  - 판매 여부 토글 (B2C 개별 결제 허용)
- **동작**: 추가 클릭 시 차수 생성

### 차수 삭제 모달 (DeleteSessionModal)
- **용도**: 차수 삭제 전 확인
- **내용**: "{차수명}을(를) 삭제하시겠습니까? 삭제된 차수는 복구할 수 없으며, 수강 기록도 함께 삭제됩니다."
- **버튼**: 취소 / 삭제(빨간색)

## 연결 페이지

| 방향 | 대상 | 조건 |
|------|------|------|
| 부모 | 과정 레이아웃 | 탭 네비게이션 |
| 이동 | 차수 상세 (`/backoffice/courses/{courseId}/sessions/{sessionId}`) | 행 클릭 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseSession | session | 차수 (name, type, status, startDate, endDate, enrolled, capacity, minEnrollment, cohortNumber) |
| CourseInstructor | session | 차수 강사 배정 (name, role: PRIMARY/ASSISTANT) |
| SessionStatus | session | 차수 상태 enum: DRAFT, OPEN, ONGOING, CLOSED, CANCELLED |
| SessionType | session | 차수 유형 enum: COHORT, SELF_PACED |

## 비즈니스 규칙

- 차수 유형: COHORT(정규, 시작/종료일 지정) vs SELF_PACED(상시, 기간 없음)
- 차수 상태: DRAFT(준비중) -> OPEN(모집중) -> ONGOING(진행중) -> CLOSED(종료) / CANCELLED(폐강)
- 정원 0 = 무제한, 최소 수강 인원 미달 시 OPEN/ONGOING 상태에서 "미달" 경고 표시
- 강사 배정은 차수별로 관리하며, 주강사(PRIMARY) 1명 + 보조강사(ASSISTANT) N명 구조
- 차수 삭제 시 수강 기록도 함께 삭제되므로 복구 불가
- 최소 수강 인원 기본값은 과정 수준 설정에서 상속받는다.
