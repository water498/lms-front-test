# 차수 오프라인/출결 관리

차수 내 오프라인 수업 회차를 관리하고, QR 출석 및 수동 출결 처리를 수행하는 화면.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > 오프라인 탭 (또는 출결 탭)
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/offline` (또는 `/attendance`)
- **목적**: 오프라인 수업 회차 등록, 출석률 확인, QR 출석/수동 출결 관리

## 화면 구성

### 레이아웃
```
┌──────────────────────────────────────────────┐
│                                [+ 회차 추가]  │
├──────────────────────────────────────────────┤
│  회차 | 날짜/시간      | 장소 | 강사 | 정원 | 출석률 | 상태 | 액션  │
│  ─────────────────────────────────────────── │
│  1회차 | 2025-02-10    | 본관 | 이정민+1 | 30명 | 85% | 완료 | [QR][출결]│
│        | 09:00 – 12:00 |      |          |      |     |      |           │
│  2회차 | 2025-02-17    | 본관 | 이정민   | 30명 | —   | 예정 | [QR][출결]│
└──────────────────────────────────────────────┘
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 회차 추가 버튼 | 우상단 바이올렛 버튼 | CreateOfflineSessionModal 열기 |
| 회차 테이블 | 회차번호, 날짜/시간, 장소, 강사, 정원, 출석률, 상태 | — |
| 강사 셀 | 주강사 이름 + 보조강사 수 뱃지 | — |
| 상태 뱃지 | 예정(파랑), 완료(초록), 취소(빨강) | — |
| QR 버튼 | 바이올렛 텍스트 + QrCode 아이콘 | QrModal 열기 |
| 출결 버튼 | 슬레이트 텍스트 + ClipboardList 아이콘 | AttendanceModal 열기 |
| 출석률 | 완료 회차만 퍼센트 표시, 예정은 "—" | — |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 회차 0건 | 점선 테두리 빈 상태: "등록된 회차가 없습니다." + "회차를 추가해 출결을 관리하세요" |
| 회차 존재 | 테이블에 회차 목록 표시 |
| SCHEDULED 회차 | 출석률 "—" 표시 |
| COMPLETED 회차 | 출석률 퍼센트 계산 (출석+지각 / 전체) |
| CANCELLED 회차 | 빨간 "취소" 뱃지 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| status = SCHEDULED | 출석률 "—" |
| status = COMPLETED/CANCELLED | 실제 출석률 계산 표시 |
| 보조강사 존재 | 주강사명 옆 "+N" 뱃지 |
| 주강사 없음 | 강사 셀에 "—" 표시 |

## 모달

### QR 출석 (QrModal)
- **용도**: 해당 회차의 QR 코드 생성/표시 (학습자가 스캔하여 출석 체크)
- **출처**: course-offline 공유 모달 재사용

### 출결 관리 (AttendanceModal)
- **용도**: 해당 회차의 수강생별 출결 상태를 수동으로 관리
- **출처**: course-offline 공유 모달 재사용

### 회차 추가 (CreateOfflineSessionModal)
- **용도**: 새 오프라인 수업 회차 등록
- **출처**: course-offline 공유 모달 재사용

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 상위 | 과정 상세 차수 탭 | 탭 네비게이션 |
| 동일 레벨 | 대시보드/수강생/채점/Q&A/자료실 탭 | 탭 전환 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| OfflineSession | course | 오프라인 수업 회차 (날짜, 장소, 정원, 상태) |
| OfflineAttendance | course | 출결 기록 (출석/지각/결석/사유결석) |
| CourseInstructor | course | 회차별 강사 (주강사/보조강사) |
| CourseSession | course | 차수 식별 |

## 비즈니스 규칙

- 출석률 계산: (PRESENT + LATE) / 전체 출결 기록 수 * 100
- 회차 상태: SCHEDULED(예정) > COMPLETED(완료) / CANCELLED(취소)
- 강사는 주강사(PRIMARY) 1명 + 보조강사(ASSISTANT) N명 구조
- QR 출석과 수동 출결을 병행 가능
- 3개 모달 모두 course-offline feature의 공유 컴포넌트 재사용
