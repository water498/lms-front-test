# 시험 에디터

시험 템플릿의 섹션 구성과 출제 규칙을 설정하는 전체 화면 에디터.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 시험 목록에서 행 클릭 또는 + 새 시험
- **URL**: /backoffice/resources/assessments/exam/[id] (fullscreen)
- **목적**: 시험의 섹션 구성, 문항 그룹 연결, 출제 수 설정

## 화면 구성
### 레이아웃
```
[상단 바: 뒤로가기 | 제목 입력 | 총 문항 수 | 저장]
[좌측 패널: 섹션 목록] [중앙: 섹션 편집기] [우측: 시험/섹션 설정]
```
전체 화면 3-panel 구조. h-screen 고정.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 섹션 목록 (좌) | 순서 변경(위/아래), 선택, 그룹명·출제 수 표시 | 해당 섹션 편집 |
| 섹션 편집기 (중) | 섹션명, 문항 그룹, 유형 필터, 출제 수, 셔플 | 값 변경 |
| 문항 미리보기 (중 하단) | 선택된 그룹의 문항 목록과 태그 | 읽기 전용 |
| 시험 설정 (우) | 유형(단답/최종), 통과기준(%), 시간제한(분), 재응시 횟수 | 값 변경 |
| 섹션 설정 (우 하단) | 출제 수, 셔플, 섹션 삭제 | 값 변경 |
| 저장 버튼 | 시험 템플릿 저장 | 저장 실행 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 섹션 없음 | 빈 상태 + "첫 번째 섹션 추가" 버튼 |
| 섹션 선택됨 | 섹션 편집 폼 + 우측 섹션 설정 |
| 그룹 미선택 | "문항 그룹을 선택하면 소속 문항이 표시됩니다" |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 출제 수 > 그룹 보유 문항 | 빨간색 경고, 저장 버튼 비활성화 |
| 무제한 재응시 체크 | 횟수 입력 필드 비활성화 |
| 유형 필터 적용 | 매칭 문항 수 갱신 표시 |

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 뒤로가기 | assessment-exam-list | 항상 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| ExamTemplate | assessment | 시험 메타(유형, 통과기준, 시간제한) |
| AssessmentSection | assessment | 섹션별 출제 규칙(그룹, 출제 수, 셔플) |
| QuestionGroup | assessment | 문항 그룹(EXAM 종류) |
| Question | assessment | 개별 문항(유형별 미리보기) |

## 비즈니스 규칙
- 시험 유형: SHORT(단답), FINAL(최종)
- 각 섹션은 하나의 EXAM 문항 그룹과 연결
- 유형 필터로 특정 문항 타입만 출제 가능 (객관식 단일/복수, O/X, 주관식)
- 출제 수가 그룹 내 매칭 문항 수를 초과하면 저장 불가
- 섹션 순서는 위/아래 화살표로 변경
