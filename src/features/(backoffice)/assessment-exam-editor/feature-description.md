# 시험 에디터 (Admin)

시험(ExamTemplate) 템플릿을 섹션 단위로 구성하고 설정하는 3패널 에디터.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| ExamTemplate | assessment/exam | 시험 템플릿 (유형, 통과 기준, 시간 제한, 재응시) |
| AssessmentSection | assessment/exam | 시험 섹션 (문항 그룹, 출제 수, 셔플) |
| QuestionGroup | assessment/question | 문항 그룹 |
| Question | assessment/question | 개별 문항 |

## 화면 구성

- **상단 바**: 시험 제목 인라인 편집, 총 문항 수 표시, 저장 버튼
- **좌측 패널 (섹션 목록)**: 섹션 추가/선택/순서 변경, 섹션별 그룹명과 출제 수 표시
- **중앙 패널 (섹션 편집)**: 섹션 이름, 문항 그룹 선택, 유형 필터(객관식 단일/복수/O-X/주관식), 출제 수, 셔플 토글, 문항 미리보기
- **우측 패널 (시험 설정)**: 유형(단답/최종), 통과 기준(%), 시간 제한(분), 재응시 횟수(무제한 옵션), 선택된 섹션 출제 수/셔플/삭제

## 비즈니스 규칙

- 출제 수가 그룹 보유 문항 수를 초과하면 저장 불가 (빨간색 경고)
- EXAM 그룹만 선택 가능 (SURVEY 그룹 제외)
- 유형 필터 적용 시 해당 유형 문항만 출제 대상
