# 메시징 크레딧 (Admin)

메시지 발송에 사용되는 크레딧의 잔액 확인, 충전, 자동 충전 설정, 사용 이력을 관리하는 페이지.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CreditPool | credit | 테넌트 크레딧 잔액 및 자동 충전 설정 |
| CreditTransaction | credit | 크레딧 충전/사용 이력 |

## 화면 구성

- **잔여 크레딧 카드**: 잔액 표시, 채널별(SMS/알림톡/이메일) 예상 발송 가능 건수
- **충전 섹션**: 패키지 선택(1,000 / 5,000 / 10,000 / 30,000 cr) 또는 직접 입력
- **자동 충전 설정**: 활성화 토글, 임계값과 충전량 설정 (예: 2,000cr 이하 시 10,000cr 충전)
- **충전 및 사용 이력 테이블**: 일시, 유형(충전/플랫폼지급/사용), 채널, 내용, 크레딧 증감

## 모달

### 크레딧 충전
- 패키지 선택 또는 직접 입력 후 충전 실행

## 비즈니스 규칙

- 자동 충전 비활성화 시 잔액 부족은 수동 충전 필요
- 충전 이력은 TOPUP, 플랫폼 지급은 GRANT, 발송 차감은 USAGE
