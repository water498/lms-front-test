# 메시징 크레딧

메시지 발송용 크레딧의 잔액 확인, 충전, 자동 충전 설정, 사용 이력을 관리하는 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN)
- **진입 경로**: 사이드바 > 조직 > 크레딧
- **URL**: /backoffice/org/credits
- **목적**: 크레딧 잔액 확인, 수동/자동 충전 설정, 사용 이력 조회

## 화면 구성
### 레이아웃
잔액 카드 + 충전 섹션 + 자동 충전 설정 + 이력 테이블. 단일 컬럼 (max-w-3xl).

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 잔여 크레딧 카드 (다크) | 잔액, 채널별(SMS/알림톡/이메일) 예상 발송 건수 | 읽기 전용 |
| 충전 패키지 (4종) | 1,000 / 5,000 / 10,000 / 30,000 cr | 읽기 전용 |
| 충전하기 버튼 | 크레딧 충전 | 충전 모달 열기 |
| 자동 충전 토글 | 자동 충전 ON/OFF | 설정 변경 |
| 자동 충전 조건 | 임계값·충전량 설정 (수정 버튼) | 인라인 편집 모드 |
| 이력 테이블 | 일시, 유형(충전/플랫폼지급/사용), 채널, 내용, 크레딧 증감 | 읽기 전용 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 자동 충전 활성 | 임계값/충전량 표시 + 수정 버튼 |
| 자동 충전 비활성 | "잔액 부족 시 수동으로 충전해야 합니다" 안내 |
| 이력 없음 | "이력이 없습니다" |

## 모달
### 크레딧 충전
- 패키지(4종) 선택 또는 직접 금액 입력
- 충전하기 버튼으로 실행

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | messaging-automation | 크레딧 잔액 공유 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| CreditPool | credit | 테넌트 크레딧 잔액 및 자동 충전 설정 |
| CreditTransaction | credit | 크레딧 충전/사용 이력 |

## 비즈니스 규칙
- 트랜잭션 유형: TOPUP(셀프 충전), GRANT(플랫폼 지급), USAGE(발송 차감)
- 자동 충전: 잔액이 임계값 이하 시 설정된 금액 자동 충전
- 채널별 건당 크레딧 비용이 다름
