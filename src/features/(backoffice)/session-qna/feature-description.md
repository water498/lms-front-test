# 차수 Q&A 관리

차수 내 학습자 질문 목록을 관리하고, 답변을 작성하며, 부적절한 게시글을 숨김 처리하는 화면.

## 누가, 언제

- **역할**: ORG_ADMIN, INSTRUCTOR
- **진입 경로**: 과정 상세 > 차수 선택 > Q&A 탭
- **URL**: `/backoffice/courses/[courseId]/sessions/[sessionId]/qna`
- **목적**: 학습자 질의응답 관리, 미답변 질문 처리, 부적절 게시글 모더레이션

## 화면 구성

### 레이아웃
```
┌──────────────────────────────────┐
│  총 N개  [미답변 N개]  숨김 N건 보기│
├──────────────────────────────────┤
│  ┌ [답변완료] 박지호 2025.02.12 ─┐│
│  │  비상대응 절차 시뮬레이션 범위.. │▼│
│  └──────────────────────────────┘│
│  ┌ [미답변] 최유진 2025.02.13 ──┐│
│  │  SCORM 콘텐츠 로딩이 안 됩니다│▼│
│  └──────────────────────────────┘│
└──────────────────────────────────┘
  ↓ 게시글 펼침 시
┌──────────────────────────────────┐
│  질문 본문                        │
│  ┌ A 이정민 강사  2025.02.12 ──┐ │
│  │  답변 내용                   │ │
│  └─────────────────────────────┘ │
│  [답변 텍스트영역] [전송]  [숨김] │
└──────────────────────────────────┘
```

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 질문 카드 헤더 | 답변 상태 뱃지 + 학습자명 + 날짜 + 제목 | 카드 펼침/접기 토글 |
| 답변완료 뱃지 | 초록색. 답변이 1개 이상일 때 | — |
| 미답변 뱃지 | 빨간색. 답변이 없을 때 | — |
| 숨김 뱃지 | 빨간 배경. 숨김 처리된 게시글 | — |
| 답변 영역 | 강사/관리자 아바타 + 이름 + 날짜 + 내용 | — |
| 답변 입력 폼 | textarea + 전송 버튼 (미답변 게시글에만 노출) | 답변 등록 |
| 숨김/공개 버튼 | 게시글 가시성 토글 | isHidden 전환 |
| 숨김 N건 보기 | 상단 토글 버튼 (숨김 게시글이 있을 때만 노출) | 숨김 게시글 표시/감추기 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 질문 0개 | 빈 상태: MessageCircle 아이콘 + "아직 질문이 없습니다." |
| 미답변 존재 | 상단에 빨간 "미답변 N개" 뱃지 |
| 전체 답변 완료 | 상단에 초록 "전체 답변 완료" 뱃지 |
| 숨김 게시글 존재 | "숨김 N건 보기/감추기" 토글 버튼 노출 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| showHidden = false | 숨김 게시글 목록에서 제외 |
| showHidden = true | 숨김 게시글도 표시 (빨간 테두리 + 배경) |
| post.isHidden = true | 숨김 뱃지 표시, 카드 빨간 테두리 |
| replies.length === 0 | 답변 입력 폼 표시 |
| replies.length > 0 | 답변 입력 폼 미표시, 답변 목록만 표시 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| QnaPost | qna | Q&A 게시글 (제목, 본문, 숨김 여부) |
| QnaReply | qna | 답변 (강사/관리자 작성) |
| CourseSession | course | 차수 식별 |

## 비즈니스 규칙

- 답변은 게시글당 여러 개 가능하나, 현재 UI는 미답변 게시글에만 입력 폼 표시
- 답변 작성자명은 "관리자"로 고정 (ADMIN_NAME 상수)
- 숨김 처리된 게시글은 학습자에게 비노출, 관리자만 확인 가능
- 숨김 게시글도 공개로 복원 가능 (토글 방식)
- 미답변 건수는 숨김 게시글을 제외하고 계산
