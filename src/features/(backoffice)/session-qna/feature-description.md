# 차수 Q&A (Admin)

차수 내 수강생 질문을 조회/답변하고, 부적절한 게시글을 숨김 처리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| QnaPost | qna | 질문 게시글 (제목, 본문, 숨김 여부) |
| QnaReply | qna | 답변 (강사/관리자 답변) |

## 화면 구성

- 헤더: 총 게시글 수, 미답변 수 뱃지, "숨김 N건 보기/감추기" 토글
- 게시글 아코디언 목록
  - 접힌 상태: 숨김 뱃지, 답변완료/미답변 뱃지, 작성자, 작성일, 제목
  - 펼친 상태: 본문 + 답변 목록 + 답변 폼 + 숨김/공개 버튼
- 답변 폼: 미답변 게시글에만 텍스트에리어 + 전송 버튼 표시
- 숨김/공개 토글 버튼: 부적절 게시글 관리

## 비즈니스 규칙

- 숨김 게시글은 기본적으로 목록에서 제외, 토글로 표시 가능
- 숨김 게시글은 빨간 테두리로 시각 구분
- 답변은 "관리자" 이름으로 등록
