# 강사 계좌 관리 (Admin)

강사의 정산 수령 계좌를 등록/관리하는 탭.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| InstructorBankAccount | instructor | 강사 계좌 (은행, 계좌번호, 예금주, 주계좌 여부) |

## 화면 구성

- 등록 계좌 목록: 은행 아이콘, 은행명, 주계좌 뱃지, 계좌번호, 예금주
- 계좌별 액션: "주계좌 설정" 버튼 (비주계좌만), 삭제 버튼
- "계좌 추가" 버튼 → 인라인 폼 표시
  - 은행명, 계좌번호, 예금주 입력 → 등록/취소
- 계좌 없으면 빈 상태 안내

## 비즈니스 규칙

- 첫 번째 계좌는 자동으로 주계좌 설정
- 주계좌는 하나만 유지 (다른 계좌 주계좌 설정 시 기존 해제)
- 강사 역할 사용자에게만 탭 노출
