# 과정 수강평

과정에 달린 수강평 목록을 조회하고 공개/숨김을 관리하는 페이지.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 과정 상세 > 수강평 탭
- **URL**: `/backoffice/courses/[courseId]/reviews`
- **목적**: 수강평 현황 파악, 부적절한 리뷰 숨김 처리, 공개 리뷰 기준 평균 평점 확인

## 화면 구성

### 레이아웃

```
┌──────────────────────────────────────────────────┐
│  4.2  ★★★★☆              전체 12건               │
│       공개 리뷰 기준       공개 10건 / 숨김 2건     │
├──────────────────────────────────────────────────┤
│ 수강생   │ 평점  │ 리뷰 내용      │ 작성일 │ 상태 │      │
│ ──────── │ ───── │ ─────────────  │ ────── │ ──── │ ──── │
│ [K] 김학생│ ★★★★★ │ 정말 유익한...  │ 24.03  │ 공개 │[숨기기]│
│ [L] 이학생│ ★★★☆☆ │ 내용이 좀...   │ 24.03  │ 숨김 │[보이기]│
│ ...      │       │               │        │      │      │
└──────────────────────────────────────────────────┘
```

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 평균 평점 | 공개 리뷰 기준 평균, 큰 숫자 + 별 아이콘 | - |
| 통계 요약 | 전체/공개/숨김 건수 | - |
| 수강생 컬럼 | 아바타(이니셜) + 이름 | - |
| 평점 컬럼 | 1~5 별 아이콘 | - |
| 리뷰 내용 컬럼 | 본문 truncate 표시 | - |
| 작성일 컬럼 | 날짜 표시 | - |
| 상태 배지 | 공개(초록) / 숨김(회색) | - |
| 숨기기 버튼 | 공개 리뷰에 표시 | 해당 리뷰 숨김 처리 |
| 보이기 버튼 | 숨김 리뷰에 표시 | 해당 리뷰 공개 처리 |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| 리뷰 존재 | 요약 카드 + 리뷰 테이블 |
| 리뷰 없음 | "아직 리뷰가 없습니다." 중앙 메시지 |
| 숨김 리뷰 행 | 배경 연하게(bg-slate-50/30), 본문 색상 연하게 |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| review.visible = true | 공개 배지 + "숨기기" 버튼 |
| review.visible = false | 숨김 배지 + "보이기" 버튼, 행 스타일 연하게 |

## 연결 페이지

| 방향 | 대상 | 조건 |
|------|------|------|
| 부모 | 과정 레이아웃 | 탭 네비게이션 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| CourseReview | course | 수강평 (id, userName, rating, body, createdAt, visible) |

## 비즈니스 규칙

- 평균 평점은 공개(visible=true) 리뷰만 기준으로 계산한다.
- 숨김 처리된 리뷰는 수강생에게 노출되지 않지만, 관리자 화면에서는 계속 조회 가능하다.
- 리뷰 삭제 기능은 없으며, 공개/숨김 토글만 제공한다.
- 별점은 1~5 정수이며, 소수점 평균은 소수 첫째 자리까지 표시한다.
