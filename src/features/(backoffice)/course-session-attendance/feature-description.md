# 차시 출결 관리 (Instructor)

강사가 오프라인 회차별 수강생 출결을 조회·수정하고 QR 코드를 발급하는 화면.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| OfflineSession | course | 오프라인 회차 (일차·장소·시간) |
| Attendance | progress | 수강생 출결 기록 |
| Enrollment | progress | 수강 등록 정보 |

## 화면 구성

- 회차 선택 탭: 1일차, 2일차 등 버튼으로 전환
- 회차 정보 카드: 제목, 시간, 장소, 강사(주/보조), 상태(완료·예정·취소), QR 버튼
- 출결 테이블: 수강생명, 출결 상태 배지(클릭 토글), 비고, 체크 시각
- 출결 상태 순환: 출석 → 지각 → 결석 → 공결 (클릭마다 순환)
- 예정 회차는 테이블 대신 안내 문구 표시

## 모달

### QR 코드 모달
- 출결/평가 두 모드 탭 전환
- 출결 모드: QR 이미지 + 유효 시간 설정 (시작 전 0~30분, 종료 후 10~60분)
- 평가 모드: 평가 항목 드롭다운 선택 → 해당 평가 페이지 이동 QR 생성
- 재발급 버튼으로 QR 갱신, 활성/만료 상태 표시

## 비즈니스 규칙

- 완료(COMPLETED) 상태 회차만 출결 변경 가능
- 예정(SCHEDULED) 회차는 읽기 전용
- QR은 출결·평가 두 용도로 사용 가능
