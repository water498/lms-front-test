# 차시 자료실 (Instructor)

강사가 수강생에게 배포할 문서 자료를 등록·관리하는 화면.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionResource | course | 차시 첨부 자료 (파일 메타·공개 여부) |

## 화면 구성

- 헤더: "자료실" 타이틀 + 설명 + 자료 등록 버튼
- 카테고리별 그룹: 접힘/펼침 토글 (강의자료, 서식, 참고문헌 등)
- 자료 행: 파일 아이콘(PDF/PPT/XLS), 제목, 비공개 배지, 과목 태그, 파일명·크기
- hover 액션: 공개/비공개 토글, 수정, 삭제
- 자료 없을 경우 빈 상태 + "첫 자료 등록하기" 버튼

## 모달

### 자료 등록
- 파일 선택 (드래그앤드롭 영역, PDF/PPT/DOC/XLS/HWP/ZIP 허용)
- 자료명: 파일 선택 시 파일명에서 자동 채움
- 분류: 추천 태그(강의자료·참고문헌·서식·기타) + 직접 입력
- 설명: 선택 입력
- 등록/취소 버튼

## 비즈니스 규칙

- 공개/비공개(isVisible) 토글로 수강생 노출 제어
- 카테고리 미지정 시 "미분류"로 그룹화
- 과목(Subject) 연결 자료는 보라색 태그로 구분
