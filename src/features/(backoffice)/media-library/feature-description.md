# 미디어 라이브러리

동영상, PDF, SCORM, 이미지 파일을 폴더별로 관리하는 미디어 자산 관리 페이지.

## 누가, 언제
- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 사이드바 > 리소스 > 미디어
- **URL**: /backoffice/resources/media
- **목적**: 학습 콘텐츠용 미디어 파일 업로드·정리·삭제

## 화면 구성
### 레이아웃
좌측 폴더 트리 + 우측 미디어 그리드/리스트 뷰.

### 주요 요소
| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| 폴더 트리 (좌) | 계층형 폴더 구조. 전체/미분류/사용자 정의 폴더 | 해당 폴더 필터링 |
| 미디어 그리드/리스트 | 파일 썸네일, 유형 뱃지, 크기, 업로드 상태 | 상세 보기 |
| 업로드 버튼 | 새 파일 업로드 | UploadModal 열기 |
| 뷰 전환 (그리드/리스트) | 표시 방식 변경 | 뷰 토글 |
| 유형 필터 | 전체/동영상/PDF/SCORM/이미지 | 해당 유형만 표시 |
| 상태 필터 | 전체/활성/처리 중/오류 | 해당 상태만 표시 |
| 폴더 컨텍스트 메뉴 | 이름 변경, 삭제 | 해당 액션 |

## 상태별 화면
| 상태 | 화면 |
|------|------|
| 파일 있음 | 그리드/리스트에 파일 표시 |
| 폴더 비어있음 | 빈 상태 안내 |
| PROCESSING | 파란색 펄스 뱃지 |
| ERROR | 빨간색 배경 + 오류 뱃지 |

## 조건부 분기
| 조건 | 변화 |
|------|------|
| 미분류 필터 | 폴더 미지정 파일만 표시 |
| 특정 폴더 선택 | 하위 폴더 포함 파일 표시 |

## 모달
### 업로드 모달 (UploadModal)
- 용도: 새 미디어 파일 업로드
- 동작: 파일 선택 후 업로드 처리

## 연결 페이지
| 방향 | 대상 | 조건 |
|------|------|------|
| 참조 | course-curriculum | 미디어가 과정 콘텐츠로 연결 |

## 도메인 모델
| 모델 | 모듈 | 설명 |
|------|------|------|
| MediaAsset | media | 미디어 파일(유형, 크기, 상태, 폴더) |
| MediaFolder | media | 폴더(계층 구조, 순서) |

## 비즈니스 규칙
- 파일 유형: VIDEO, PDF, SCORM, IMAGE
- 업로드 상태: PENDING -> VALIDATING -> PROCESSING -> ACTIVE (또는 ERROR)
- 차수에 연결된 파일은 삭제 시 경고 표시
- 폴더 삭제 시 하위 폴더도 함께 삭제
