# 과정 통계

과정 전체의 수강/수료 현황을 KPI 카드, 차트, 차수별 비교 테이블로 시각화하는 대시보드.

## 누가, 언제

- **역할**: 관리자(ORG_ADMIN), 강사(INSTRUCTOR)
- **진입 경로**: 과정 상세 > 통계 탭
- **URL**: `/backoffice/courses/[courseId]/statistics`
- **목적**: 과정 운영 성과 모니터링, 차수 간 비교, 활동별 병목 식별

### 주요 요소

| 요소 | 설명 | 클릭 시 |
|------|------|---------|
| KPI 카드: 총 수강생 | 모든 차수 합산 수강생 수 + 추세 화살표 | - |
| KPI 카드: 수료율 | 전체 수료자/수강생 비율 + 수료자 수 서브텍스트 | - |
| KPI 카드: 평균 진도율 | 수강생 있는 차수의 평균 진도율 | - |
| KPI 카드: 평균 점수 | 점수 있는 차수의 평균 점수 | - |
| 주간 추이 차트 | 바 차트, 보라색(수강) + 초록색(수료), 주 단위 | - |
| 점수 분포 차트 | 가로 바, 구간별(90~100, 80~89, ...) 인원 수 + 비율 | - |
| 활동별 완료율 | 가로 프로그레스 바, 활동명 + 완료율(%) | - |
| 차수별 비교 테이블 | 수강생, 수료, 수료율, 평균 진도, 평균 점수, 이탈률 | - |

## 상태별 화면

| 상태 | 화면 |
|------|------|
| 데이터 존재 | 전체 KPI + 차트 + 테이블 표시 |
| 차수 없음/수강생 없음 | KPI 0 표시, 차트 비어있음 |

## 조건부 분기

| 조건 | 변화 |
|------|------|
| 추세 up | KPI 카드에 초록 상승 화살표 |
| 추세 down | KPI 카드에 빨간 하락 화살표 |
| 추세 flat | KPI 카드에 회색 수평선 |
| 수료율 >= 70% | 차수 비교 테이블에서 초록색 |
| 수료율 50~69% | 노란색 |
| 수료율 < 50% | 빨간색 |
| 이탈률 > 10% | 빨간색 강조 |
| 활동 완료율 >= 80% | 초록 바 |
| 활동 완료율 60~79% | 노란 바 |
| 활동 완료율 < 60% | 빨간 바 |

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| SessionStat | statistics | 차수별 통계 (enrolled, completed, avgProgress, avgScore, dropoutRate) |
| WeeklyTrend | statistics | 주간 수강/수료 추이 (week, enrollments, completions) |
| Course | course | 과정 기본정보 |

## 비즈니스 규칙

- KPI는 모든 차수 데이터를 합산/평균하여 계산한다.
- 평균 진도율은 수강생이 있는 차수만 대상으로 한다.
- 평균 점수는 점수가 0보다 큰 차수만 대상으로 한다.
- 주간 추이 차트는 최근 6주 데이터를 표시한다.
- 점수 분포는 10점 단위 구간(90~100, 80~89, 70~79, 60~69, ~59)으로 나눈다.
- 활동별 완료율은 과정 전체 기준이며, 병목 식별에 활용한다.
- 이 탭은 읽기 전용이며, 데이터 수정 기능은 없다.
