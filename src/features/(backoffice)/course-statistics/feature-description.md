# 수강 통계 (Backoffice)

과정 단위 수강/수료 통계. 과정 상세 > 운영 > 수강 통계.

## 도메인 모델

| 모델 | 모듈 | 설명 |
|------|------|------|
| Course | course | 과정 |
| CourseSession | course | 차수 |
| Enrollment | enrollment | 수강 |
| ActivityCompletion | progress | 활동 완료 |

## 화면 구성

### KPI 카드
- 총 수강생, 수료율, 평균 진도율, 평균 점수

### 주간 수강/수료 추이
- 바 차트: 주별 수강 신청 vs 수료 건수

### 점수 분포
- 가로 바: 점수 구간별 인원수 + 비율

### 활동별 완료율
- 프로그레스 바: 각 활동의 완료율 (높→낮 순)

### 차수별 비교 테이블
- 차수명, 상태, 수강생, 수료, 수료율, 평균 진도, 평균 점수, 이탈률

## 비즈니스 규칙

- 이 과정의 전체 차수 데이터를 합산/비교
- DRAFT 차수는 통계에서 제외 (데이터 없음)
