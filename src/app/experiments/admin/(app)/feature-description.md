# 기업 관리자 대시보드

기업(테넌트) 관리자가 LMS 운영 현황을 한눈에 파악하는 메인 페이지.

## 주요 기능

- **통계 카드**: 총 수강생, 활성 과정, 수료율, 이번 달 매출 등 핵심 지표
- **최근 활동**: 최근 수강 신청, 수료 완료, 문의 등 타임라인
- **빠른 액션**: 과정 생성, 수강생 등록, 공지사항 작성 등 바로가기

## 역할

- **접근 가능**: ORG_ADMIN (기업 관리자)
- **인증**: 로그인 필수 — 미인증 시 `/admin/login`으로 리다이렉트

## 참고

- B2B 테넌트의 경우 SSO 로그인 후 진입
- B2C 테넌트의 경우 결제/매출 관련 지표가 추가로 표시됨
