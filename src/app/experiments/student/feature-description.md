# 수강생 홈

수강생이 로그인 후 처음 접하는 메인 페이지. 추천 과정, 진행 중인 학습, 공지사항 등을 표시.

## 주요 기능

- **히어로 배너**: 프로모션 또는 주요 공지
- **추천 과정**: 카테고리별 과정 카드 목록
- **내 학습 현황**: 진행 중인 과정 요약 (로그인 시)
- **검색**: 과정 검색 바

## 역할

- **접근 가능**: STUDENT (수강생)
- **비로그인 접근**: 가능 — 과정 탐색은 로그인 없이 가능

## B2C vs B2B 차이

| 항목 | B2C | B2B |
|------|-----|-----|
| 결제 버튼 | 표시 | 숨김 |
| 장바구니 | 표시 | 숨김 |
| 과정 가격 | 표시 | 숨김 |
| 필수 수강 과정 | 없음 | 상단 배너로 안내 |
