# LMS 기능 개요

> **총계:** 19개 기능 영역 / 79개 데이터 모델
> **유형:** B2B2C 멀티테넌트 학습관리시스템
> **대상:** 기업 내 임직원 학습 운영 (B2B) + 개인 수강생 (B2C)

---

## 핵심 사용자 플로우

### 1. 수강생 학습 플로우
```
강좌 탐색 → 수강신청 (또는 관리자 지정) → 온라인/오프라인 학습
→ 진도 추적 → 시험 / 과제 / 설문 제출 → 수료 조건 충족 → 수료증 발급
```

### 2. 강사 강좌 운영 플로우
```
강사 프로필 등록 → 강좌 생성 → 카테고리·커리큘럼 구성
→ 콘텐츠 업로드 (동영상 / SCORM / 과제) → 시험·설문 설정
→ 강좌 게시 → 수강생 관리 → 정산 내역 확인
```

### 3. 관리자 조직 운영 플로우
```
조직 설정 (사업장·부서·직급) → 사용자 초대·역할 부여
→ 강좌 수강 지정 (필수 과정) → 학습 현황 모니터링
→ 알림 발송 → 수료 현황 확인
```

## 기능 영역별 상세

### 1. 플랫폼 운영
> 서비스 전체를 관리하는 슈퍼어드민 영역

- 플랫폼 전역 설정 (서비스명, 도메인, 세션 타임아웃, 2FA 정책)
- 스토리지 / 사용자 수 임계값 알림 설정
- 테넌트 생성 / 정지 / 재개 이력 감사 로그
- 플랫폼 공지사항 관리

---

### 2. 테넌트 관리
> 고객사(기업) 단위 관리

- 테넌트 생성 및 플랜 설정 (트라이얼 / 활성 / 정지)
- 서브도메인 및 계약 기간 관리
- 사용자 수 / 스토리지 한도 설정
- AWS 인프라 프로비저닝 현황 모니터링 (EC2 / RDS / S3)
- SSO 연동 설정 (SAML / OIDC — Azure AD, Okta 등)

---

### 3. 조직 구조
> 테넌트 내 조직 체계 구성

- 사업장 등록 (본사, 지점 등 물리적 단위)
- 부서 트리 구성 (무한 depth 계층 구조)
- 직급 체계 설정 (사원 / 대리 / 과장 등)
- 조직 브랜딩 (로고, 색상, 파비콘)
- 공지사항 관리 (조직 단위 공지)
- 조직 이전 이력 관리

---

### 4. 포털
> 수강생이 접하는 학습 포털 화면 관리

- 배너 관리 (이미지, 링크, 노출 기간 설정)
- 법적 문서 관리 (이용약관, 개인정보처리방침 버전 관리)
- 사용자 동의 이력 기록

---

### 5. 사용자 & 인증
> 사용자 계정 및 권한 체계

- 역할(Role) / 권한(Permission) RBAC 체계
- 사용자 계정 관리 (이메일 가입 / SSO 연동)
- 세션 관리 (Refresh Token, 기기별 세션)
- 사용자 그룹 생성 및 그룹별 학습 지정
- 사용자 초대 (이메일 초대 링크)
- 접근 로그 기록
- 인앱 알림

---

### 6. 강사
> 강사 전용 기능

- 강사 프로필 (소개, 전문 분야, 공개 여부)
- 정산 계좌 등록 및 관리
- 수강생 리뷰 조회
- 수익 / 정산 내역 확인

---

### 7. 학습 콘텐츠
> 강좌 및 커리큘럼 구성

- 강좌 카테고리 트리 (무한 depth)
- 강좌 생성 및 기본 정보 관리 (제목, 설명, 썸네일, 난이도, 언어)
- 수강 취소 정책 설정
- 과목(Subject) 및 활동(Activity) 단위 커리큘럼 구성
- 활동 유형: 동영상 / 문서 / 과제 / 시험 / 설문 / SCORM
- 선수 강좌 설정 (수강 전 이수 필요 강좌 지정)
- 강좌 세션 관리 및 담당 강사 배정

---

### 8. SCORM
> SCORM 표준 e-Learning 콘텐츠 지원

- SCORM 패키지 SCO(Sharable Content Object) 관리
- SCORM 1.2 / 2004 런타임 세션 데이터 저장

---

### 9. 오프라인 학습 & 출결
> 집합 교육 및 현장 출석 관리

- 오프라인 세션 생성 (날짜, 장소, 정원)
- 출석 명부 관리
- 출결 이력 기록

---

### 10. 수강
> 수강신청 및 대기열 관리

- 수강신청 처리 (본인 신청 / 관리자 지정 / 그룹 일괄 지정)
- 정원 초과 시 대기열 자동 관리

---

### 11. 학습 이력
> 개인별 학습 진도 및 결과 기록

- 활동별 완료 여부 추적
- 시험 응시 이력 및 점수 관리
- 과제 제출 및 채점 이력
- 설문 응답 저장
- 전체 학습 활동 로그 (append-only)
- 동영상 재생 진도 저장 (구간별)

---

### 12. 평가 & 문항은행
> 시험, 과제, 설문 도구

- 문항은행 관리 (객관식, 주관식 등 문항 유형 지원)
- 시험 템플릿 생성 (문항 구성, 시간 제한, 합격 기준)
- 설문 템플릿 생성
- 과제 템플릿 생성 (채점 기준표 포함)
- 문항 자동 구성 규칙 설정

---

### 13. 수료증
> 학습 완료 인증서 발급

- 수료증 디자인 템플릿 관리
- 수료 조건 달성 시 자동 발급
- 발급 이력 및 고유 번호 관리

---

### 14. 미디어 라이브러리
> 콘텐츠 자산 통합 관리

- 동영상 / 이미지 / 문서 파일 업로드 및 관리
- 파일 타입, 용량, CDN URL 관리

---

### 15. 결제
> 강좌 구매 및 결제 처리 (B2C)

- 주문 생성 및 주문 항목 관리
- 결제 처리 및 결제 수단 기록
- 환불 요청 및 처리 이력

---

### 16. B2C 전용 기능
> 개인 학습자(B2C) 전용

- 장바구니 (강좌 담기, 수량 관리)
- 위시리스트 (관심 강좌 저장)
- 쿠폰 (할인 코드 발급 및 적용)
- 강좌 수강 후기 (별점, 텍스트 리뷰)

---

### 17. 학습 경로 (코스 묶음)
> 여러 강좌를 묶은 커리큘럼 패키지

- 학습 경로 생성 (복수 강좌 묶음, 순서 지정)
- 학습 경로 내 강좌 구성 관리

---

### 18. 메시징 & 크레딧
> 자동화 알림 및 메시지 발송

- 메시지 템플릿 관리 (이메일, SMS, 앱 푸시)
- 이벤트 기반 자동 발송 규칙 (수강신청 완료, 수료 등)
- 발송 이력 조회
- 메시징 크레딧 잔액 관리
- 크레딧 충전 / 사용 트랜잭션 이력
- 서비스별 크레딧 단가 설정

---

## 사용자 역할 체계

| 역할 | 설명 |
|------|------|
| Platform Admin | 전체 플랫폼 및 테넌트 관리 (슈퍼어드민) |
| Tenant Admin | 고객사 전체 설정 및 운영 관리 |
| Org Admin | 조직 단위 학습 운영 관리 |
| Instructor | 강좌 제작 및 강의 운영 |
| Learner | 강좌 수강 및 학습 |

---

## 지원 인증 방식

| 유형 | 인증 방식 |
|------|----------|
| B2C (개인) | 이메일 / 소셜 로그인 (Google, Kakao 등) |
| B2B (기업) | SSO — SAML 2.0 / OIDC (Azure AD, Okta 등) |
